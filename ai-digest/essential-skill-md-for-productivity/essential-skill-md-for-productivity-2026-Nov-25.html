1. Claude Code 2.1.332 loads skills straight from MCP servers, and adds a hook that can veto a skill's shell commands

Claude Code 2.1.332 is the new top entry in the official changelog. Its headline feature, in beta, lets MCP servers provide skills. They appear in the / menu as server:skill, while other skills keep their names. A team can now ship skills alongside the MCP server they depend on, rather than asking everyone to copy a skill folder into their repo. The release also adds a PreSkillShellCommand hook event that can refuse a skill or command's inline shell commands as it loads. This gives admins a policy point before a third-party skill runs anything. On 2.1.331 and older, a settings file that names the hook opens a dialog at start. Related fixes stop temp_* folders piling up in ~/.claude/plugins/cache when a plugin can't be copied into place, and stop hooks with endless or very large output from freezing the session.

Sources: Claude Code CHANGELOG.md, Claude Code changelog (docs)

2. addyosmani/agent-skills 0.6.18 makes each skill self-contained, and lets /plan write to your issue tracker

Addy Osmani's agent-skills pack released 0.6.18 on 24 Nov. Each skill now carries its own copy of the shared checklists under references/shared/, so installing one skill on its own no longer leaves it pointing at files that aren't there, and CI fails if a copy drifts from its source. That pattern is worth copying for anyone who publishes skills that people install one at a time. The /plan command can now create items in a configured issue tracker instead of always writing tasks/todo.md, which fits planning output into the tools a team already uses. The floor guard now reports findings as file:line without printing the flagged lines, which keeps secret-like values out of terminals and logs. The a11y audit script now resolves from the installed skill, so it runs from your own project. The SSRF example is now marked as partial, because fetch resolves DNS again after the check.

Sources: agent-skills releases, addyosmani/agent-skills repo

4. OpenClaw 2026.11.9 ships as stable while beta.3 opens library skills to remote app servers, and plugin config keys face removal from 29 Nov

OpenClaw published 2026.11.9 as its Latest stable release on 25 Nov, a day after 2026.11.8. The 2026.11.10-beta.3 pre-release (24 Nov) adds the skill changes: its Codex setup fixes make library skills readable to remote app servers and handle MCP servers that share a name. The beta also keeps the plugin session-fork feature from beta.2, allows hook bodies up to 1 MiB and reports rejected ones, and retries owed plugin updates on schedule while still respecting Hold. For people maintaining plugins or skill setups, the deprecation schedule is the main point. Plugin-related config, including registerCliBackend registrations, plugins.entries settings, plugin SDK session-resolution aliases, and the web search and fetch plugin keys, reaches its earliest removal date around 29 to 30 Nov. The notes advise running openclaw doctor and moving to the replacement settings before then.

Sources: OpenClaw v2026.11.9 release, OpenClaw v2026.11.10-beta.3 release, OpenClaw releases

5. Hermes Agent 0.23.4 lets you size the skill index, and Copilot CLI 1.0.116 flags plugins that duplicate an MCP server

Two agents shipped small but practical changes for people running many skills and plugins. Hermes Agent v0.23.4, marked Latest on 24 Nov, adds a skills.index_desc_limit setting. It controls how much of each skill's description goes into the index the model sees, which trades how easily skills are discovered against how much context the index uses. The same release adds hermes plugins config for editing a plugin's settings from the terminal, plus a batch of new plugin-catalog entries. GitHub's Copilot CLI 1.0.116 pre-releases (24 to 25 Nov) warn when a plugin and a standalone MCP server connect to the same endpoint, and show how to turn one off in /mcp. They also load workspace MCP servers from .mcp.json and .github/mcp.json files that contain comments, and stop repeated sign-in prompts when several sessions share an MCP server. Both releases address the same problem: setups that pile up skills and plugins tend to end up with duplicates and bloated context.

Sources: Hermes Agent releases, Copilot CLI v1.0.116-2 release, Copilot CLI releases
