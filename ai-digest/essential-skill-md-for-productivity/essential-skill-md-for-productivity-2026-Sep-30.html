1. Claude Sonnet 5.5 lands: 30% faster, up to 30% cheaper per task, and built for everyday documents, slides and spreadsheets

Anthropic released Claude Sonnet 5.5 on 28 September at unchanged Sonnet 5 pricing ($2 / $10 per million tokens), claiming 30%+ faster output and up to 30% lower cost per task because it needs fewer tokens and batches tool calls. Anthropic singles out everyday scoped work, including polished documents, slides and spreadsheets, and says it can follow slide templates to produce decks needing minimal editing. That is exactly the kind of work most productivity skills package, so template-driven skills should get cheaper and quicker to run. Early testers cited fewer tool calls and shell executions, and Claude Code 2.1.284 now points the sonnet alias at claude-sonnet-5-5.

Sources: Anthropic, 9to5Mac, Unite.AI, Digital Trends, The Decoder

2. Peak State Global ships 17 knowledge-worker SKILL.md skills

Peak State Global published a release of seventeen thinking-and-communication skills on 30 September, including pre-mortem, root-cause, stakeholder-map, meeting-to-actions, pyramid-rewrite, plain-english, hard-conversation-prep and systems-map. Unlike most skill packs aimed at coders, these target general knowledge work: structuring problems, rewriting for clarity and turning meetings into actions. It ships both as one-file-per-skill and as multi-file folders, each with SHA256 checksums, and the maintainers say it was verified on Claude Code with eval results in the repo. It is a ready-made starter set for non-engineering productivity workflows.

Sources: Peak State release notes

3. Claude Code 2.1.284 and 2.1.285 tighten plugin permissions and provider controls

Claude Code 2.1.284 stops plugins pre-approving their own tools under managed settings, so managed deny rules now win, and honours a block decision from elicitation hooks. It also adds an /mcp reconnect-all and fixes MCP calls in resumed sessions. Version 2.1.285, released on 29 September, adds an allowedProviders managed setting, a CLAUDE_CODE_DISABLE_WEB_FETCH switch and claude --desktop, and makes claude -p sessions on third-party providers start in auto mode when no permission mode is set. For teams distributing skills and plugins, the takeaway is that allowed-tools auto-approval is no longer something a skill can grant itself.

Sources: Claude Code 2.1.285 release notes, Claude Code 2.1.284 tracking issue, orchestkit cc-adoption issue, Claude Code What's new

4. SkillSeam: skills fail at the seams of a collection, not one by one

A new arXiv paper argues that individual skills may be competent yet fail as a library grows, because procedures compete for attention, aliases double-load, boundaries blur and badly sized skills turn routing errors into task failures. SkillSeam proposes six collection-level principles (persistence gradient, system coherence, regime gating, orthogonal coverage, flow and granularity discipline) and tests each through the failure channel it predicts rather than accuracy alone. The principles are also distributed as an installable skill, which makes it a practical checklist for anyone whose skills folder has passed a dozen entries.

Sources: arXiv abstract, arXiv HTML

5. Codex CLI 0.159 adds instant interrupt; 0.159.1 makes GPT-6.1 Sol the default model

OpenAI's Codex CLI 0.159.0, released on 29 September, adds an opt-in instant interrupt so you can steer the agent mid-response or during a long code-mode call. The follow-up 0.159.1 makes GPT-6.1 Sol the default model across the bundled catalogs, including Amazon Bedrock. Recent releases also improved the bundled OpenAI documentation skill with targeted official-source lookup. Steering a running agent without restarting matters for skill-driven multi-step tasks, where a wrong turn otherwise costs a full rerun.

Sources: Codex changelog, Gradually Codex CLI changelog
