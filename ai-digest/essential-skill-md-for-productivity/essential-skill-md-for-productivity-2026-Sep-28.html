1. Google confirms Gemini Gems will become Skills, with automatic migration starting November 17

Google has moved from the leaked, rumored version of this story (covered here back in August, with an October 20 cutoff) to an official one: the Gemini app now shows an in-product notice stating Gems will become Skills starting November 17, 2026, with automatic migration of existing Gems beginning that day and creating or editing Gems disabled from October 13. Skills serve the same purpose as Gems — packaged custom instructions for Gemini — but are invoked with a slash command in the prompt box and can be stacked, multiple at once, in a single conversation, which is a meaningfully different interaction model than a single selected Gem. The catch for anyone relying on this for free-tier productivity workflows: Gems are available to every Gemini user today, while Skills are currently gated to Google AI Pro and Ultra subscribers, and Google has not said whether that eligibility changes once migration completes. For a topic tracking "essential" SKILL.md-style skills, this is Google formally joining Anthropic, OpenAI, Microsoft and Notion in standardizing on the skill-as-reusable-instruction-package model — just with its own, currently paywalled, on-ramp.

Sources: 9to5Google, Android Authority (APK teardown), NewsBytes

2. GitHub Copilot makes organization and enterprise skills portable across local and cloud agent sessions, adds local sandboxing preview

GitHub's September 21 weekly Copilot release (published September 25) closes a gap that has quietly limited team-wide skill adoption: shared organization and enterprise skills, along with org-managed custom instructions, now work identically whether a developer is running Copilot locally or dispatching a cloud agent session — previously these could drift out of sync between the two surfaces. The same release puts local sandboxing into public preview, letting teams limit an agent's access to files, networks and credentials on the developer's own machine, and adds OpenTelemetry-based activity tracking so agent (and by extension, skill) usage flows into existing enterprise monitoring stacks instead of a Copilot-only dashboard. Paired with a separate September 24 change enabling GA Copilot features by default for Business and Enterprise plans within 28 days, this is GitHub tightening the operational plumbing around skills — portability and observability — rather than shipping new skill capabilities themselves, which matters for any org trying to standardize a shared skill library across its whole engineering org rather than per-laptop.

Sources: GitHub Changelog — weekly releases, Sept 21, GitHub Changelog — default feature enablement

3. Vercel's skills.sh registry crosses 1 million published skills and ~280 million installs — but installs are brutally concentrated

Vercel's new "State of Agent Skills" report puts hard numbers on how fast the SKILL.md ecosystem it helped standardize has grown: skills.sh reached roughly 1 million published skills and nearly 280 million installs in about seven months, a pace the report contrasts with GitHub's 27 months to reach a million repositories, the App Store's five-plus years to a million apps, and npm's nine-plus years to a million packages. The more useful finding for anyone building a "which skills are actually essential" list is the concentration data: nearly half of all published skills have been installed exactly once, while just 0.04% of skills account for 62% of all installs, meaning the practical skill ecosystem that matters for productivity is far smaller than the headline catalog size suggests. The report also found supply skews technical — software engineering, agent workflows, security — while installs are spread more evenly across categories including business operations and writing, and cross-industry (non-coding) skills capture 87.5% of installs despite being only 66% of classified skills. For a digest curating "essential" skills, this is a useful corrective against treating catalog size as a quality signal.

Sources: Vercel — State of Agent Skills, Superpower Daily, daily.dev summary

4. Anthropic opens a developer portal for submitting Agent Skill and MCP plugin bundles to the Claude directory

Following the September 23 launch of the Claude Marketplace (a procurement-focused hub covered in this digest's September 24 edition), Anthropic opened a separate developer-facing directory submission portal on September 25 at claude.ai/directory/manage. It lets developers on paid Claude plans submit two kinds of listings — a single remote MCP connector, or a full plugin bundle combining MCP servers and Agent Skills hosted on GitHub — track each submission through an automatic safety scan and review process, and, once approved, choose when to publish and see analytics on installs by surface, listing views and the search terms that led people to the plugin. By the time the portal launched, the underlying Claude Marketplace it feeds was already listing over 2,000 tools. This is the missing piece for teams that have built internal or niche SKILL.md packages and want a supported, reviewed distribution path into Claude's ecosystem instead of an unofficial GitHub repo.

Sources: Claude — Build plugins for Claude, Unite.AI, Superpower Daily
