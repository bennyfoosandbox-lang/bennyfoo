1. NVIDIA turns its physics and CUDA-X libraries into verified agent skills

NVIDIA announced an expansion of its Agent Toolkit for engineering, packaging PhysicsNeMo and the CUDA-X library family — including cuOpt, cuDF, NeMo, and CUDA-Q — as agent-ready "skills" that autonomous engineering agents can call directly. The move extends NVIDIA's existing open catalog of 110+ verified agent skills (hosted on GitHub and docs.nvidia.com) that install straight into Claude Code, Codex, and other coding agents to run physical-AI, robotics, simulation, and RAG workflows end to end. The new domain skills give agents access to sparse solvers and quantum-chemistry routines for physics simulation, plus cuOpt for real-time routing, scheduling, and supply-chain optimization. For this topic it's a concrete signal that a major infrastructure vendor now treats SKILL.md-style packaging as the distribution unit for expert engineering capability, not just office-productivity tasks — explicitly framed as letting "autonomous AI engineers" use accelerated solvers without needing CUDA expertise themselves.

2. A hobbyist's Claude skill teaches Autodesk Fusion 360 to take natural-language orders

Hackaday profiled a builder who, frustrated with Fusion 360's UX and lacking formal mechanical-engineering training, wired Claude up to Fusion's new MCP server via a project called ClaudeBridge — a Fusion 360 add-in paired with a dedicated .claude/skills/fusion360/SKILL.md that teaches Claude how to sketch, extrude, assemble, and export in Fusion's 3D coordinate space. The write-up doubles as a useful reality check on skill quality: a local Qwen model got most of the way through a clock-case design on one request but broke on a second, more complex one, while a more capable Claude model completed the job cleanly. ClaudeBridge illustrates a pattern this digest keeps tracking — a lean, single-job SKILL.md file that encodes hard-won domain knowledge (here, "where things go in 3D space") so the next session doesn't have to relearn it from scratch. It's a small but concrete data point for one of the topic's recurring themes: the most valuable skills aren't generic productivity boilerplate, they're narrow domain bridges into specialist software.

Sources: Hackaday, GitHub — altjx/ClaudeBridge

3. Addy Osmani's open-source engineering-discipline skill pack tops 75K GitHub stars

agent-skills, Google engineer Addy Osmani's open-source collection of 24 production-grade engineering skills (spec-writing, testing, security review, and shipping discipline) for AI coding agents, has grown from roughly 31,000 stars in early May to more than 75,000–77,000 stars and 8,300+ forks by late July — a growth curve several outlets flagged again this week. The pack works across 70+ coding tools (Claude Code, Cursor, Copilot, Codex) via 8 slash commands and targets a specific failure mode: agents that skip specs, under-test, and ship prototype-quality code when left unsupervised. The milestone is a useful crowd-validation signal for the "essential skills" question this digest tracks — it favors a curated, disciplined starter set over a sprawling marketplace grab-bag, echoing the "8–12 skill starter set" and "lean SKILL.md, one job" findings already logged in this knowledge base. It's also a counter-data-point to the ecosystem's ongoing quality complaints: this is one of the few widely-adopted packs treated as a genuine trust signal rather than noise.

Sources: Daily AI World, CoddyKit, GitHub — addyosmani/agent-skills

5. Codex's desktop app learns to discover skills across multi-folder projects

OpenAI shipped a Codex app update (v26.715, 23 July) that lets local ChatGPT desktop projects span multiple related folders — useful when an app and its docs, or a frontend and backend, live in separate directories. The skills-relevant detail: a project's designated primary folder now drives not just new chats and Git operations but automatic discovery of AGENTS.md, skills, and config.toml, so Codex reliably finds a project's skill definitions even as folder layouts get more complex. The same release added GPT-Live-powered ChatGPT Voice for narrating and coordinating tasks across Chat, Work, and Codex from the desktop app. It's a small but practical fix for a real productivity failure mode — a skill silently failing to trigger because an agent couldn't locate the SKILL.md in a multi-repo layout — landing in the same stretch where Codex's skill-invocation rate among active users has been climbing sharply this year.
