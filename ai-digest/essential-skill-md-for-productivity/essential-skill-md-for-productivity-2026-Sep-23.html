1. Claude Opus 5.5 ships and instantly becomes Claude Code's default model

Anthropic released Claude Opus 5.5 on September 22, cutting typical Opus workload cost by roughly 40% ($4/$20 per million input/output tokens, cache reads down to $0.20) while claiming 30%+ faster output and keeping a 1M-token context window. Claude Code shipped v2.1.280 the same day, making Opus 5.5 the new default Opus model, adding mouse-wheel scrolling to the /skills list and clickable plugin-state options, and letting teams raise the long-fixed 2,048-character cap on MCP tool descriptions via a new environment variable. GitHub Copilot picked up Opus 5.5 on its own changelog that same day, and OpenAI answered within hours by shipping two cheaper GPT-6 models — turning one model release into a same-day pricing skirmish across the two largest coding-agent ecosystems this digest tracks. For teams building SKILL.md-based workflows, the practical effect is a materially cheaper, faster default reasoning engine under both Claude Code and Copilot with no migration required.

Sources: Claude Code v2.1.280 release notes, Claude Code changelog, SiliconANGLE, GitHub Changelog, Havoptic

2. Anthropic's first transparency disclosure: Claude now leads 26% of its own R&D, up from under 1% in February

Anthropic published its first structured disclosure on internal AI automation, reporting that Claude "leads" 26% of the company's internal AI research and development work as of August 2026, measured on an Epoch-AI-derived AL0–AL5 automation scale where "leading" sits well above simple assistance but short of full autonomy. Anthropic said roughly 30,000 Claude agents now run concurrently on its internal research platform, and that it reviewed more than one billion agent decisions in August, blocking about one in every 47,000 (0.002%). A separate offline monitor now scans 100% of agent actions after the fact, flagging roughly 100,000 transcripts a week for automated follow-up and escalating about 50 of the highest-priority cases to human reviewers weekly. Anthropic framed the three metrics — automation share, block rate, and escalation volume — as a reusable measurement framework it hopes other frontier labs adopt, bearing directly on how much day-to-day engineering and research work a skill-driven agent fleet can be trusted to run unsupervised.

Sources: BetaNews, Quartz, AlphaSignal, Inside AI News

3. GitHub Copilot CLI v1.0.88 tightens terminal integration and session-approval memory

GitHub shipped Copilot CLI v1.0.88 on September 22, adding optional OSC 777 terminal notifications for users running direct Ghostty or WezTerm sessions and fixing text selection inside bottom-anchored dialogs, including login device-code prompts. A same-day patch, v1.0.88-1, preserves the /allow-all setting across managed-settings refresh failures and now remembers exact per-path session approvals for missing directories without silently widening the grant to the parent folder — visible via /list-dirs and reversible with /reset-allowed-tools. It's a smaller release than the CLI's recent sandbox-hardening pushes, but it continues the near-daily run of Copilot CLI point releases this digest has tracked since August, most of them closing gaps in how skill, plugin and permission state survives across sessions.

Sources: GitHub Copilot CLI releases, Havoptic
