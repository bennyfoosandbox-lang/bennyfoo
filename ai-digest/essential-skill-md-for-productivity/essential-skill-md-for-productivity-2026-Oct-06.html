1. Claude Code 2.1.290 adds a Managed Agents onboarding command and fixes /loop after compaction

Claude Code 2.1.290 shipped late on 5 October, the day after the Mods-hardening 2.1.289. The headline addition is `/claude-api managed-agents-onboard`, which sets up the Managed Agents pattern from inside the session and pairs with a same-day update to the official claude-api skill. For people who automate recurring work, the more practical fix is that scheduled tasks created with `/loop` no longer stop firing after the conversation is compacted, and `/rewind` now lists prompts that were sent while Claude was still working. Mod and plugin authors get two small hooks: `serverToolUses` in `turn.step` hook results and an `agentId` on the `tool.check` event.

Sources: Claude Code v2.1.290 release notes, Claude Code releases

2. anthropics/skills ships a managed-agents-onboard path in the claude-api skill

The official anthropics/skills repository took another commit on 5 October (#1962) that updates the `claude-api` skill so Managed Agents onboarding can start from either a quickstart name or a URL. It is the follow-on to the 29 September refresh that made Opus 5.5 the default, and it matches the new slash-command route in Claude Code 2.1.290. The repo's recent history shows the skill being touched roughly weekly (1 Sep, 10 Sep, 24 Sep, 29 Sep, 5 Oct), so anyone vendoring a copy should re-sync often rather than pin an old snapshot. It is a useful template for how a single reference skill can track a fast-moving API.

Sources: anthropics/skills commit history, anthropics/skills repository

3. Copilot CLI 1.0.92 goes stable with config subcommands as 1.0.93 pre-release follows

GitHub's Copilot CLI promoted 1.0.92 to the latest release on 5 October after a run of pre-release builds. It adds `copilot config` subcommands for managing settings and a Ctrl+E shortcut for switching environments, plus better credential handling for Entra-protected servers, oversized-image handling and shell output streaming. A 1.0.93-0 pre-release the same day keeps warmed language servers running across LSP requests when sandboxing is off and lets truncated shell commands be expanded with a click. The earlier 1.0.91 release (1 October) added sandbox certificate-authority commands for managing proxy trust. For teams sharing SKILL.md packs through Copilot, the sandbox and config work is what makes shared setups reproducible.

Sources: Copilot CLI releases, Copilot CLI v1.0.92

4. Codex CLI 0.160.1 patches remote MCP servers on Windows while 0.162 alphas roll

OpenAI cut Codex CLI 0.160.1 on 5 October as a narrow fix: remote stdio MCP servers launched with explicitly configured environment variables now keep `SYSTEMROOT`, `TEMP` and `TMP`, so a Unix host driving a Windows executor no longer loses the startup environment. Two 0.162.0 alpha builds followed the same day, though their notes were not published in detail. The patch matters because Codex plugins bundle skills together with MCP servers, and a server that fails to start silently breaks the skill that depends on it. It is a small release, included because it is new since the 0.160.0 entry already in the knowledge base.

Sources: Codex 0.160.1 release notes, Codex releases
