1. Claude Managed Agents ships budget caps, an advisor role, geo control, and GitHub-loaded skills in one week

Anthropic's Claude Developer Platform shipped four updates to Claude Managed Agents between August 5–8: sessions can now carry a hard budget cap that pauses the run with a budget_reached stop reason once spend hits the limit; a session can be given an "advisor," a model at least as capable as the agent's own that the primary thread can consult mid-turn for strategic guidance; teams can pin model inference to a US or global region via inference_geo, with US-pinned runs billed at 1.1x; and, most relevant here, a Managed Agents session can now mount a GitHub repository and have Claude automatically discover and load any skills in its root .claude/skills directory at session start. Together the changes make it easier to run long, unattended agent sessions with predictable cost and repo-sourced skills, building directly on the July 24 change that raised the per-session skill cap to 500.

Sources: Claude Platform release notes, ClaudeDevs announcement thread

2. Vercel's skills.sh launches Skill Packs, bundling multiple agent skills into one shareable, installable unit

Vercel added "skill packs" to skills.sh on August 7, letting anyone bundle several agent skills — pulled from the community registry, local folders/zips, or public and private GitHub repos — into a single shareable package with its own URL. A recipient installs the whole pack in one command via the MIT-licensed vercel-labs/skills CLI (npx skills add <pack-url>) and can refresh it later with npx skills update; packs can be scoped privately to one person or a whole team to standardize a shared skill set across projects. It extends the npm-for-skills model skills.sh has pursued since launch from single-skill installs to curated collections — useful for onboarding a team onto a consistent productivity toolkit in one step, though it also concentrates supply-chain risk into a single install if a pack's upstream sources aren't vetted.

Sources: Vercel changelog, Digital Applied analysis

3. New benchmark maps malicious SKILL.md files onto MITRE ATT&CK by adversarially rewriting real shell exploits as "helpful" skills

Researchers from Monash University and Transurban (arXiv 2608.05223, posted August 5) used six LLMs across four model families to transform 471 real-world malicious shell commands into skill files that read as benign, mandatory setup steps — for example, framing a credential-stealing command as a "preflight check" the coding agent should run without asking. The resulting 2,826-skill benchmark is mapped to 11 MITRE ATT&CK tactics, giving skill scanners and detection tools a structured, attack-technique-labeled dataset to test against rather than one-off proof-of-concept skills. It's the latest entry in a fast-growing line of malicious-skill research this digest has tracked (SkillCloak, SkillGate, MalSkillBench), reinforcing the pattern that an agent's willingness to follow "mandatory" instructions inside a skill file is itself the exploited surface, not just the skill's code.

Sources: arXiv abstract, arXiv PDF

4. SkillTrace treats skill selection as graph traversal, not single-shot retrieval, and sets a new SkillsBench state of the art

A new paper (arXiv 2608.02356, posted August 3) argues that picking the right skills for a task isn't a single retrieval problem but a graph problem: SkillTrace decomposes a user query into a semantic hierarchy, matches sub-queries against candidate skills, and then propagates across the dependencies between selected skills to assemble a complete, executable composition rather than a loose bag of plausibly-relevant skills. On SkillsBench it reaches a 53.17% success rate and 91.43% on ALFWorld, beating prior single-shot retrieval and reranking approaches. It complements the Field Aware Agent Skill Retrieval finding logged in this digest on August 8 (keeping a skill's name/description/body as separate fields improves retrieval) — together suggesting that as personal and team skill libraries grow past a handful of files, naive similarity search stops being enough and structure-aware selection becomes necessary.

Sources: arXiv abstract, arXiv full text

5. Drata opens limited availability for AI Agent Governance, shipping deepest for Claude and Anthropic-run agents first

Compliance platform Drata extended its Trust Management Platform on August 4 with AI Agent Governance, now in limited availability to enterprises that want to discover, monitor, and govern the AI agents — and by extension the skills and tools those agents load — running inside their organization, with continuous traceability rather than a one-time audit. The product ships first and deepest for Anthropic's ecosystem, with early-access customers already running it end-to-end against Claude-based agents in production, before expanding to other model providers. It's the compliance-vendor counterpart to the security-vendor tooling this digest has tracked all month (Mondoo's Shadow AI BOM, StepSecurity's Dev Machine Guard, Cequence's Skill Registry) — another sign that "which skills are our agents actually running" is becoming a standing enterprise question rather than a one-off security review.

Sources: Drata newsroom, Security Boulevard, IT Brief UK
