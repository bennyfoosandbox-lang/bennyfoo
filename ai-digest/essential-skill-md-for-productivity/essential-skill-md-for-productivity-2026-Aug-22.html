1. Claude Platform reaches GA: computer use, browser use, Skills API, and Files API

Anthropic announced on August 20 that computer use, a new browser-use tool, the Skills API, and the Files API are now generally available on the Claude Developer Platform — the most significant productization milestone yet for the Agent Skills format the company introduced in October 2025. Developers can now call the Skills API without the skills-2025-10-02 beta header, computer use ships as computer_toolset_20260801 with batch actions and zoom on by default, and the new browser-use tool drives structured web pages directly. Together the four GA'd primitives let teams build production agents that operate software, apply a team's expertise via reusable skills, and return finished files without beta gating — a clear signal Anthropic considers Skills-based agents ready for broad enterprise use, not experimental deployment.

Sources: Anthropic blog, Claude Platform Skills API docs

2. OWASP publishes Agentic Skills Top 10 v1.0

OWASP released version 1.0 of its Agentic Skills Top 10 on August 17, days after Black Hat USA and DEF CON, giving the fast-growing SKILL.md ecosystem its first vendor-neutral risk taxonomy. The list catalogs the top security failure modes specific to agentic skill bundles — spanning SKILL.md, skill.json, and manifest.json formats across ecosystems — and is explicitly mapped to OWASP's own AI System Verification Standard, the MCP Top 10, the LLM Top 10, ISO/IEC 42001, and the NIST AI RMF. It lands after a year of escalating skill-marketplace incidents already tracked in this digest — Zenity's 1.7M-install Paperclip campaign, ESET's tally of thousands of malicious skills, SkillCloak's scanner-evasion technique — giving enterprises adopting third-party skills for productivity a shared checklist instead of each vendor inventing its own.

Sources: OWASP project page, GitHub repo

3. "@skills: Attention Is All You Have" — trigger slots, not skill count, are the real bottleneck

A new paper (arXiv:2608.12610, submitted August 12) argues that the real ceiling on skill-based productivity gains isn't how many skills exist — it's that only around 100 skill descriptions can reliably compete for attention in an agent's system prompt at once, out of more than 56,804 public skills already published. The authors propose decoupling a skill's content, persistence, and triggering into an addressable, non-resident protocol — open-sourced as @skills/atskills — so agents can reference skills without permanently installing them into scarce prompt real estate. It's a direct, practical follow-up to last week's "Demystifying Agent Skills" finding (covered in this digest's August 21 run) that retrieval precision collapses from 29.6% to 3.3% as a skill pool grows from 5 to 100: this paper proposes an architectural fix rather than just diagnosing the problem.

Sources: arXiv abstract, Full text (HTML)

4. JetBrains ships a breaking Junie Agent Skills update in Rider/ReSharper 2026.2.1

JetBrains released Rider and ReSharper 2026.2.1 on August 19, updating the Junie AI agent to add Claude Opus 5 model support alongside refreshed Unreal Engine agent skills (ue-code-authoring, ue-test-authoring). The update is a breaking change for skill installs specifically: anyone who already has the older Unreal Engine skills installed has to manually uninstall and reinstall them via Settings → Tools → AI Assistant → Skills for the fixes to take effect, rather than picking them up automatically on update. It's a small but concrete reminder that SKILL.md-format productivity tooling now carries real versioning and upgrade-path obligations for IDE vendors, not just chat-agent vendors.

Sources: JetBrains .NET blog

5. Claude Code v2.1.237-239 tighten output, plugin security, and its own claude-api skill

Three Claude Code releases landed August 20-21: v2.1.237 adds a built-in "Concise" output style that has Claude lead with results and skip preamble/narration for equivalent work depth; v2.1.238 adds a plugin-marketplace headersHelper that mints short-lived auth headers for private catalog and archive fetches during skill/plugin installation; and v2.1.239 ships /claude-api upgrade, which migrates Python projects off the older anthropic SDK 0.x and updates the bundled claude-api SKILL.md skill's own reference material for SDK 1.x (e.g. anthropic.Timeout replacing httpx.Timeout). Together they're a small but telling batch: one changes how skills communicate results, one hardens how skills get installed from private marketplaces, and one keeps a first-party skill's own reference material from going stale as the underlying SDK changes.

Sources: Claude Code changelog
