1. Google ships Modern Web Guidance 1.0, a skill set that stops coding agents writing outdated web code

Google's Chrome team moved Modern Web Guidance out of preview to a stable 1.0 on 10 November. It is a free set of 203 guides covering roughly 250 web platform features, packaged so coding agents load the relevant guide when they write HTML, CSS or JavaScript instead of falling back on patterns from years ago. You install it in a project with npx modern-web-guidance@latest install or through the plugin marketplaces of the main coding agents, and Google lists Codex, Cursor, GitHub Copilot, Antigravity, JetBrains WebStorm and others as supported. Google runs a public nightly dashboard where agents from Anthropic, OpenAI and Google do the same tasks with and without the guidance: Chrome reports about 90% of checks passing with it versus about 50% without, and one adopter, note inc., saw pass rates rise from 61% to 94% over 180 runs. For front-end teams it is one of the clearest measured cases yet of a vendor-maintained skill set making agent output better, and Google says it will next pair it with Chrome DevTools so agents can test their own code in a browser.

Sources: Chrome for Developers, Search Engine Journal, Coywolf, DEV Community

2. Claude puts skills, connectors and plugins on one Plugins page, and Enterprise admins must enable Skills by 30 November

Anthropic has replaced Claude's separate Skills, Connectors and Plugins tabs with one Plugins page, and the sidebar's Customize item is now called Plugins. The rollout started gradually on 29 October and reached Free, Pro, Max, Ultra and Team plans on 9 November; Enterprise plans get it on 30 November. Existing connectors stay connected and only move in the menu. The practical catch is for admins: if Skills are turned off for an organization, plugins stop working in Claude Desktop once the update lands, so Team and Enterprise admins who want plugins need to turn Skills on before 30 November. It is another sign that skills are now the base layer that plugins are built on, not an optional extra.

Sources: Claude Help Center, Superpower Daily

3. shadcn's improve skill has a strong model write the plans and a cheaper model carry them out

shadcn, the creator of the shadcn/ui component library, published improve, a skill that audits a codebase and writes implementation plans but never changes source code itself. Its README states the idea plainly: use your most capable model to understand the codebase, judge what is worth doing and write the spec, then hand each plan to a cheaper model to build. A run produces a findings table; you choose which items to plan, and each becomes a self-contained Markdown file in plans/ with an index giving order, dependencies and status. Commands include /improve quick, /improve branch for just the current branch's changes, /improve execute, which sends a plan to a cheaper model in an isolated worktree and reviews the diff, and /improve reconcile to tidy the backlog. Installed with npx skills add shadcn/improve, it was trending on GitHub this week with roughly 10,000 stars, and it gives teams a ready-made way to spend expensive model time only on planning.

Sources: shadcn/improve on GitHub, explainx.ai, SaaSCity

4. HackerNoon's Cuttlefish.MD library packages 2,806 license-checked skills as installable plugins

HackerNoon has turned its Project Cuttlefish.MD library of SKILL.md files into an installable marketplace. The companion repo, hackernoon/cuttlefish-agent-skills, includes every skill from the library whose license allows redistribution: 2,806 skills from 29 authors, credited to their original authors, with licenses checked one repo at a time and human editors reviewing them. The skills are grouped into nine category plugins, including Writing & Blogging (706), Data & Science (599), Dev Workflow (530), QA & Testing (422) and Security (102). In Claude Code you add it with /plugin marketplace add hackernoon/cuttlefish-agent-skills and install a category such as dev-workflow@cuttlefish; for Codex, Cursor or Gemini CLI you copy a category's folders into .agents/skills/. Since most large skill collections are scraped with unclear rights, a curated, license-checked set is a safer place for teams to start, though the counts come from HackerNoon's own repo and announcement.

Sources: hackernoon/cuttlefish-agent-skills on GitHub, HackerNoon
