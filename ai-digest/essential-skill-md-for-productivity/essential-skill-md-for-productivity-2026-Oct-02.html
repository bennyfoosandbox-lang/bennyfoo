1. Chainguard details how it hardens agent skills: scan, auto-remediate, re-verify, sign and pin

Chainguard published a walkthrough on 1 October of the pipeline behind its Agent Skills product, which now covers internally built skills as well as community ones. Each skill is hashed on ingestion, scanned with Chainguard's own rules plus open-source scanners including Cisco's Skill Scanner and NVIDIA's SkillSpector, and analysed by AI agents; anything showing credential harvesting or prompt poisoning is ejected. Remediable risks are fixed by an agent that edits the skill, the full scans are re-run to confirm the fix and that the skill still works, and the result is signed, pinned to a digest and published to a private registry with a HARDENING.md audit report. The company also describes a monitoring technique it calls linear probing, which watches the agent's behaviour rather than just the skill text. It is a vendor description, but it shows what a vetted-skill supply chain looks like for teams that do not want to read every SKILL.md by hand.

Sources: Chainguard

2. Red Hat: a skill that misfires never errors, so test triggers with skill-creator, promptfoo and CI

A 1 October Red Hat Developer article by Dejan Bosanac argues that the most common way a skill fails is a silent misfire: the trigger description is weak, so the agent just does the job itself and the skill never runs. He recommends drafting with Anthropic's skill-creator, whose eval loop and description optimizer tune triggering, then moving those prompts into promptfoo, which can drive real agent runtimes and offers a skill-used assertion. Test sets should include positive, near-miss and negative prompts, kept beside the skill and run in CI through the promptfoo GitHub Action when a SKILL.md changes. The author puts a trigger suite at roughly $0.10 to $0.15 per eval and suggests starting as an informational check before making it a blocking gate. For anyone building productivity skills of their own, it is a practical recipe for keeping them working.

Sources: Red Hat Developer

3. SkillSeek: plain bm25 plus a small cross-encoder finds the right skill as well as an LLM loop, at about half the cost

With open-source collections now past 230,000 skills, a paper submitted on 30 September (arXiv 2609.38822, accepted at AACL-IJCNLP 2026) says choosing a skill, not writing one, is the bottleneck. The authors built SkillSeek, a two-stage retriever using a BGE-base bi-encoder and a small cross-encoder, exposed over MCP. On the 89-task SkillsBench benchmark it matched the pass rate of an LLM-mediated retrieval loop, and plain bm25 alone matched or beat that loop in three of four settings. Total per-trial spend fell from USD 51.30 to USD 27.54, within fifty cents of having no skills at all. The caveat is that results are for the SkillsBench tasks and OpenHands harness they tested, but it suggests big skill libraries can be searched cheaply instead of paying tokens for the agent to hunt.

Sources: arXiv, Hugging Face Papers

4. Atlassian's TWG CLI installs a set of Jira and Confluence skills into every major agent at once

Atlassian's developer documentation, updated 30 September, describes how the TWG CLI installer writes a canonical skill bundle to ~/.agents/skills, the universal layout read by Codex, Cursor, Gemini CLI, GitHub Copilot, Rovo Dev and others, and also copies it to ~/.claude/skills when Claude Code is present. The bundle is a root twg skill plus focused siblings for Jira, Confluence and workflows such as status rollups and engineering work, with detailed references loaded on demand. A twg help discover-skills command lets an agent search the unloaded references locally instead of guessing. Prompts such as summarising what a team did this week or showing the current sprint and blockers then work in plain language. This is separate from Atlassian's Rovo custom-skills news and shows a vendor shipping one skill set that follows the open layout across tools.

Sources: Atlassian Developer docs

5. Skills Manager 1.40.3 keeps one skill library synced across 54 agents, and its own skill lets agents manage it

The open-source Skills Manager desktop app (5.3k GitHub stars) shipped version 1.40.3 on 1 October. It keeps a single central library of skills and deploys them by symlink or copy to 54 supported agents, including Claude Code, Codex, Cursor, Copilot, Gemini CLI and, since mid-September, GitLab Duo. Presets let you switch whole groups of skills on or off per agent or project, update tracking checks Git-based skills for upstream changes, and optional backup syncs the library across devices through a private Git repository with skill-aware merging. A published manage-skills skill, installable with npx skills add, lets Claude Code or Codex drive the same CLI instead of writing into agent folders directly. For people juggling several agents it is a tidy answer to skill sprawl, though the project is community maintained.

Sources: Skills Manager on GitHub
