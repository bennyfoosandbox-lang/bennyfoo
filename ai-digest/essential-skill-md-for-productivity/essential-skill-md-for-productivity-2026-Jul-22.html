1. Claude Cowork can now learn a skill just by watching you work

Anthropic shipped "Record a Skill" inside Claude Cowork's desktop workspace: users click the "+" menu, record their screen while performing a task, and narrate it out loud, and Claude converts the capture — screen activity, mouse clicks, keystrokes, and voice commentary — into a reusable, structured skill it can run again on demand. The feature is live now for Pro, Max, and Team plan subscribers and directly targets the biggest barrier to building good SKILL.md files: most people don't want to hand-write instructions and scripts. It mirrors a similar "record and replay" capability OpenAI shipped for Codex, making show-don't-tell skill authoring a competitive front between the two platforms rather than a one-off feature.

Sources: The Decoder, Android Headlines, Cyber Security News

2. OpenAI's ChatGPT Work agent tops 10 million users as a small-business push follows

OpenAI announced that Codex and its new ChatGPT Work agent have collectively surpassed 10 million users, with demand nearly doubling since ChatGPT Work's launch. Powered by GPT-5.6, ChatGPT Work connects to Slack, Microsoft Teams, Google Drive, and SharePoint through a new unified plugins directory, then works multi-step projects for hours — building slides, sheets, docs, and even web apps — while checking in for approval on key actions and using Scheduled Tasks to keep projects moving unattended. To back the launch, OpenAI simultaneously introduced a "ChatGPT for Small Business" program bundling hands-on webinars, guides, and curated partner skills from Dropbox, Shopify, Intuit, Slack, Atlassian, and Wix. It rolled out today for Pro, Enterprise, and Edu plans, with Plus and Business following within days — a direct challenge to Claude Cowork's positioning as the reusable-workflow productivity layer.

Sources: OpenAI, 9to5Mac, Inc., BigGo Finance

3. Claude Code closes two permission-bypass classes that let commands slip past "auto mode"

Claude Code v2.1.216 fixes two distinct ways commands could evade the agentic permission checker while running unattended. The Bash bypass let compound statements — commands chaining execution and file redirection with && or negation operators — pass through without being flagged as write operations; the PowerShell bypass exploited invisible Unicode Tags-block characters (U+E0000–U+E007F) that render as nothing on screen but are still executed by the shell, letting an attacker smuggle instructions past visual review. Combined with six more bypass fixes shipped two days earlier in v2.1.214, Anthropic calls it the most concentrated period of permission hardening in the tool's release history — directly relevant to anyone running skills or scripted agents in auto/unattended mode, where these gaps matter most.

Sources: Tech Times, Classmethod, GitHub Releases

4. "AgentBaiting" and a fresh ESET scan put real numbers on the fake-skill malware problem

Following on from yesterday's report of 7,600 fake GitHub repos, security researchers now attach a name and bigger figures to the same campaign class: "AgentBaiting" uses roughly 800 fake AI Skills and MCP servers to trick coding agents into recommending malware, delivering the SmartLoader loader and StealC infostealer, and cyberpress.org reports the tainted packages across public AI registries have collectively racked up 14 million downloads. Separately — and more broadly — ESET says it scanned around 800,000 agentic skills between March and May 2026 and found over 25,000 flagged suspicious and more than 2,500 classified outright malicious, the first large-sample prevalence study of its kind. Together they turn last week's isolated incident into a quantified, ecosystem-wide risk: install skills from vetted sources only, and treat "popular" as no substitute for reviewed.

Sources: Cybersecurity News, GBHackers, ESET, Cyberpress, Help Net Security

5. Enterprises are told to stop treating skills like app-store downloads

A new enterprise-security framing argues that agentic skills need governance as software supply-chain components, not casual marketplace installs: an AI agent invoking a skill inside an "approved" workflow can silently pass along credentials, repository access, and infrastructure permissions that were granted for something else entirely, and risk tends to build from the accumulation of capabilities across many skills rather than any single flawed one. A companion piece from Snyk distills this into three concrete rules — skills run code with your system permissions, they are not inert documents, and they must be reviewed like any third-party code dependency, from approval through runtime behavior and future updates. It's the practical, defensive counterpart to today's AgentBaiting and ESET findings: know why a skill needs the access it asks for before you install it.

Sources: DevOps Digest, Snyk (via Truthinit)
