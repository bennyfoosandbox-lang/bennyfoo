1. Trojanized Claude Code extension in Cursor's marketplace planted an SSH backdoor

Tampered builds of the Claude Code editor extension (2.1.312 and 2.1.313) were served from Cursor's marketplace for roughly 11 hours on 29 October, adding an attacker's SSH key, opening a reverse tunnel and installing persistence. Cursor puts the exposure at up to 5,000 users and says it shut the marketplace, pulled the package, rotated keys and rebuilt the service. Anthropic says it never built or published the tampered copy and that 2.1.313 was not on its official hosts, though some researchers say it also surfaced on Open VSX, so that point is unresolved. Uninstalling or updating does not remove the backdoor, so anyone who ran those versions, and who keeps SKILL.md-driven agent setups on the same machine, should check for them, rotate credentials and consider rebuilding the host.

Sources: ThreatDefence, StepSecurity, Notebookcheck, Morphisec, Cybersecurity News

2. Claude Code 2.1.316 lets sub-agent effort be set separately

Claude Code 2.1.316, which reached npm overnight between 30 and 31 October, adds the CLAUDE_CODE_SUBAGENT_EFFORT variable so sub-agents no longer inherit the main session's effort level. An effort field in a sub-agent's own definition still wins over both the session and the variable. For skills that fan work out to sub-agents, this means routine research or formatting helpers can run at low effort while the lead session stays high, trimming latency and spend. The release also adds a kill switch for ultrathink and deprecates Opus 4.8 fast mode, which is removed on 30 November. Coverage disagrees on the exact valid effort levels, so confirm them with /model on your install.

Sources: DEV Community, Classmethod, clauding.de, Creators Toolbox, Pasquale Pillitteri

3. Agent Skill Doctor ships a first alpha for linting SKILL.md files

Agent Skill Doctor v0.1.0 is a first public alpha of a static checker for SKILL.md-based skills, flagging invalid structure, weak metadata, broken local references, packaging problems and risky script or instruction patterns. It treats the target files as untrusted and never executes their code, redacts credential-like strings from its evidence, and can emit JSON or SARIF for CI pipelines. Its own guidance warns that static patterns cannot prove runtime behaviour or rule out prompt injection, so it complements rather than replaces review. The release date could not be confirmed from search results, so treat this as a recent but undated find; it is one of several similarly named skill linters, so check you have the 014-code project.

Sources: Agent Skill Doctor v0.1.0 release discussion, Bundled skill-doctor SKILL.md
