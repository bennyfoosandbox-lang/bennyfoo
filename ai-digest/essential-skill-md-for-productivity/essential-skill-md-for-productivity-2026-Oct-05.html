1. Claude Code 2.1.288–2.1.289 spends two releases hardening plugins and the new Mods layer

Two point releases landed on 2–3 October, right after 2.1.287 introduced in-process Mods, and almost every fix targets the plugin surface. Anthropic closed a hole where a user-installed plugin could rewrite the descriptions of an organization-managed MCP server's sign-in tools, and fixed managed-mode cases where plugins or marketplaces could pre-approve their own tools through allowed-tools. Bash deny/ask rules that were skipped behind an environment-variable prefix or a bare assignment under sandbox auto-allow were also patched. For skill and plugin authors, `claude plugin validate` no longer skips a plugin when its folder also holds a marketplace manifest, and `--plugin-dir` hot reload now follows symlinks. The takeaway for productivity-minded teams: skills and plugins are now treated as a governed, security-reviewed layer, so pin to 2.1.289 before rolling out shared skill packs.

Sources: Claude Code v2.1.289 release notes, Claude Code v2.1.288 release notes, Claude Code v2.1.287 release notes

2. OpenAI's DevDay recap: plugin extensions, always-on 'dots' and a shared ChatGPT Space (from 29 Sep)

OpenAI's 29 September DevDay, which the digest had so far only covered as pre-event speculation, delivered more than 20 announcements aimed at turning ChatGPT and Codex into a work platform. Plugin extensions let developers ship what the company calls entire applications native to ChatGPT and Codex, distributed through OpenAI, building on the Codex plugins that already bundle skills, app integrations and MCP servers (six role-specific plugins spanning 62 apps and 110 skills). 'Dots' are always-on agents with their own cloud computer and browser, connectable to 4,000+ apps, and ChatGPT Space gives teammates, ChatGPT and a dot one shared knowledge base, rolling out to Pro, Business Premium and Enterprise. Codex now also runs fully in the cloud, so long skill-driven jobs no longer need a laptop open. This is a few days older than the 24-hour window; it is included because it is new to the knowledge base and directly reshapes where reusable skills live.

Sources: CNBC, BGR, Engadget, 9to5Mac, Pulse 2.0

3. Copilot CLI turns /skills into a full management command: list, edit, create, review, status

GitHub's Copilot CLI reference now documents `/skills` with five subcommands, `[list|edit|create|review|status]`, where it was previously a simple picker; the change was picked up by an automated docs tracker on 2 October. It means authoring and auditing a SKILL.md can happen entirely inside the terminal session, including a review step and a status view of what is loaded. The adjacent 1.0.92 builds (1 to 4 October) carried no skills changes of their own, but added a local-versus-cloud environment picker (Ctrl+E) and `copilot config` subcommands, so the release notes understate where skills management moved. Copilot is the last major agent whose skills UX lagged Claude Code's, and this closes much of that gap.

Sources: Copilot CLI docs-change tracker (#108), Copilot CLI v1.0.92-4, Copilot CLI v1.0.92-3

4. Addy Osmani's agent-skills pack passes 101K stars, now 25 skills and 70+ supported agents

The engineering-discipline skill pack from Addy Osmani, last logged here at about 75K stars in July, now shows 101.2K stars and 10.6K forks, with the repo updated on 3 October. It bundles 24 lifecycle skills plus a `using-agent-skills` meta-skill, wired to nine slash commands that follow a spec, plan, build, test, review, ship loop (`/spec`, `/plan`, `/build`, `/test`, `/constraints`, `/review`, `/webperf`, `/code-simplify`, `/ship`). Install paths now cover Claude Code, Codex, Copilot, Gemini CLI, Cursor, Windsurf, Kiro and more than 70 agents in total. A curated, small set of skills growing this fast is good evidence that people prefer opinionated workflows over giant skill dumps. This is a materially new development on a previously covered repository (stars up ~35% since July).

Sources: addyosmani/agent-skills on GitHub, VoltAgent/awesome-agent-skills (1000+ skills index)

5. Anthropic's official skills repo refreshes its claude-api skill for Opus 5.5 and Sonnet 5.5

The most recent commit to anthropics/skills, dated 29 September (#1930), updates the `claude-api` skill so Claude Opus 5.5 is the default model, adds Sonnet 5.5, and ships new build-eval and hillclimb guides. The repository, which now shows about 180K stars and 21.2K forks, has seen a steady cadence of claude-api updates (1, 10 and 24 September) plus a September rewrite of the frontend-design skill to avoid generic design defaults. For anyone using these as productivity skills, the practical point is that reference skills are living documents tied to model releases, so re-pulling them regularly keeps agents from coding against stale model names. The cadence also shows Anthropic dogfooding its own eval-driven loop on skill content.

Sources: anthropics/skills commit #1930, anthropics/skills commit history, anthropics/skills repository
