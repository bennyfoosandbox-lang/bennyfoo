1. Red Hat publishes a vendor-neutral playbook for combining AGENTS.md with Agent Skills

Red Hat Developer's Dejan Bosanac published a practical guide on pairing AGENTS.md — an "always-on" project-context file he recommends keeping under 150 lines — with Agent Skills, the task-specific SKILL.md folders that load on demand via progressive disclosure. The piece walks through concrete distribution patterns for teams: bundling related skills into a Claude Code plugin via a plugin.json manifest, then cataloging multiple plugins into a Git-hosted marketplace (a marketplace.json file) that installs with a single /plugin marketplace add command instead of manual cloning and symlinking. It's honest about the gaps too — packaging and distribution aren't standardized across agents yet (Cursor uses its own plug-in directories, the Gemini CLI uses extension configs) — and points to Red Hat's own "Lola" package manager as one attempt at unifying installation across tools. For anyone assembling an "essential skills" starter kit, it's a rare hands-on playbook for how to structure and share skills at team scale rather than just author individual ones.

Sources: Red Hat Developer

2. Microsoft's rebuilt Copilot Studio lets you import Claude Code and GitHub Copilot skills directly

Microsoft's July 7 general-availability rebuild of Copilot Studio replaced the platform's old topic-based conversation model with an agent-first orchestrator — Microsoft reports roughly 20% higher evaluation performance alongside close to a 50% drop in token consumption — and introduces "Skills" as a first-class authoring primitive: plain-markdown instruction sets that load on demand instead of permanently bloating the system prompt. The part that matters most for the SKILL.md ecosystem is portability: Copilot Studio's new unified Build surface explicitly supports importing skills already written for GitHub Copilot or Claude Code, giving enterprise no-code builders a way to reuse developer-authored skills instead of rewriting them from scratch. It ships alongside a Workflow Designer that mixes deterministic steps with reasoning "agent nodes," node-by-node debugging, native workflow version history, and preview support for Entra agent identities so agent actions get tied to a real, audit-logged identity instead of a shared service account. If Microsoft follows through on the cross-tool import path, it's the first concrete skill-portability bridge between the enterprise low-code world and the developer-first coding-agent world — noted here a few weeks after its July 7 ship date since it hadn't surfaced in this digest yet.

Sources: Microsoft Community Hub, ChatForest builder's guide, ERP Software Blog

3. Agensi's paid SKILL.md marketplace crosses 2,000 skills three months after launch

Agensi, a dedicated marketplace for buying and selling SKILL.md files that plug into Claude Code, Cursor, GitHub Copilot and other coding agents, announced (July 9) that it has crossed 2,000 listed skills, 3,000 registered users and 50,000 monthly visitors just three months after launch, powered by a community of 200+ expert skill creators. The pitch is simple: a $5 skill that saves an hour of configuration pays for itself immediately, and SKILL.md's emergence as a cross-agent standard means a skill built once can reach buyers across 20+ compatible tools instead of being locked to one vendor. It's a smaller data point than a platform launch — and it's syndicated wire-service PR rather than independent reporting — but it's a useful proxy for how fast the paid, curated end of the skills economy is growing relative to the much larger free/open registries like skills.sh and ClawHub that dominate raw install counts. It's also a reminder for the vetting question this digest has tracked repeatedly: a growing paid marketplace still needs buyers to check a skill's permissions and provenance before installing something with file or shell access.

Sources: Newsfile Corp, Agensi
