1. CTech explainer: a practical guide to building, porting and vetting your own skills

Israel's CTech published a how-to for non-developers on turning repeated chores into skills for Claude, ChatGPT or Gemini, drawing on Alex Choroshin, who maintains Skills IL, a volunteer library of 200+ skills for Israeli users such as tax and insurance forms. His rules are concrete: write a description that says when the skill triggers, cut anything the model already knows, keep one job per skill, and date any facts that can go stale. The piece also stresses that SKILL.md files are portable but not identical across platforms, and that you should read a downloaded skill's files for requests unrelated to its stated task before installing it.

Sources: CTech by Calcalist

2. Adobe's skills repo now spans 15 plugins, installable into Claude Code, Copilot CLI, Cursor and npx skills

Adobe's public adobe/skills repository packages its agent skills as Claude-format plugins covering analytics (KPI pulse, funnel analysis and executive briefings that call Adobe Analytics and CJA MCP servers), Workfront planning, AEM and Edge Delivery Services, Commerce, App Builder and a Creative Cloud set for the Claude desktop app. Its README says Copilot CLI reads the same plugin manifests, and it also documents installs through npx skills and the gh-upskill extension, so one repo serves several agents. Recent commits include a stardust 0.33.0 release and a new Workfront Fusion optimizer skill, and the repo has about 200 stars. For productivity teams it shows a large vendor shipping ready-made reporting and briefing skills rather than prompts.

Sources: GitHub: adobe/skills

3. rote compiles a proven SKILL.md into a deterministic pipeline that runs without an LLM

The open-source rote CLI takes a working skill (a SKILL.md plus references) and compiles it into a typed pipeline in which fixed logic and tool orchestration become reviewable code, with a model called only for steps that need judgment. Its README pitches this as turning a 10-20 minute agent loop into a cheaper background workflow that can be regression tested, and ships an expense-audit example that processes sixteen multi-currency expense lines with no model in the loop. It targets the cost and repeatability problem of running the same skill a thousand times, and sits alongside the retrieval and bloat work already covered here as another way to cut skill overhead.

Sources: GitHub: trevhud/rote

4. codeArbiter adds repo-owned hard gates for Claude Code, Codex CLI and Pi

codeArbiter, an AGPL-licensed governance layer at version 3.2.0, ships sibling plugins for Claude Code, Codex CLI and Pi that share one checked-in .codearbiter/ store of specs, plans, ADRs and audit history. Every request enters a named lane that defines the evidence required and the reviewers dispatched, and the rules refuse to write feature code before a failing test exists, commit on a red suite, guess at open questions or push to the default branch. It appeared at the top of GitHub's freshly updated skill repositories with about 149 stars, an example of skills used as enforceable process rather than advice.

Sources: GitHub: arbiterForge/codeArbiter, Trending Claude Skills tracker

5. Linkly's daily Best Skills rankings: find-skills past 3.9M installs, grill-me at 1.4M

Linkly AI's open-data Best Skills repository merges installs and social buzz from skills.sh, ClawHub and Tencent SkillHub into nine daily CSV rankings, tracking 10,000+ skills. The 19 October snapshot puts Vercel's find-skills first by installs on skills.sh at about 3.92 million, followed by Matt Pocock's grill-me at about 1.38 million and agent-browser at about 1.17 million; the skills.sh vendor table shows Microsoft with 582 skills and 7.1 million installs and Anthropic with 605 skills. The data is CC BY 4.0, and the repo itself ships a SKILL.md and llms.txt so an agent can query the rankings, a handy shortlist source for choosing which skills to install.

Sources: GitHub: LinklyAI/best-skills, Linkly AI rankings
