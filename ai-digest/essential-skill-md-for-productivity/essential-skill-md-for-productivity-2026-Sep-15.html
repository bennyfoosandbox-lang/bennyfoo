1. Claude Code v2.1.271 brings fast mode to Remote sessions and locks Bash/PowerShell to per-command domains

On September 14, 2026, Anthropic shipped Claude Code v2.1.271, extending "fast mode" — the low-latency Opus configuration previously limited to local sessions — to Claude Code Remote, covering both cloud and self-hosted runners; the host's fast-mode setting or a /fast toggle typed mid-session now applies wherever an organization allows it. The release also adds per-command allowed_domains to Bash, PowerShell, and Monitor when running in auto mode with sandboxing: instead of one sandbox-wide allowlist, the specific hosts a command needs get reviewed and opened for that command alone, with every other host refused. For teams running unattended Claude Code sessions — exactly the productivity use case this digest tracks — the change tightens the blast radius of any single automated command without slowing interactive work. It continues a two-week pattern of releases (v2.1.265 through v2.1.270) focused on hardening unattended and remote execution rather than adding new user-facing capability.

Sources: Claude Code v2.1.271 release notes, Claude Code changelog

2. "Skill Issue" finds that optimizing a repo's SKILL.md against its own merged PRs beats generic benchmarks — but only for one of two leading methods

A new paper accepted to EMNLP 2026's REALM workshop, "Skill Issue: Lessons from Optimizing Repository SKILLs for Coding Agents" (arXiv:2609.12742), tackles a practical problem for anyone maintaining a SKILL.md: most automatic skill-optimization methods tune the document against a generic benchmark, not the repository it actually lives in. The authors instead mine a repo's own merged pull requests, revert them to a frozen base commit, and score a candidate SKILL document by whether the same coding agent does measurably better with it than without it. Tested across three Kotlin repositories, GEPA-optimized skill documents lifted the agent's success score by 4.9 percentage points on average, while SkillOpt-optimized documents left performance essentially unchanged — just 0.1pp above the unoptimized seed. It's a concrete signal for teams treating SKILL.md as a productivity lever: the optimization method matters as much as writing the skill at all, and testing against your own repository's real history beats testing against someone else's benchmark.

Sources: arXiv:2609.12742 abstract, arXiv:2609.12742 full text

3. OpenClaw's densest release week yet ships four stable builds — while two new MCP server CVEs and a CISA-listed flaw keep security in the spotlight

OpenClaw's September 7–14 week was its most dense release cycle to date, shipping four stable builds (v2026.9.1 through v2026.9.4) that, among other changes, now require Node 24.16+ or Node 26.1+. The same week brought two new disclosures affecting bundled MCP servers: CVE-2026-87911, letting the PostgreSQL MCP server execute OS commands via COPY ... TO PROGRAM when running with superuser privileges even in "read-only" mode, and CVE-2026-85788, where SQL inline comments let attackers bypass the MySQL MCP server's read-only filtering. A third, unrelated MCP vulnerability, CVE-2026-59822, became the first MCP-specific flaw added to CISA's Known Exploited Vulnerabilities catalog. Separately, OpenAI's Agents API — its answer to Anthropic's Managed Agents, wrapping the Codex harness as a one-API-call service with nine sandbox partners — entered public beta the same week, underscoring how fast "run an agent as a hosted skill-driven service" is becoming table stakes across vendors.

Sources: OpenClaw Weekly, Sep 14 2026, OpenClaw releases

4. Salesforce formalizes its agent governance stack into a Trusted Enterprise AI Harness and a new AI Control Plane

On September 10, 2026, Salesforce introduced the Trusted Enterprise AI Harness, a composable architecture built on six capabilities — trusted context, agency, action, governance, security, and models — meant to give every agent a shared, policy-bound understanding of the customer and the business. Anchoring the harness is a new AI Control Plane, a single place for organizations to discover and register agents (Salesforce's own and third-party), set identity and policy, manage lifecycle, evaluate performance, observe behavior, and control cost across the stack. The announcement lands two weeks after Salesforce and Anthropic's Claudeforce sales-skills launch, and reframes that kind of skill-packaged agent as one tenant among many that now needs central registration and governance rather than a one-off integration. Broad rollout is pinned to early fiscal 2028 (beginning next February), with pricing and regional availability to follow closer to general availability — a reminder that, as with many "control plane" announcements in this space, the governance promise is currently ahead of the shipping product.

Sources: Salesforce: Trusted Enterprise AI Harness, SiliconANGLE coverage

5. Microsoft adds a "which governance tier does this agent need" skill to its open cat-agent-skills library

A pull request merged into Microsoft's open-source cat-agent-skills repository on September 11, 2026 adds the Enterprise Agent Governance Advisor, a platform-neutral, decision-support SKILL.md meant to help teams pick both an appropriate agent delivery approach and a proportionate governance tier for a given enterprise scenario. Unlike Microsoft's product-specific skill releases (SharePoint, Copilot Studio, Agent Builder), this one is deliberately generic — its authors note it contains no organization-specific policies, systems, or internal process details — so it can be dropped into Copilot Studio or any other Agent-Skills-compatible harness as a reusable governance checklist rather than a wired-up tool. It's a small but telling entry for this digest's theme: as skill libraries mature, "how do I decide whether to govern this" is itself becoming a packaged, reusable skill alongside the task-automation ones.

Sources: cat-agent-skills PR #320, CAT Agent Skills
