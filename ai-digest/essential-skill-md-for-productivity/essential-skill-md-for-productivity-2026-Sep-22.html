1. Plugin4Shell: a zero-click supply-chain flaw breaks "pinned" plugin/skill integrity across all four major coding agents

AIR Security disclosed Plugin4Shell, a zero-click, high-severity vulnerability affecting Claude Code, OpenAI Codex, GitHub Copilot, and Google's Gemini CLI: when these agents install a plugin or skill pinned to a specific reviewed commit hash, none of them actually verify that the checked-out working tree matches that hash, letting anyone who controls the plugin's source repository silently swap in malicious code without any click or re-approval from the user. This is the first confirmed bypass of the "pinning" safety mechanism that skill and plugin ecosystems lean on to make third-party capabilities trustworthy, directly undermining a core productivity promise of reusable, versioned skills. AIR says it built working exploits against all four agents back in May and disclosed to vendors in June; by the time the story broke on September 18–21, Anthropic had patched in Claude Code 2.1.179 and OpenAI in Codex 0.146.0, but GitHub had issued no fix for Copilot and Google was declining to patch Gemini CLI at all, pointing users instead to its Antigravity agent as Gemini CLI heads toward retirement. No CVE had been assigned as of publication, and none of the four vendors had issued a formal security advisory.

Sources: The Hacker News, AIR Security (original research), Cyber Security News, CryptoRank, Eastern Herald

2. OpenClaw ships v2026.9.5 with Plugin Hot Reload and Atomic Updates for safer skill/plugin rollouts

OpenClaw released v2026.9.5, its most operationally-focused update in weeks: Atomic Updates now stage and verify the next Gateway version against a private copy of a user's setup before switching over, rolling back automatically (short of database migrations) if verification fails, while Plugin Hot Reload lets admins or the CLI install or reload supported plugins without restarting the Gateway at all. For teams that treat OpenClaw as a personal or team skill-and-plugin runtime, this directly targets the reliability gap that has dogged skill and plugin distribution — prior weekly coverage flagged upgrade failures and migration deadlocks as recurring pain points. The release also expands GPT Live and adds conversation sharing and archiving; per the weekly ecosystem digest, the release cycle saw roughly 4,179 pull requests and 502 contributing accounts, though multiple users reported upgrade failures migrating from 2026.9.3/9.4.

Sources: MarkTechPost, Big Hat Group (weekly ecosystem digest), OpenClaw official release notes, Superpowerdaily

3. GraphSkillEvo: representing skills as graphs, not prose, beats the leading SkillOpt baseline

A new arXiv paper, GraphSkillEvo, argues that the unstructured natural-language SKILL.md format that has become the de facto standard is actually a bottleneck for automated skill improvement: because such skills lack explicit workflow structure and contain redundancy, the search space for optimizing them is too unconstrained to explore effectively. The authors instead represent each skill as a graph — nodes are execution steps with their guidance, edges are context-dependent transitions — and apply a population-based evolutionary algorithm with mutation and crossover operators built for that graph structure. Across five agent benchmarks, GraphSkillEvo beat the strong SkillOpt baseline by 4.01% average accuracy on GPT-5.4-nano and 1.76% on GPT-5.4, suggesting that as organizations accumulate large SKILL.md libraries, structuring the skill format itself — not just prompting better — may be the next lever for productivity gains. Code was released alongside the paper.

Sources: arXiv (abstract), arXiv (full text), Hugging Face Papers
