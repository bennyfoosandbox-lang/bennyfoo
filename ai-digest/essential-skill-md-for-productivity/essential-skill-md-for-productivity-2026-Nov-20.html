1. Google adds an Agent Registry skill and cuts its Gemini API skill from 272 lines to 106

On 19 Nov, Google's public skills repo added agent-platform-agent-registry. It is a 496-line SKILL.md with 2,738 lines in total once you count its references and scripts. It manages Google Cloud Agent Registry through gcloud agent-registry: agents, MCP servers, endpoints, bindings, AI applications, and skills with their revisions. It also covers automatic registration for Cloud Run and GKE, and a bundled annotate_gke.py script handles the GKE side. The skill runs read-only commands such as list and search straight away. For anything that changes state, it shows the exact command and waits for a yes. It also never runs the interactive gcloud auth login flows itself. The same day, a performance commit cut the gemini-api skill's SKILL.md from 272 lines to 106. The per-language quick starts moved to references/sdks.md, the skill now points agents to the exact line ranges they need, and SDK bugs that had caused repeated verification loops were fixed. Separately, Google's three Cloud Operator skills now work with one personal operator agent per Google Cloud organization, and they walk the user through creating that agent if it doesn't exist yet.

Sources: google/skills commit 5fb62c2 (agent-platform-agent-registry), google/skills commit dbabd35 (gemini-api token footprint), google/skills commit e96f207 (org-scoped Cloud Operator skills), agent-platform-agent-registry SKILL.md

2. awesome-copilot lists Postman, Outlook, DocSpring and Azure Observability plugins and adds a six-month re-review board

On 19 Nov, GitHub's awesome-copilot catalog approved four new external plugins, each pinned to an exact commit. Postman's plugin (0.3.0) can set up a repo's Postman configuration, mock an API before it's built, run collection and governance checks in CI, and publish API docs. Outlook Assistant (3.14.2) gives Copilot 22 Microsoft Graph tools for mail, calendar and contacts. It comes with a safety skill and a hook that asks before anything goes to other people, plus dry-run previews, a read-only mode, per-session send limits and recipient allowlists. DocSpring (1.10.2) bundles eight skills for filling PDF and Word templates and collecting e-signatures. Microsoft's azure-observability walks an agent through read-only troubleshooting of Azure web apps, APIs and Foundry agents, and it applies fixes only after they're approved. Late the same day, maintainers merged PR #6521, a board for the six-month re-review of every external plugin. It pulls in each listing's latest release, compares it with the pinned commit, and sorts plugins into Keep, Needs changes and Remove. Nothing is posted to GitHub until a maintainer saves a decision, and a reason is required for any change or removal.

Sources: PR #6515: add postman, PR #6514: add outlook-assistant, PR #6513: add docspring, PR #6521: external plugin re-review board, littlebearapps/outlook-assistant, DocSpring/skills, microsoft/azure-skills

3. Claude Code 2.1.329 says where a folder's hooks come from and fixes skills folders that went unnoticed

Claude Code 2.1.329 came out on npm at 18:40 UTC on 19 Nov, and its changelog followed at 22:14. When you trust a folder, the trust dialog now warns you and says where that folder's hooks are declared. Claude Desktop and other non-interactive hosts now show a warning in the conversation when hooks from managed settings fail to load. One fix matters for skill authors: a new skills, commands or agents folder was sometimes missed when --add-dir named the working directory, or when Claude Code started in the home folder. In Code Mode, a PreToolUse hook that errors no longer blocks a script's tool call. That matches how hooks behave outside Code Mode, and a hook that must block now needs "onFailure": "block". If you rely on a hook to refuse calls in Code Mode, check its settings. /code-review <pr> now reads the pull request with gh pr diff instead of sometimes reviewing the checked-out branch. Cloud sessions also retry plugins that failed to download at startup.

Sources: Claude Code CHANGELOG (2.1.329), Claude Code changelog, npm: @anthropic-ai/claude-code

4. Codex 0.171.0 bundles a create-statusline skill and keeps plugin skill rankings across version changes

OpenAI released Codex CLI 0.171.0 shortly before 01:00 UTC on 20 Nov, just after 19 Nov ended. It is the first release to include create-statusline (PR #62036), a bundled skill that shows you how to build, register and select a custom footer for the Codex CLI. It comes with a Python stdio MCP server to start from, which shows the thread's model and agent state. Two other skill changes are smaller. The plugin skill picker now keeps its ranking when a plugin's version changes (#61871). Cloud plugin and skill catalogs now refresh while each step is being prepared (#61429), so new skills show up without restarting. Plugin manifests now load only once a marketplace entry is selected, and cloud catalogs are reused across turns until something invalidates them. Both should make plugin-heavy sessions start faster. Subagent transcripts now appear next to the main conversation by default, and you can open them from activity links or the sidebar.

Sources: Codex rust-v0.171.0 release notes, PR #62036: create-statusline bundled skill, PR #61871: plugin skill picker ranking, npm: @openai/codex

5. OpenClaw beta installs agent templates, with their skill folders, from ClawHub

OpenClaw published 2026.11.10-beta.1 on npm at 15:09 UTC on 19 Nov. Its headline feature is agent templates you can install straight from a ClawHub package. A template is a CLAW.md manifest plus bundled skill folders, and the native trust flow checks those folders before they're used. Before this change, openclaw templates add @openclaw/... treated a package name as a local path and failed (PR #195707, merged 9 Nov). The CLI now resolves an exact published version and checks the package's identity and SHA-256 digest before it extracts anything. A --dry-run flag previews the result, and existing agent IDs and workspaces are never overwritten. Trust acknowledgement, plugin capabilities and consent to install dependencies are still asked for separately. Because ClawHub has had repeated malicious-skill campaigns, checking the digest and keeping those steps separate matters here. The stable 2026.11.6 release, which came out the same day, also keeps SecretRef-backed skill API keys as references instead of writing them out as plaintext (#190618).

Sources: OpenClaw v2026.11.10-beta.1 release, PR #195707: templates from ClawHub packages, OpenClaw v2026.11.6 release, npm: openclaw
