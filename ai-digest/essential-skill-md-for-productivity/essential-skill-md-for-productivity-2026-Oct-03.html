1. Claude Code 2.1.287 ships "Mods" — in-process plugins that Anthropic admits are not sandboxed

Anthropic published Claude Code 2.1.287 on 1 October with Claude Mods, a plugin type written in JavaScript or TypeScript that runs inside the Claude Code process and can watch, rewrite or take over events such as tool calls, submitted prompts and UI rendering. Unlike a SKILL.md, which is only text the model reads, a mod is executable code with the user's own permissions: Anthropic's docs say it can read files and environment variables (including API keys), start processes outside the sandbox, and approve tool calls an ask rule would have prompted for. Only the permission prompt itself is off-limits to mods. Mods are on by default but the stable npm tag still points at 2.1.285; `claude plugin validate` previews the events a mod hooks, and admins get an `allowManagedModsOnly` switch that disables user-installed mods while leaving a plugin's skills, commands and agents working.

Sources: MIXED, Pasquale Pillitteri, Streamline Feed

2. Security researchers: a mod can arrive as a plain skills folder, invisible to endpoint tools

Dash Security's analysis of Claude Mods finds that the riskiest load path is the one skills users already trust: a folder under ~/.claude/skills loads as a plugin with no install step, and the same folder inside a repo's .claude/skills loads once the workspace-trust dialog is accepted. Because the code runs inside the Claude Code process, endpoint security sees only a legitimate Claude process; the team built a proof-of-concept that swaps Bitcoin wallet addresses by rewriting what it passes to next(). Their advice for skill-heavy teams is concrete: grep plugin and skills folders for hooks.json files containing a "modules" key, treat any mod combining http.fetch with process.run as a download-and-execute risk, and use a managed plugin hooking plugin.register to refuse such mods centrally. The research dates from 25 September, so it is the pre-release warning for what shipped on 1 October.

Sources: Dash Security, MIXED

3. "A new form of malware": Security Journey exec demos a hidden-exfiltration skill, and a one-question defence

In a 2 October TechInformed interview, Security Journey's Michael Burch describes demonstrating to a ~300-person security group how easily a downloaded skill can turn hostile: he showed a customer-service triage skill that looked like a full workflow automation but carried a buried line telling the agent to silently copy every customer detail to another address. His point is that business users, not just developers, are now installing shared skills with no idea what the agent is allowed to do. The practical mitigation he offers is cheap: before activating any skill, ask an AI to break down everything it does and flag anything risky, and he urges companies to pair AI-adoption champions with security training instead of simply buying licences and hoping.

Sources: TechInformed

4. October "Agent Skills by the numbers": repos up 34%, but npm downloads fall 27%

The second monthly snapshot from the open skillsboard project shows agent-skills adoption still compounding in the open: repos tagged agent-skills grew from 20,783 to 27,832 (+33.9%), claude-skills repos reached 9,584 (+22.6%) and about 46,592 READMEs now print an `npx skills` install line (+25.1%). The paradox is that npm downloads for the matching packages fell 26.6% to roughly 28.1M for 31 Aug–29 Sep, with daily counts sliding from 1.3–2.2M to about 0.7M late in the month, and downloads per matching README dropping from 1,030 to 604. For anyone choosing which skills to trust, it suggests publication is outpacing real usage — more skills are being written than installed.

Sources: skillsboard PR #205

5. Hostinger Agents packages 150+ guided "Skills" for solopreneurs, with up to 50 saved custom skills

Hostinger's AI team for small-business owners treats skills as guided, stepwise tasks: pick Keyword Research under the SEO Consultant and the agent asks about your business and audience, then returns a prioritised keyword list. The 150+ skills are grouped by specialist — Business Advisor, SEO Consultant, Legal Advisor, Creative Writer, Customer Comms, Marketing Planner, Sales & Outreach — and the help centre page, updated 1 October, adds a Create skill option that saves reusable instructions (up to 50 per user), echoing the SKILL.md idea in a no-code product. Pricing starts at $6.99/month with 1,000 monthly credits, support requests stay free, and business-type skills consume credits by complexity — a sign skills are becoming a mainstream packaging unit well beyond coding agents.

Sources: Hostinger Help Center, Hostinger Agents
