1. Claude Code 2.1.292 adds a marketplace install flag and sub-agent effort levels, with a long list of /loop and plan-mode fixes

Claude Code 2.1.292 landed on 6 October, hours after the 2.1.291 patch that repaired two regressions (cloud sessions dropping permission-prompt answers, and the last messages of a session being lost on quit). The new release lets `claude plugin install` take a `--marketplace <source>` flag so a plugin and its marketplace can be added in one step, and lets agents launch sub-agents at a chosen effort level. The fixes are the part that matters for people who automate recurring work: background sessions no longer lose `/loop` state on restart, scheduled tasks created after `/resume`, `/branch` or `/clear` now fire, plan mode is restored on `claude --resume`, and routine runs stop showing as running for hours. Several permission fixes also close gaps where hook approvals and auto mode could skip prompts for UNC network paths.

Sources: Claude Code v2.1.292 release notes, Claude Code v2.1.291 release notes, Claude Code releases

2. Copilot CLI 1.0.93 pre-releases apply MCP config changes mid-session and add enterprise domain limits

GitHub's Copilot CLI shipped three 1.0.93 pre-releases between 5 and 7 October. The newest, 1.0.93-3, makes MCP server configuration changes take effect between turns without restarting the session, which removes a common friction when tuning the tools that skills depend on. Build 1.0.93-2 adds an enterprise `permissions.limitTo` setting to confine network requests to managed domains, moves the model picker toward GPT-6.1 Sol, GPT-6 Astra/Luna and Claude 5.5, and now reads user settings only from `~/.copilot/settings.json`, ignoring keys left in the old `config.json`. Teams that share a standard skills setup should check that migration before the stable release.

Sources: Copilot CLI v1.0.93-3, Copilot CLI v1.0.93-2, Copilot CLI releases

3. Gemini CLI 0.63.0 separates missing MCP config from broken JSON and enables autonomous plan execution in non-interactive mode

Google's Gemini CLI promoted 0.63.0 on 6 October, with eight contributors and about a dozen fixes. Two changes touch agent workflows directly: errors now distinguish an MCP server that simply is not enabled from one whose configuration JSON is malformed, and non-interactive mode can execute an approved plan autonomously, which suits scripted or scheduled runs. Stability work includes ending infinite authentication loops caused by file contention and keyring problems, bounding tool-output size and memory in long agent loops, and cleaning up temp directories after background shell commands. A 0.64.0 preview the same day adds a settings migration to a V2 format with atomic state persistence and corruption recovery.

Sources: Gemini CLI v0.63.0 release notes, Gemini CLI releases

4. OpenClaw ships 2026.9.8 stable, a 2026.10.1 beta and an 8.35 LTS-style build with GPT-6.1 Sol support

OpenClaw, the open agent runtime many SKILL.md packs target, put out three builds in four days. Version 2026.9.8 (3 October) is a reliability-focused stable release covering 58 commits, 43 pull requests and 21 contributors. The 2026.8.35 build (2 October) is positioned as an extended-stable line and adds GPT-6.1 Sol support across OpenAI routing, discovery and reasoning, while preserving plugin settings and preventing duplicate Gateways during maintenance. The 2026.10.1-beta.1 build (5 October) keeps usage data across registry changes, delivers worker attachments from remote workspaces and fixes session turns stalling on queued cancellations. Detailed notes live in OpenClaw's separate changelog files, so this entry reflects the release headlines only.

Sources: OpenClaw releases, OpenClaw v2026.9.8
