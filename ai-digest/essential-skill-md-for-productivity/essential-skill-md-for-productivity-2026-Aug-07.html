1. Cloudflare open-sources Cloudflare OS, putting a shared skills library at the center of an enterprise agent workspace

On August 5, as the centerpiece of its second "Agents Week," Cloudflare open-sourced Cloudflare OS — a self-hostable, browser-based agent workspace built from three layers: an agent workspace grounded in a company's curated context and skills, a zero-trust "Gatekeepers" layer that sits between agents and systems of record so agents never hold raw credentials, and a layer of personal, modifiable micro-apps that can turn a chat into a document, workflow, or small full-stack app. The skills piece is the most on-topic detail: an IT team curates a shared library of reusable prompt procedures so that when one employee finds a better way to run a recurring task, every other employee's agent picks up the same approach automatically, instead of each person re-explaining the workflow from scratch. Cloudflare has run an internal version since May and is launching publicly with two implementation partners, Presidio and Happy Cog, for enterprises that want deployment help. It's a strong data point for this digest's throughline: a shared, org-wide skill library is becoming first-class enterprise agent infrastructure, not just a convention inside a single coding tool.

Sources: Cloudflare Blog, Cloudflare press release, SiliconANGLE, Decrypt

2. Anthropic ships inference hooks, letting Claude Enterprise vet every skill and tool response before the model sees it

Anthropic launched inference hooks in beta for Claude Enterprise on August 5 — a feature that routes every prompt, and every tool or skill response, through a customer's own security server for an allow-or-deny verdict before it reaches Claude, across chat, Claude Code, and Cowork. Verdicts are binary (allow or deny, never rewrite or redact) over a published webhook schema built to plug into existing DLP infrastructure such as Netskope, Palo Alto Networks, Proofpoint, or Zscaler, alongside three other use cases: real-time transcript archival, prompt telemetry, and custom policy engines like model allowlists. What makes this squarely relevant here: when Claude calls a tool through MCP, a skill, or a plugin, the tool's response is checked by the hook before it ever reaches the model — closing a gap this digest has flagged repeatedly, where a compromised or malicious skill's output was otherwise trusted implicitly once it returned to the conversation. It's Anthropic's most direct answer yet to enterprise concerns about ungoverned skill execution, landing the same week as the governance moves from Cloudflare above and Cequence below.

Sources: Claude Blog, Unite.AI, Claude Platform Docs

3. Mitiga finds 1,230+ leaked API keys hiding in AI instruction files, launches a free Skillgate scanner

Mitiga Labs published research on "PromptLogger"-style attacks — malicious instructions hidden inside AI instruction files such as SKILL.md, CLAUDE.md, AGENTS.md, hooks, and MCP server configs that quietly exfiltrate prompts and responses to an attacker, in some cases by getting an agent to silently run a curl command or override a base-URL environment variable to reroute model traffic through a third-party proxy. The underlying study scanned more than 50,000 AI instruction files across 7,000-plus public repositories between April and June, and turned up upward of 1,230 hardcoded API keys and tokens in agent and MCP configuration files, plus real cases of attacker-controlled ANTHROPIC_BASE_URL overrides. Off the back of it, Mitiga launched Skillgate, a free public scanner — unrelated to the academic "SkillGate" paper this digest covered on July 30 — that takes a GitHub repo URL, pins the scan to a specific commit, and combines signature and AST analysis with an LLM-as-judge step to score files 0-100 and flag them Clean, Risky, Suspicious, or Dangerous. It's another entry in this digest's running theme: static, pre-install scanning keeps surfacing new categories of skill-adjacent credential and exfiltration risk faster than the ecosystem can standardize defenses against them.

Sources: CSO Online, Mitiga Labs research, Mitiga press release, Skillgate (free scanner)

4. Ambition packages sales-management rituals into a composable Agent Skills library

Revenue-performance platform Ambition launched Agent Skills on August 5: a library of out-of-the-box, composable AI workflows that turn recurring sales-management rituals — coaching prep, pipeline inspection, forecast reviews, performance check-ins, and QBR analysis — into skills any member of a revenue team can run instead of building a workflow from scratch each time. Individual skills include Coaching Prep, which assembles a complete pre-read before a 1:1; a Weekly Manager Brief that surfaces the key actions a manager should take that week; and a Rep Goal Builder that generates a measurable, individualized goal per rep, with each skill configurable, permission-aware, and grounded in a company's own data through Ambition's "Performance Graph." Ops teams can adjust data inputs, ground analysis in uploaded documentation via "Procedures," and schedule skills to run on a recurring cadence, shifting a manager's job from building the spreadsheet to just having the conversation. It's a concrete example of the pattern this digest tracks most closely: a specific business function — here, front-line sales management — getting its own purpose-built, reusable skill library rather than ad hoc prompting.

Sources: PR Newswire, AOL, The AI Journal

5. Cequence adds a Skill Registry to AI Gateway, closing its "Agentic Zero Trust" ring around MCP, APIs, and LLMs

Cequence Security shipped four new AI Gateway capabilities — AI Discovery, API Registry, LLM Registry, and Skill Registry — alongside upgraded Agent Personas that bind an agent's job description directly to its model, tools, data access, and guardrails, all enforced automatically through policy. The new Skill Registry gives security and platform teams a curated, once-vetted set of skills that can be reused across every agent that needs a given capability, rather than each team or agent pulling its own unreviewed copy from a public marketplace. Combined with the other three registries, Cequence says it's now the first platform to close the ring around every channel an agent uses to reach the outside world — MCP governs tool discovery and invocation, the LLM Registry governs every model call, and the API Registry governs calls to backend services and data — letting a business user stand up a properly governed agent without touching AI Gateway directly or needing technical expertise. It's a governance-layer complement to the scanner-style tools this digest covers most often (Skillgate above, SkillSpector, and others): rather than judging a skill's content before install, it controls which vetted skills an agent is allowed to draw from at all.

Sources: Cequence Security, Security MEA, Channel Post MEA
