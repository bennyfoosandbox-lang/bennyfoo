1. Salesforce and Anthropic launch Claudeforce, putting a 37-skill sales agent inside Claude

On August 26, Salesforce and Anthropic announced Claudeforce, an expanded strategic partnership that ships "Salesforce in Claude" — a plugin built around 37 prebuilt sales skills covering meeting prep, deal-health review, and pipeline inspection. Sellers can reason over live CRM data and take governed action — updating pipeline, drafting account plans — directly from Claude, with Salesforce's new AIforce harness routing every action through the same business rules and permissions as the core platform, so admins connect once and every seller gets access without per-user setup. The deal also makes Claude the default reasoning model across Agentforce, Slack, and Slackbot (already driving 8.1M annualized hours of internal productivity gains at Salesforce), making this one of the largest enterprise deployments yet of the Agent Skills format outside Anthropic's own products. Salesforce in Claude is live for pilot customers now, with open beta planned for September 2026 and more prebuilt skills due later in the year.

Sources: Salesforce investor press release, Anthropic announcement, CNBC, VentureBeat

2. Claude Code v2.1.246 and v2.1.247 tighten Bash safety and fix skill/plugin bugs

Anthropic shipped two Claude Code releases back to back on August 25 and 26. v2.1.246 adds an Auto Mode tab to /permissions and fixes several skills/plugins bugs, including /reload-plugins under-reporting skill counts for plugins that define skills under skills/*/SKILL.md, doubled plugin-prefixed skill names, and plugin installs failing on a UTF-8 BOM in plugin.json. v2.1.247 follows with a startup warning for Bash allow-rules that use a wildcard before the subcommand (which can silently also match inserted options), a new SendFeedback tool for drafting issue reports via /feedback, and an updated claude-api skill with Admin API coverage for organization members, workload identity federation, and CMEK. Together the two releases are a reminder that as SKILL.md tooling matures, a growing share of each release cycle goes to bug fixes in skill discovery and plugin packaging rather than new capability.

Sources: Claude Code changelog, DevelopersIO summary

3. Socotra becomes the first insurance core platform to publish its own Agent Skills

Socotra announced the free public release of "Socotra Skills" on August 26 — reusable, open-source SKILL.md instructions that teach Claude Code, Claude Cowork, Codex, Cursor, and other agents how to build and operate on Socotra's insurance core without re-explaining its APIs, MCP server, and configuration model on every session. The skills let insurers price, issue, and underwrite quotes, manage policy transactions and billing, and model what-if pricing across a portfolio, and because they're open source, insurers can customize them to enforce their own product standards or reconcile against filings. Socotra joins Atlassian, Databricks, GitHub, Google, Microsoft, OpenAI, and Stripe as vendors publishing official Agent Skills, but says it is the first insurance-specific core system to do so — a sign the SKILL.md pattern is moving from horizontal dev tools into vertical, regulated-industry software.

Sources: BusinessWire release, Socotra Skills on GitHub

4. Camunda's 11 official Agent Skills turn weeks of BPMN work into days, engineer says

Camunda published a detailed first-hand account on August 26 of building a full insurance policy-change process using its own camunda/skills library — 11 official Agent Skills covering BPMN modeling, DMN decision tables, FEEL expressions, forms, connectors, and job workers, compatible with Claude Code, Cursor, GitHub Copilot, Codex, and Gemini CLI. The author reports the skills turned a task that previously required constantly re-explaining BPMN/DMN/FEEL fundamentals into one where the agent's first draft was "close enough to correct" that the remaining time went to review rather than rebuilding, freeing up enough time to also ship a custom portal, live-metrics dashboard, and chatbot on top of the same process. It's a concrete, single-vendor data point for a recurring claim in this space — that domain-scoped, well-written skills compound productivity gains — backed by real Optimize dashboard metrics rather than a vendor benchmark.

Sources: Camunda blog, camunda/skills on GitHub

5. Microsoft's Agent Package Manager ships strict Agent Plugins 1.0 bundling and a breaking skills-declaration change

Microsoft's open-source Agent Package Manager (apm) shipped v0.29.0 on August 26, adding apm pack --format agent-plugin to produce strict Agent Plugins 1.0 bundles alongside its existing Claude-compatible default, plus --trust-bin/--no-trust-bin flags that make consent for marketplace plugin executables explicit at install time. The release also carries a breaking change: a plugin's skills declarations now exclusively control which skills get deployed, so teams that relied on omitting the key for automatic discovery need to declare their intended skills explicitly going forward. Windows users also get Authenticode-signed release binaries to stop Windows Defender false positives — a release focused squarely on making skill and plugin packaging safer to distribute across the multi-agent, multi-registry ecosystem (Copilot, Claude Code, Cursor, OpenCode, Codex, Gemini) that apm sits in front of.

Sources: apm CHANGELOG, microsoft/apm on GitHub
