1. Claude Code's week of seven releases: skills now re-sent after compaction, /reload-skills trimmed

A hands-on roundup of Claude Code releases 2.1.304 to 2.1.310 (19–23 October) tested on 2.1.310 lists the changes that touch day-to-day skill work. After context compaction Claude now gets the skill list again, and /reload-skills sends only new or changed skills instead of the whole set, which cuts wasted tokens for people with large skill libraries. Around that, /auto-mode-setup reads your project and recent sessions to teach auto mode your environment, and /usage warnings became one-line fixes applied with the f key. The author counts 169 bug fixes across the week and flags two script-breaking changes: sed -i now gets a normal Bash prompt, and claude ultrareview needs --trust-workspace in CI.

Sources: AI Parabellum

2. Plane ships five workspace skills, with a personal-vs-workspace split for scheduled agents

Plane's product blog walks through five ready-made skills for its AI agents: customer-feedback-synthesizer, acceptance-criteria-writer, security-reviewer, release-readiness-checklist and deployment-runbook-writer. The useful design point is scope: personal skills are visible only to their author, while workspace skills are created by admins and shared, and agents that run on schedules or on work-item events must use workspace skills so their instructions survive unattended runs. Users invoke a skill by typing / in Plane AI chat or attach saved skills when configuring an agent. It is another sign that the SKILL.md pattern is moving from coding agents into project-management products.

Sources: Plane blog

3. Academic Research Skills reaches v3.23.2 with stricter integrity checks

The Imbad0202 academic-research-skills repository, a Claude Code skill suite that covers research, writing, review, revision and finalization, shipped v3.23.2 on 24 October. The suite is built around Deep Research, Academic Paper, Academic Paper Reviewer, Academic Pipeline and SR-Screener skills. This release makes integrity checks read only the cited version of a source, makes Stage 2.5 always run, and repairs adapter, announcement and Windows issues. It is licensed CC BY-NC 4.0, so it suits personal and academic workflows rather than commercial reuse, and it shows how multi-stage pipelines are being packaged as versioned skills.

Sources: GitHub: Imbad0202/academic-research-skills

4. How-To Geek: 84.6K tokens burned before the first word of a chat

A How-To Geek piece published on 25 October argues that before you trim prompts to save tokens, you should check what each chat costs before you type anything. The author's screenshot shows the Claude desktop app at 84.6K of 1M tokens used after just saying hi, and the article's captions point to a skills menu listing 25 skills synced from claude.ai and a Claude Code context view at 46.7K tokens with MCP tools loaded. Only the headline, summary and image captions were readable to us (the full text sits behind a bot check), so the exact fix is not verified here. The takeaway for skill users is that the always-loaded skill and tool descriptions are a real, measurable startup cost worth auditing.

Sources: How-To Geek

5. A "Blast Radius Analyzer" skill makes Claude trace dependencies before editing

A Medium post from 25 October describes seven Claude Code skills meant to make an agent think before it codes, and the first one, Blast Radius Analyzer, is the one we could read in full. It makes Claude trace callers, API consumers, database queries and background jobs that might depend on existing behavior before touching the implementation, and it separates dependencies it can verify from risks it only suspects. The rest of the list is paywalled, so we cannot vouch for the other six. It is a community example of the pre-change analysis skill pattern, and a reminder that a skill's value lies in the discipline it enforces rather than the code it generates.

Sources: Medium (Infinity)
