1. VS Code's Copilot agents window learns to migrate old prompt files into skills — and run any harness in its own worktree

GitHub's July 2026 VS Code changelog (v1.127–v1.131) ships a one-click way to turn existing prompt files into reusable SKILL.md-style skills from the AI Customizations overview, closing a common on-ramp gap for teams that built up ad-hoc prompt libraries before skills existed. The same release lets you start Copilot, Claude, or Codex sessions in an isolated Git worktree from the redesigned Agents window, so multiple agent sessions — including skill-driven ones — no longer stomp on the same working copy. It also adds subagent tracking (model, elapsed time, active tool call) and multi-chat sessions for Claude, both aimed at making multi-agent, skill-heavy workflows easier to supervise. None of this changes the SKILL.md spec itself, but it lowers the friction of actually adopting skills inside the most-used Copilot surface.

Sources: GitHub Changelog: Copilot in VS Code, July 2026 releases

2. Nubank built "Skill Vector" after scanning 2,000+ AI skills turned up 1,500+ risks

At an AI Engineer conference talk, Nubank product security manager Lucas Palma described how the fintech's security team screened more than 2,000 AI agent skills before letting developers install them, and found over 1,500 flagged risks in the process — everything a skill can do once loaded, from silent data exfiltration to scope creep beyond its stated purpose. Rather than treat skills as trusted config, Nubank built an internal tool called Skill Vector to vet and continuously re-check skills the way a software supply chain would vet a dependency, then exposed a curated, pre-vetted catalog internally so 122+ million customers' worth of engineering org doesn't each have to repeat the audit. It's one of the more concrete "essential productivity skill" governance case studies to surface this year: the productivity gain from skills is real, but only after the vetting cost is paid once, centrally.

Sources: BigGo: "We Vetted 2000 AI Skills Before They Reached Developers" — Lucas Palma, Nubank, StartupHub.ai: Nubank Vetted 2000 AI Skills for Developer Use

3. Creator David Ondrej open-sources his personal SKILL.md library

Prominent AI creator David Ondrej released his personal collection of agent skills as a free, open-source GitHub repository (installable with a single `npx skills add davidondrej/skills` command), covering agent orchestration, skill authoring, research and web capabilities, and day-to-day ops/setup workflows. Each skill follows the standard SKILL.md-plus-scripts layout and is meant to be dropped straight into Claude Code, Codex, or any other spec-compliant harness. It's a small release next to enterprise skill marketplaces, but it's exactly the kind of individually-curated, battle-tested skill pack this digest has repeatedly found outperforms unvetted marketplace sprawl for building a personal "essential skills" starter set.

Sources: Build Fast with AI: AI News Today, July 29 2026, GitHub: davidondrej/skills
