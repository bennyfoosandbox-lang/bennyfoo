1. Apple makes SKILL.md the way apps teach Siri AI multi-step tasks

Apple's Siri AI Developer Preview, released on 3 November with the iOS, iPadOS, macOS and visionOS 27.3 betas, lets any app expose custom actions to Siri and describe how to combine them in a SKILL.md file. Apple's documentation calls these app skills a subset of the Agent Skills format: a folder per skill with a name (1 to 64 characters), a description of up to 1,024 characters that Siri reads first, and a body capped at 10,000 characters that is loaded only once the skill matches. Apple says skills are advice, not a program, so they cannot enforce deterministic behavior, and it added a Siri Evaluations framework so developers can script conversations and re-run them. Integrations can't reach App Store customers until spring, and iPhone users in the EU are excluded for now. This item is from 3 November and is included because it was not yet covered here.

Sources: Apple Developer: Orchestrating complex actions with app skills, PPC Land: Apple opens Siri AI to all developers

2. Zep Agent Skills compiles verified agent runs into SKILL.md procedures

Zep launched Agent Skills on 5 November, a hosted service that records agent task attempts, keeps only runs whose success was confirmed by something other than the agent, and compiles them into versioned SKILL.md procedures. A second model checks each claim against recorded events, and security scans gate admission before a new version goes live. In Zep's paper, skills compiled from Claude Opus 5.5 traces lifted smaller models by up to 18.8 points across 26 configurations and cut tokens per completed task by up to about 45% on a banking benchmark. On EnterpriseOps-Gym, DeepSeek V4.1 Flash with skills scored 58.3% against 52.8% for Opus 5.5 at maximum effort without them. The caveats are that these are the vendor's own benchmarks, gains are small on tasks a model already handles, and a task no agent has solved yet gets no skill. It is free for 60 days.

Sources: Zep: Announcing Zep Agent Skills, arXiv: Learning by Doing: Compiling and Curating Agent Skills from Verified Traces

3. Google evolves a SKILL.md with AlphaEvolve and finds generic advice adds little

A 5 November Google Cloud post describes treating a skill's text as the program: AlphaEvolve rewrites the description and body, Harbor runs a real coding agent on Terminal-Bench 2.0 tasks, and the best-scoring version is checked on tasks the search never saw. Google's hand-written baseline skill made no measurable difference, while a skill that supplied knowledge the agent lacked added 33 points on dev tasks. AlphaEvolve's winner centred on the most common failure, running out of time: about a third of trials hit their time limit, so it tells the agent to write a working baseline early and stop the moment checks pass. The loop gave roughly a 5% improvement after a few iterations, the search stalled after about 10 hours, and the authors warn about slow model windows and log storage. The practical lesson for anyone writing skills is to encode specifics and measured failure modes rather than general best practice.

Sources: Google Cloud Blog: Building an agent skill optimizer with AlphaEvolve and Harbor

4. Sophos pairs a deobfuscator with small LLMs to catch malicious skills

Sophos AI previewed on 6 November a BSides Sydney talk (given 7 November) on detecting agent skills whose code disagrees with their SKILL.md description, such as a skill that claims to summarize CSVs but reads credentials. Its pipeline decodes obfuscation deterministically without running the skill, writes a facts-only summary, and lets a small LLM judge whether the behavior fits the declared purpose. In the researcher's tests, Cisco Skill Scanner and NVIDIA SkillSpector in static mode stayed precise but missed some obfuscated malicious skills, a smallest model failed on raw obfuscated code but matched the stronger scanner once given decoded evidence, and a distilled 4B Qwen3 student beat both scanners on a synthetic benchmark. Sophos notes the benchmark is synthetic and full results are still to come. For productivity users, the point is that a skill's description is not evidence of what its bundled scripts do.

Sources: Sophos: Killing ill-willed skills

5. LinearB ships an "effort" skill that scales a coding agent's work to the risk of the change

LinearB launched its Agentic Studio on 2 November with a first agent skill, now in early access, that matches a coding agent's effort to the task. It weighs a change's business relevance, complexity and risk using rework rates, recent incidents and ownership history, so low-risk edits use fewer tokens while risky or high-priority ones get more careful, tested work. LinearB says the skill works with any coding agent and lets leaders see how often agents were routed to low, medium and high effort, with review, merge governance and token-cost skills planned. It cites its own benchmarks of 2.7 million pull requests: heavy AI users merged 96% more pull requests per week, and token spend at the 90th percentile reached $35.20 per developer per coding day. The TNW piece is a contributed article, so the claims are LinearB's own.

Sources: The Next Web (contributed): LinearB launches Agentic Studio, SiliconANGLE: LinearB Agentic Studio
