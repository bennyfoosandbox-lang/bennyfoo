1. GitHub takes Copilot code review's agent skills and MCP support to general availability

GitHub moved Copilot code review's agent-skills and MCP support out of public preview and into general availability on July 29 for all Pro, Pro+, Business, and Enterprise users. Teams can now drop a SKILL.md file under .github/skills so Copilot's automated reviews enforce a repository's own conventions and internal tooling, while read-only MCP connections pull live context from issue trackers, documentation, and service catalogs into every review. A new attribution tag marks which review comments were generated using a skill or an MCP server, so reviewers can see exactly why a suggestion appeared. It is the clearest sign yet that SKILL.md is becoming a first-class extension point for automated code review, not just for interactive coding agents.

Sources: GitHub Changelog

2. StepSecurity ships fleet-wide inventory for AI agent skills after showing 3 lines of markdown can steal SSH keys

StepSecurity's Dev Machine Guard now inventories every AI agent skill installed across a company's developer machines, tracking what arrived via npx skills add, a git clone, or a zip file passed between teammates. The announcement makes the stakes concrete: StepSecurity's own researchers demonstrated that three lines of markdown inside a SKILL.md file were enough to exfiltrate SSH keys, and skills routinely land with no procurement step, review gate, or installation record at all. The new inventory specifically flags skills that ship executable scripts rather than plain instructions, giving security teams their first fleet-wide view into an attack surface that mostly evades governance today. It lands in the same week as a near-identical pitch from Mondoo (below), suggesting skill-inventory tooling is becoming its own enterprise security category.

Sources: StepSecurity Blog

3. Mondoo expands vulnerability management to cover "Shadow AI" skills, agents, and MCP servers

Mondoo announced a major expansion of its agentic vulnerability-management platform to build an automatic, enterprise-wide AI Bill of Materials: an inventory of every installed AI agent, loaded skill, configured MCP server, and model running on employee endpoints. The company argues the workstation — not the cloud — is now the real AI control plane, since agents there execute shell commands and hold credentials with little oversight; its earlier free AI Skill Check tool already found unsanctioned skill installs running rampant. The new release adds policy enforcement and remediation through tools enterprises already run, like Microsoft Intune and CrowdStrike Falcon, so security teams can disable a risky skill or remove an unapproved agent without deploying new endpoint software. For any team calling a skill set "essential," this is the emerging toolchain for proving that claim rather than just asserting it.

Sources: GlobeNewswire via Manila Times

4. SkillGate paper cuts malicious-skill screening cost 77% while beating existing scanners 5–6x

Researchers Rui Yang, Michael Fu, Kla Tantithamthavorn, Chetan Arora, and Joey Chua published SkillGate, a runtime security gateway meant to catch malicious SKILL.md files before a coding agent installs them, addressing what the paper calls a supply-chain surface with "no systematic toolchain defense." Its hybrid pipeline runs a cheap regex prefilter first and sends the LLM judge only the flagged snippet rather than the whole file, cutting LLM input tokens by 77% versus full-file screening while still hitting an F1 of 0.817 and a false-positive rate of 1.13% on the 1,650-skill SkillsBench benchmark (9.1% malicious). Its threshold-independent AUPRC of 0.830 beats the two existing tools it was benchmarked against by 5–6x, a meaningful jump given how many prior scanners have been shown to miss obfuscated payloads. It is a direct academic answer to the same problem StepSecurity and Mondoo are now selling commercial tooling against.

Sources: arXiv:2607.25619, PDF

5. HANDBOOK.md benchmark: even the best agents follow a corporate policy document only 36% of the time

Surge AI released HANDBOOK.md, a benchmark that drops an agent into a mocked company environment with files, tools, and a dense corporate handbook of up to 124 pages, then simply asks it to follow the rules. Across 65 company environments and 824 deterministic acceptance criteria, the best current model configuration passes only 36.2% of trials, with most frontier systems below 25%; the dominant failure mode is a policy getting silently overridden by whatever the user happens to ask for in the moment. It's the same failure mode that makes lean, narrowly-scoped SKILL.md files outperform sprawling ones — the more an instruction document reads like a wall of text instead of small, on-demand-loaded guidance, the less reliably an agent obeys it deep into a task. The benchmark gives the "lean file, one job" school of skill design its first hard number to point to.

Sources: arXiv:2607.25398, Surge AI Blog
