1. Anthropic donates Agent Skills to the Agentic AI Foundation, citing 1 million skills and nearly 280 million installs

On 22 October Anthropic said it is handing the SKILL.md standard to the Agentic AI Foundation under the Linux Foundation, the same home MCP moved to in December 2025. The transfer covers the Agent Skills name and logo, the GitHub organisation and the agentskills.io domain, and Anthropic says people can keep using or contributing to the format without joining the foundation. It reports more than 70 platforms supporting skills, including ChatGPT, Cursor, GitHub Copilot and VS Code, though those adoption numbers are its own and not independently counted. Engineers from Anthropic, Google, OpenAI and others will maintain it as individuals, with David Soria Parra and Mahesh Murag as lead maintainers, and the proposed roadmap starts with versioned releases, a formal proposal process and security guidance for people who write and install skills. For anyone building a personal skills library, the practical takeaway is that the format you write today now has neutral governance rather than a single vendor behind it.

Sources: Anthropic, MIXED, FourWeekMBA, Blockchain.News, Simon Willison

2. VirusTotal: 62% of the malicious skills it found contain no malicious code, only plain-language instructions

In Part III of its From Automation to Infection series, VirusTotal analysed 35,878 agent skills submitted to its service and flagged 6,637 as malicious, roughly 18.5% of that sample. Its central finding is that 62% of those malicious skills carry no malicious code at all, because the payload is written as ordinary instructions in the skill documentation that the agent then follows. That matters because a scanner or reviewer looking for scripts and suspicious binaries will pass them. The sample is only skills submitted to VirusTotal, so it does not describe the million published skills, but it is a useful warning to read the SKILL.md prose of any skill before installing it.

Sources: VirusTotal Blog, FourWeekMBA

3. Itential Builder Skills 2.0 ships 17 skills that run unchanged in five coding agents

Itential released version 2.0 of its Builder Skills, an open-source repo of 17 skills (eight delivery skills and nine platform skills) for network and infrastructure automation work. One repository now serves Claude Code, Codex CLI, GitHub Copilot CLI, GitHub Copilot in VS Code and Cursor, each through its own install path such as a plugin marketplace add or the gh skill install command. It is a clear example of the portability the open SKILL.md format promises: one folder of instructions maintained once, installed in whichever agent a team already uses.

Sources: Itential

4. Adyen open-sources Agent Marketplace, a single-binary CLI for sharing skills, commands, hooks and MCP servers across agents

Adyen released Agent Marketplace on 22 October, an open-source command-line tool it built to share agent resources across teams, repositories and tools. It handles skills, commands, subagents, hooks, MCP servers and collections, and works with Claude Code, Codex, Cursor, Devin CLI, Factory Droid, Gemini CLI, Opencode and Windsurf. It ships as one binary for macOS and Linux with no runtime dependencies and is driven by init, install and sync commands against a registry URL. For teams, it is a way to keep one vetted set of skills in sync rather than having each developer copy folders by hand.

Sources: Adyen

5. AWS publishes an official Agent Toolkit bundling MCP servers and skills for six coding agents

AWS pushed an official Agent Toolkit for AWS repository that packages its MCP server with skills covering service selection, CDK and CloudFormation, serverless, containers, observability, billing, Bedrock and AgentCore agent building, data analytics, incident investigation and security scanning. It supports Claude Code, Codex, Cursor, Devin, Kiro and others, with installs through the AWS CLI, plugin marketplaces or npx skills add. The repository showed no tagged releases when checked, so treat it as early, but having a cloud vendor maintain the skills rather than the community is a useful signal for anyone who works on AWS day to day.

Sources: GitHub: aws/agent-toolkit-for-aws
