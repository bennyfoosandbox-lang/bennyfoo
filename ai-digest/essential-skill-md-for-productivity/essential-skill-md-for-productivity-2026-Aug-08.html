1. OpenAI, AWS, Microsoft, Cursor and Vercel unify agent extensions under an Agent Plugins 1.0 standard — Google joins, Anthropic notably doesn't

On August 6, OpenAI, AWS, Cursor, GitHub, Microsoft and Vercel published Agent Plugins 1.0.0, an open, vendor-neutral packaging standard that bundles an Agent Skill (a SKILL.md-based procedure) together with its MCP server configuration into a single distributable, plugin.json-manifested directory — with Google joining the Technical Steering Committee shortly after launch. The pitch, made explicitly in the spec's own framing, mirrors how JavaScript converged on package.json: instead of every agent client (ChatGPT, Codex, Cursor, GitHub Copilot, Kiro, VS Code) needing its own manifest, folder layout and install flow for the same skill, a plugin built once now installs unmodified everywhere a compatible client discovers it. AWS's Agent Toolkit, Vercel's skills.sh/skills CLI, and Kiro Powers have already shipped native support. Early technical reaction flags real gaps worth watching before trusting these bundles at scale: v1.0.0 is a self-described "working draft" that standardizes packaging only — it defines no portable credential mechanism (authorization stays entirely client-managed), no marketplace, install, or sandbox-isolation protocol, and ships without Anthropic among the founding partners despite Agent Skills itself originating from Anthropic's SKILL.md format.

Sources: 9to5Mac, AWS Open Source Blog, Vercel Blog, Google Developers Blog, Agentic AI Foundation, Agent Plugins spec (GitHub)

2. Salesforce's Agentic Enterprise Index: skills per agent tripled from 2 to 6 in a year, and it now takes 1.9 days to stand up an agent

Salesforce published the second edition of its Agentic Enterprise Index, aggregating real usage data from the Agentforce platform across February 2025 to April 2026. The average number of distinct skills a single agent can act on rose from 2 at the start of 2025 to 6 by the report's cutoff, with that skill set stretching by up to 350% during seasonal demand spikes in sectors like retail and financial services. Over the same window the average number of activated agents per business nearly tripled, from 5 in February 2025 to 13 by April 2026 (a 7% compound monthly growth rate), while the average time to stand up a new agent fell 53%, to 1.9 days. The report also documents a "tale of two rollouts": consumer-facing sectors favor many narrow, high-volume single-skill agents, while regulated, operationally complex sectors like manufacturing and the public sector favor fewer, more versatile multi-skill agents. It's a useful quantitative counterpart to this digest's usual coverage of individual skill-library launches — real evidence that "more skills per agent" and "faster time-to-agent" are the productivity metrics actually moving inside large deployments.

Sources: Salesforce Newsroom, CIO.com, Futurum Group

3. "Field Aware Agent Skill Retrieval" shows skill files retrieve better when their fields aren't flattened into one blob

Researchers from UC Riverside and Nokia published "Field Aware Agent Skill Retrieval" on August 3, addressing a problem this digest has tracked for months as skill libraries balloon past a million entries: most retrieval systems flatten a skill's name, description and body into one document before embedding it, discarding the fact that a skill file is naturally a multi-field object where each field signals something different about when and how to use it. The authors instead keep each field separate, compute sparse and dense similarity scores per field, and combine them with either uniform weights or a small learned MLP — producing a field-aware, tensorized representation of the whole skill bank instead of one flat index. Tested on two skill-retrieval benchmarks, SkillRet and SRA-Bench, preserving field structure this way measurably improves hybrid retrieval over the flat-document baseline most production skill search still uses today. It's a small but concrete data point in the "skill bloat is the new context tax" thread this digest first flagged on July 21: as libraries scale into the millions, how an agent finds the right skill is becoming its own research subfield.

Sources: arXiv (abstract), arXiv (full text)
