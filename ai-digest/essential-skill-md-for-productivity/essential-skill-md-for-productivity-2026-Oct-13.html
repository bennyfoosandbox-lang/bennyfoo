1. Copilot CLI 1.0.97 prereleases give custom agents their own hooks and fix missing --plugin-dir skills

GitHub's Copilot CLI 1.0.97-0 prerelease (12 Oct) lets custom agents declare hooks scoped to just that agent, so a code-review or release agent can carry its own guardrails without touching global config. It also fixes a bug where skills and custom agents loaded from --plugin-dir plugins vanished from autocomplete and invocation, and makes resumed sessions rebuild plugin hooks from the correct plugin list so repo-local marketplace hooks keep firing while disabled-plugin hooks stay gone. In Autopilot, a preToolUse hook that returns "ask" is now denied instead of stalling on a dialog nobody is watching. The follow-up 1.0.97-1 and 1.0.97-2 prereleases (12–13 Oct) add a fix so custom agents are discovered even in repositories defining more than 100 or deeply nested agent files.

Sources: Copilot CLI v1.0.97-0 release notes, Copilot CLI releases (1.0.97-1, -2)

2. OpenClaw 2026.10.2 ships stable with provider-native compaction, as 10.5-beta.2 trims skills-watcher shutdown

OpenClaw promoted 2026.10.2 to its latest stable channel on 12 Oct, built from 85 merged PRs by 65 contributors. The headline changes are provider-native compaction as the default on OpenAI and Anthropic API-key routes, prompt-cache stability so checkpoints and tool results stay byte-identical across restarts and subagent completions, and faster, boundary-aware secret redaction in long tool output. For skill users the practical value is a calmer Gateway: large-plugin model changes and catalog loads no longer freeze new sessions. The same day's 2026.10.5-beta.2 prerelease adds a smaller skills fix, with the Gateway no longer waiting on native skills watcher cleanup when a process-owning Gateway stops.

Sources: OpenClaw v2026.10.2 release notes, OpenClaw releases (2026.10.5-beta.2)

3. Hermes Agent v0.21.7: skills installed mid-session reach the model without a prompt rebuild

Nous Research's Hermes Agent v0.21.7 (tagged 11 Oct, published 12 Oct) fixes a friction point for anyone who installs a skill while a chat is already running: the new skill now reaches the model immediately instead of waiting for a prompt rebuild. The release also widens the plugin SDK, letting plugins trigger built-in Desktop actions via ctx.runAction and show a pet bubble via ctx.pet.say, and moves Codex requests into core so plugins never hold the token. New community plugins include memory-shield, command-ledger and a model router. The maintainers note that full curated notes will land with v0.22.0, so some changes in this window are undocumented.

Sources: Hermes Agent v0.21.7 release notes, Hermes Agent releases

4. Microsoft Agent Framework: skill scripts get opt-in invocation context, MCP skill archives load more consistently

Two recent Microsoft Agent Framework releases keep tuning its now-stable Agent Skills support. Python 1.20.0 (2 Oct) adds opt-in FunctionInvocationContext injection for skill scripts, so scripts bundled with a skill can see the surrounding call context rather than running blind. The .NET 1.24.0 release (7 Oct) improves consistency when loading skill archives delivered through MCP servers, building on the earlier MCP-based skill discovery. Python 1.21.0 followed on 8 Oct, though its visible notes show no skills changes. These are incremental, but they matter for teams packaging SKILL.md bundles for non-Claude runtimes.

Sources: Agent Framework python-1.20.0, Agent Framework dotnet-1.24.0, Agent Framework releases

5. Anthropic's official Claude plugin directory refreshes vendor plugins, and data-agent-kit hits 1.0.0

The anthropics/claude-plugins-official repository, the curated directory behind Claude Code's plugin marketplace, merged a burst of updates between 9 and 11 Oct. data-agent-kit was renamed, repointed to GoogleCloudPlatform and bumped to 1.0.0, while vendor plugins from Snowflake (Cortex Code), CrowdStrike (Falcon Foundry v1.6.0 and Fusion v1.3.0), PostHog, Qodo and Fullstory were each bumped to new revisions. The cadence shows the directory behaving like a package index where vendors ship skills and connectors on their own schedules, which is worth knowing before you pin versions in a team setup.

Sources: claude-plugins-official commit history
