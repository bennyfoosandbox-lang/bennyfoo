1. Claude Code ships restricted mode, hardening skill-bearing sessions for shared and CI use

On August 27 and 28, Anthropic shipped Claude Code v2.1.248 and v2.1.250. The headline change is a new --restricted flag (or CLAUDE_CODE_RESTRICTED=1) that strips out the tools that run commands, execute code, or fetch the web unless explicitly named, confines file tools to the working directory, refuses bypassPermissions, and — notably for skill-heavy setups — ignores user, project, and local settings files entirely, so a cloned repository can no longer smuggle in permission rules, hooks, or skill grants that widen what a session can do. The same release adds experimental.cacheTtl to agent frontmatter, letting an individual skill or subagent set its own 5-minute or 1-hour prompt-cache window when no broader subagent setting applies — a small but direct productivity lever for teams running many skill-bearing subagents in parallel. v2.1.250 followed a day later with further bug fixes and reliability work. Read together, the releases show Anthropic hardening the skill/plugin execution surface for shared, CI, and higher-trust environments rather than adding new skill capability — a pattern repeating across recent point releases.

Sources: Claude Code changelog, Julian Goldie: Claude Code Restricted Mode, Havoptic release tracker

2. AccuKnox launches AgentZ, folding skills into a single govern-run-build platform

On August 27, cloud-security vendor AccuKnox launched AgentZ, a "zero trust" platform meant to take AI agents from prototype to production by bundling the agent itself, its sandboxed execution environment, reusable skills, runtime-injected credentials, workflow triggers, and audit/governance controls into one stack rather than requiring teams to stitch those pieces together from separate tools. The pitch targets the governance gap that has slowed enterprise skill adoption: AgentZ is model-agnostic, works across the stack customers already run, and lets admins apply one policy edge across every agent and skill in use, with a free tier for evaluation and enterprise pricing aimed at regulated industries such as BFSI, government, and PSU. It's the latest entrant — after Socotra and Camunda in the prior run — treating reusable skills as one governed asset among several (alongside sandboxing, credentials, and audit trails) rather than a standalone productivity feature, reinforcing the broader shift toward managing skills like production software dependencies.

Sources: GlobeNewswire release, NextBigFuture, AccuKnox AgentZ product page

3. Claude for Teachers goes district-wide, open-sourcing its Agent Skills library

On August 28, Anthropic expanded Claude for Teachers from an individual-educator program into a district- and school-wide offering: school and district leaders can now bring an entire staff into one centrally managed organization under a single set of K-12 terms, with qualifying organizations that sign up by June 30, 2027 receiving a full year free. The expansion ships alongside an open-source repository of the program's teaching skills and a technical write-up explaining how Anthropic evaluated them — extending the individual-educator skills library the company open-sourced back in July into a citable, reusable template other education-focused builders can adopt directly. The skills are grounded in a structured "Knowledge Graph" that breaks academic standards into learning components, misconceptions, and progressions, connecting to Anthropic's broader Claude Developer Platform push toward GitHub-hosted, governance-friendly skills for institutional deployments. It's a concrete example of a vendor's Agent Skills library maturing from a single-user productivity tool into shared, centrally administered infrastructure.

Sources: Anthropic announcement, The Hill, GovTech, EdTech Innovation Hub

4. GitHub Copilot's Customize tab reaches GA, unifying skill, MCP and plugin discovery

On August 25, GitHub shipped general availability of a new Customize tab in the GitHub Copilot app, bringing MCP servers, plugins, skills, and canvases together in one browsable surface instead of scattering skill discovery across separate settings screens. The tab surfaces featured customizations, lets teams browse skills and MCP servers by category or trending status, and highlights canvases that keep relevant context visible while moving from understanding a task to acting on it — arriving two weeks after Copilot's Agent Plugins 1.0 shipped as a build-once, run-everywhere standard for agent extensions across VS Code, the Copilot CLI, and the Copilot app. Read together, the two releases show GitHub consolidating skill/plugin packaging (Agent Plugins) and skill/plugin discovery (the Customize tab) into a single coherent pipeline, addressing one of the most common productivity complaints about the SKILL.md ecosystem: that useful skills exist but are hard to find inside a given tool.

Sources: GitHub Changelog, GitHub Docs
