1. OpenClaw 2026.11.7 keeps a session's chosen skills after compaction in sandboxes, and breaks three plugin SDK interfaces

OpenClaw published 2026.11.7 to npm at 01:21 UTC on 23 Nov. For skill users the main fix is in compaction: when a long sandboxed session was summarised to save context, the skills selected for that session could drop out, so the agent carried on without them. They are now kept (#194813, #194722, #198029). Creating an agent template that was only partly written can now be retried instead of leaving a broken folder (#193986, #197561, #199447). Plugin authors have work to do. Three SDK changes are marked breaking (#175837): session run registrations move into a host-provided runAttempt callback, direct access to chat controllers is replaced by dispatchGatewayMethod, which must be declared in the plugin manifest, and start observers must switch from expiresAtMs to startDeadlineAtMs with no compatibility alias. Migration notes are in docs/plugins/sdk-migration.md.

Sources: OpenClaw 2026.11.7 release notes, OpenClaw releases, npm openclaw

2. Qwen Code 0.28.4 picks up MCP server changes without a restart, and lets background hook output reach the model

Qwen Code 0.28.4 reached npm at 12:28 UTC on 22 Nov. Two changes matter for people who build workflows from skills, hooks and MCP servers. Running interactive sessions now pick up edits to the mcpServers settings automatically, and the docs now treat a restart only as a troubleshooting step (#17743). And output from hooks that run in the background now reaches the model, so an async hook that checks or enriches a turn can actually change what the agent does next (#17477, listed in the Desktop notes). The release also carries a test that covers workspace skill settings looked up by name (#17766), and it repeats the UTF-8 byte-order-mark fix for extension manifests that first appeared in the 21 Nov nightly. The rest of the release is mostly Web Shell and hosted-runtime work.

Sources: Qwen Code v0.28.4 release, PR #17743, PR #17477, npm @qwen-code/qwen-code

3. Kaseya publishes 17 ready-made skills and three MCP servers for MSP technicians, in alpha

Kaseya, whose software many managed service providers use to run client IT, has opened early access to its own MCP servers and skills. The servers cover Autotask PSA (11 tools), Datto RMM (16 tools) and IT Glue (20 tools). The 17 skills turn routine technician tasks into one request: nine for Datto RMM, such as a morning pulse, patch posture, stale and ghost devices, security coverage gaps and alert noise review; six for IT Glue, including creating or updating documentation from a ticket; and two for Autotask, a briefing and a guarded-changes skill for making edits with checks. During early access only Claude Desktop and Claude Code are supported. Skills are uploaded as ZIP files under Plugins, and the servers act with whatever permissions the configured API credentials have. The release is labelled alpha. This item dates from 17 Nov, so it comes from the 7-day fallback.

Sources: kaseya/mcp-servers on GitHub, Kaseya MCP servers & skills, Kaseya blog, Channel Insider

4. An open-source skill teaches coding agents to speed up local LLM serving by measuring the ceiling first

Sybil Solutions has released inference-optimisation-skill, an MIT-licensed skill that has Claude Code or another agent tune a local model server one change at a time. The procedure starts by working out the theoretical speed ceiling for the hardware, so impossible targets are flagged early. It then changes one setting per run, compares against interleaved control runs, logs failures as well as wins, and only accepts a result that passes a long-context retrieval check. It ships with a benchmark script for any OpenAI-compatible server, a ceiling calculator, a run queue and a memory reporter, and works with vLLM, SGLang, llama.cpp and ExLlama. The repo reports 256K-context prefill rising from 297 to 628 tokens per second and startup falling from 113 to 43 seconds on an Intel Arc B390 laptop GPU. Coverage dates from about 17 Nov, so this is also a 7-day fallback item, and the benchmark figures are the author's own.

Sources: Sybil-Solutions/inference-optimisation-skill, AlphaSignal, Developers Digest, SkillsLLM
