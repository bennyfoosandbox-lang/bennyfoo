1. OpenClaw 2.0 ships its largest update ever — and immediately reopens the skills-security debate

OpenClaw, the open-source personal-agent framework whose ClawHub marketplace has been this digest's most consistent source of skill-security trouble, shipped version 2.0 (2026.8.1) on August 30-31 — its largest release yet, with contributions from 933 developers across more than 16,000 pull requests. The update touches nearly every part of the project: guided model setup that auto-detects existing Claude or ChatGPT subscriptions, a rebuilt Control UI that now starts in roughly 575ms (down from ~1.6s), shared cloud sessions for handing an agent task between collaborators, and a new "one trust boundary per gateway" architecture meant to shrink the blast radius of a compromised session. Skills built for 1.x load on 2.0 unmodified, and the release adds skills.sh: references that install commit-pinned skill artifacts mirrored through ClawHub with the normal safety checks applied. Coverage split fast: most outlets ran the feature list straight, but The Register led with npm's former founding CTO calling the release "a security dumpster fire," pointing to Snyk's finding that over 7% of ClawHub's skills still expose credentials and arguing 2.0's trust-boundary work treats a symptom rather than the marketplace's underlying vetting gap.

Sources: The Register, InfoQ, MarkTechPost, SiliconANGLE

2. Tenable and OpenAI build an "AI Inspector" specifically to vet skills before they're installed

Tenable and OpenAI announced Exchange Inspector, a security-review pipeline built into the CyberAgents Exchange — the open-source, cybersecurity-focused registry for AI agents, skills, MCP servers, and multi-agent playbooks that Tenable launched in August. The pipeline stacks three layers: frontier assessment using OpenAI's GPT-5.6 Cyber models, skills-specific inspection powered by Tenable One's AI Exposure product, and manual review from Tenable's own researchers — aimed at the more than 100 community-submitted components already listed on the Exchange that security teams currently have no standard way to evaluate before deployment. It's a narrower, security-vertical answer to the same pre-install skill-vetting problem NVIDIA's SkillEvaluator and SkillSpector tackled more generally earlier this year, but notable for pairing a frontier model's semantic judgment with a dedicated exposure-management product rather than a single static scanner. Exchange Inspector is expected to go live this September.

Sources: Tenable press release, GlobeNewswire, CyberAgents Exchange

3. AIR raises $50M, built entirely around continuously vetting the skills and add-ons agents use

AIR, a security startup founded by two veterans of Israel's Unit 8200, came out of stealth having raised $50 million across two seed rounds closed within weeks of each other — $10M led by Sequoia, then $40M led by Greenoaks. Its platform discovers which agents are already running inside a company, continuously vets the skills, tools, and other components those agents load, and can block interactions with anything that fails its security criteria; it also runs a marketplace of pre-vetted skills and add-ons as an alternative to pulling straight from open marketplaces. The bet is that skill vetting needs to be continuous rather than a one-time install-time scan, since a previously-clean skill can be updated with malicious behavior after it's already trusted — the same fork-drift and post-install-mutation problems this digest has logged repeatedly from SkillsMP and ClawHub audits. AIR now competes directly with Noma Security, Astrix, and Zenity (which itself raised a $125M Series C in August) in what's quickly becoming a crowded agent- and skill-governance funding category.

Sources: TechCrunch, Yahoo Finance, Superpower Daily

4. Solo.io open-sources agentdesktop to bring skill and agent governance to the laptop actually running Claude Code

Solo.io released agentdesktop, an open-source (Apache 2.0) governance layer aimed at the gap between what most enterprises govern today — cloud infrastructure — and where agent harnesses like Claude Code, Codex, and Cowork actually execute skills: individual developer machines. It runs standalone on a single desktop for local visibility, or in "fleet mode," where an MDM-installed endpoint daemon reports opt-in, admin-selected session and tool-use telemetry — attributed to user and device — to a central controller wired into the organization's existing identity provider, PKI, and LLM gateway. Solo.io frames this as closing a "production gap": most agentic-AI governance tooling today watches server-side infrastructure, while the skill a developer just installed from a marketplace executes locally with whatever file, credential, and tool access that developer already has. Being open source is itself part of the pitch — organizations can audit exactly what the endpoint daemon collects and what identity and credential boundaries it enforces, the same transparency argument several skill-scanner vendors have made since the ClawHub and skills.sh credential-leak findings logged in this digest through August.

Sources: Solo.io, GlobeNewswire, AiThority
