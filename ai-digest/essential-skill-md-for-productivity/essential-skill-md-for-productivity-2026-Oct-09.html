1. Claude Code 2.1.294 and 2.1.295 add fail-closed hooks, 16K tool descriptions and a 32-skill sub-agent preload cap

Claude Code shipped two builds on 8 October. 2.1.294 fixes prompt and agent hooks written as plain instructions so they no longer let through actions they were meant to block, and makes Stop and SubagentStop prompt hooks less likely to end a session early. 2.1.295 adds onFailure: "block" for command and HTTP hooks, so a hook that cannot start, times out or exits unexpectedly now stops the action instead of waving it through. It also raises the cut-off for tool descriptions loaded via tool search from 2,048 to 16,384 characters, and makes claude.ai connectors negotiate MCP protocol version 2026-07-28 by default (opt out with MCP_PROTOCOL_NEGOTIATION=legacy). For skill authors the notable limit is that a sub-agent preloads at most 32 skills from its skills field, each once, though it can still invoke others through the Skill tool.

Sources: Claude Code changelog, MCP 2026-07-28 specification overview (Cloudflare), MCP blog: 2026-07-28 specification

2. Survey maps agent skills as a lifecycle: on-demand loading, pre-install scanning and signing

A survey published on 6 October argues the original idea of a skill, a folder with a SKILL.md that names the skill, says when to use it and explains the task, has split into several distinct lines of work by autumn 2026. Those include selective, on-demand activation so agents do not carry every skill in context, scanning skills before they are installed, and signing them so provenance can be checked. For anyone building a personal productivity skill library, the practical takeaway is that loading discipline and install-time vetting are now treated as part of authoring, not afterthoughts. This summary is based on the search listing for the article, which could not be fetched in full.

Sources: Agent Skills in 2026: A Survey from SKILL.md to On-Demand Loading, Training, Acceptance Gates, and Signing

3. Fresh star counts: obra/superpowers passes 295K, anthropics/skills hits about 180K

A SKILL.md authoring and portability guide published around 5 October reports GitHub API star counts taken on 5 October: obra/superpowers at 295,590, anthropics/skills at 179,764 and addyosmani/agent-skills at 101,480. A third-party wiki recorded superpowers at 284,306 on 10 September, so the framework has added roughly 11,000 stars in about four weeks. The guide frames a production SKILL.md as a permissioned instruction surface rather than a plain prompt file, and repeats the portability pitch that one skill folder can run across Claude Code, Codex CLI, Cursor, OpenCode, OpenClaw and Hermes Agent, though each tool still expects its own skills directory (such as .claude/skills/ or .agents/skills/). Treat the star figures as point-in-time snapshots.

4. Ecosystem census counts 62,347 agent skills as of 2 October, but the figure is single-sourced

A "State of AI Agent Skills 2026" page reports a census dated 2 October that counts 62,347 agent skills among 84,819 tracked AI coding-agent tools, and says the open standard at agentskills.io lists more than 40 adopting clients as of September. The scale matters for productivity-minded users because discovery, not availability, is now the bottleneck: with tens of thousands of skills, curating a short vetted list beats browsing registries. 5. SKILL.md has no portable permission model, argues Grith, citing a paper that halves but does not eliminate attacks

Security firm Grith argues in a post titled "An agent skill can hand a stranger your shell" that the Agent Skills spec has no portable way to limit which files a skill's bundled Python, Bash or JavaScript can read, which processes it can spawn or which hosts it can contact. The post cites SkillGuard, a 2026 paper that treats skills as permission-bearing artifacts and cut attack success from 35.3% to 20.7% for contextual injections and from 36.7% to 18.0% for obvious ones: better, but nowhere near zero. Its conclusion is that a declared permission manifest is only a promise and enforcement has to happen at runtime. The post is vendor marketing, and the publication date could not be confirmed, so it may predate the 24-hour window; it is included because nothing fresher cleared dedup.

Sources: An agent skill can hand a stranger your shell (Grith), SkillGuard: A Permission-Centric Framework for Agent Skill Security
