1. Claude Code 2.1.317 fixes skills synced from claude.ai that kept vanishing, and warns when scheduled tasks pick up extra connectors

Claude Code 2.1.317 shipped on 3 November with a fix for skills synced from claude.ai: when they could not be written to disk, they were lost or re-downloaded every ten minutes. The built-in plugin-authoring skill now offers to help you share a mod once it works. Two changes matter for unattended skill-driven routines: /schedule now warns when a new cloud scheduled task gets connectors you did not ask for, and a fix stops a cloud task's next-run time and link from being dropped after create or update. A new check also asks before a web or shell tool call sends your account email address to the network.

Sources: Claude Code changelog, Claude Code GitHub releases

2. Copilot CLI 1.0.106 pre-releases resolve ~ in skill directories and strip terminal control characters from skill metadata

Three more Copilot CLI 1.0.106 pre-releases landed over 2–3 November, following the skills add/remove/reload sync fix already covered. A ~ in skillDirectories, COPILOT_SKILLS_DIRS or COPILOT_CUSTOM_INSTRUCTIONS_DIRS now resolves to your home directory, so skills kept there finally load. The details view in /skills, /plugin and /mcp no longer passes terminal control characters from a skill's metadata through to your terminal, closing a small injection route from untrusted skill frontmatter. Skill timeline entries also show cleaned-up errors and results, and screen-reader mode reads out /skills rows.

Sources: Copilot CLI releases

3. Codex 0.166.0 adds incremental skill catalogs behind a feature flag

Codex 0.166.0 (the current stable release, from 29 October) includes incremental skill catalogs behind a skill_catalog_deltas flag, so the agent can receive changes to the skill list instead of resending the whole catalog. It also clarifies skill toggle summaries in the TUI and records skill and plugin catalog sizes when publishing. The practical upside is lower overhead as installed skill counts grow. Codex 0.167.0 alphas appeared on 1 November but their notes were empty, so nothing further is confirmed yet.

Sources: Codex releases

4. Agent Skills 0.6.14 and 0.6.15 stop leaking secrets to transcripts and make lifecycle commands user-only

The addyosmani/agent-skills pack shipped 0.6.14 on 29 October and 0.6.15 on 31 October. Its staged-secret check no longer prints matching lines, so credentials stay out of the terminal and agent transcripts. Lifecycle commands such as /ship and /build are now user-invoked only, so the model cannot start them itself. 0.6.14 also fixed more than twenty code samples that failed or taught the wrong thing, including a rollback workflow that passed input unsafely. 0.6.15 adds a report gate in the constraints skill that blocks high and critical Semgrep and axe findings, and an --eval flag to run a single behavioral case.

Sources: Agent Skills releases

5. OpenClaw 2026.10.9 and neighbouring builds tighten skill metadata and workspace boundaries

OpenClaw's 2026.10.9 stable (29 October) fixes skill metadata so icons and homepages survive an inline YAML value with a trailing comment. The 2026.9.36 maintenance build makes gateway-built tools, including skill dispatch, follow the tools.fs.workspaceOnly restriction, and delegate changes now need approval. The 2026.10.10-beta.5 build (30 October) adds a security change to audit symlinked workspace skill roots. Together they show a skills runtime hardening around where a skill's files may point, not just what they say.

Sources: OpenClaw releases
