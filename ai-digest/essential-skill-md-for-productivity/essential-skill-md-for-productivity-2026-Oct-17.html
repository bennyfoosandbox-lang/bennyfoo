1. Prismatic rebuilds its integration skills on the open standard and ships them to five coding agents

Integration platform Prismatic, on 15 October, rebuilt its Claude Code-only skills as plain SKILL.md files that follow the Agent Skills specification, with no agent-specific hooks. The package now installs with npx skills add prismatic-io/agent-skills and was evaluated end to end in Claude Code, Cursor, Codex, GitHub Copilot and Antigravity. The skills let an agent scaffold a code-native integration, write the TypeScript, deploy, test against a real instance and fix failures, and also build custom components from API docs and map Boomi or Cyclr exports. Platform operations such as log queries and component search moved out of skill scripts into Prism CLI commands, a useful pattern for keeping skills portable. Claude Code users can stay on the legacy plugin while deprecation timing is set.

Sources: Prismatic: Skills now work in Cursor, Codex, GitHub Copilot and Antigravity, prismatic-io/agent-skills on GitHub

2. Etherscan's Transaction Debugger skill grounds agents in live on-chain data

Etherscan released a Transaction Debugger skill for agents such as Claude Code and Codex, with coverage on 16 October. It decodes the calls inside an EVM transaction, reconstructs the execution path, reconciles asset and permission changes, and explains failures, in report modes from Simple to Security. Output is drawn from Etherscan's API rather than model memory, and each report links back to the explorer for verification. It is one of three companion skills in the Build with AI suite alongside Etherscan Flow for fund tracing and Contract Review, and installs with a single npx skills add command against github.com/etherscan/skills. It works on any EVM chain Etherscan supports and is best paired with the company's CLI or MCP server.

Sources: Crypto Briefing: Etherscan launches Transaction Debugger skill, etherscan/skills on GitHub

3. BlueRock launches an Agentic Trust Registry that scans skills, tools and MCP servers

BlueRock announced its Agentic Trust Registry on 16 October, a service that does semantic analysis of agentic components, explicitly including skills, tools and MCP servers. The company claims it outpaces existing scanning tools by 2 to 10 times and produces fewer false positives than legacy static analysis or frontier models. Findings can be wired into CI pipelines so trust checks run as part of the software lifecycle, and vetted components can then run on BlueRock's monitored runtime. For anyone installing third-party SKILL.md files to save time, it is another sign that pre-install vetting is becoming its own product category. The performance figures come from the vendor's own press release and are not independently verified.

Sources: AiThority (Business Wire): BlueRock launches Agentic Trust Registry

4. TrueFoundry explains versioned skill registries: pin numbered bundles and treat skills as release artifacts

TrueFoundry's explainer, published 15 October, describes its AI Gateway Skills Registry, where SKILL.md bundles live in repositories that supply RBAC and version history, are addressed by numbered names and can be used from TrueFoundry Agents, Claude Code and Cursor. Its CLI refuses a latest alias and requires a concrete version, which the post argues is the foundation of reproducibility. The UI publishes only single-file skills for now, while multi-file bundles go through the CLI or GitOps. The practical advice is that a skill is procedure, not permission: pin versions, review scripts and references as a supply chain, test selection with near-miss prompts, and keep an inventory of consumers for incident response. Several of the controls it lists are recommendations rather than built-in features, as the post itself notes.

Sources: TrueFoundry: Skills Registry, Explained

5. Google Maps Platform publishes official agent skills, installable in Claude Code, Gemini CLI, Lovable and more

Google's Maps Platform documentation, last updated 15 October, introduces an official google-maps-platform skill covering maps, places, geocoding, routing, 3D and Street View, clustering, styling and environmental APIs across web, Android, iOS and web services. It installs with npx skills add googlemaps/agent-skills, as a Gemini CLI extension, or through Lovable's skills settings, and was tested in AI Studio, Antigravity, Claude Code and Replit. Users can invoke it manually, for example /google-maps-platform Add a 3D map, and Google positions it as the how-to layer that complements the Code Assist MCP server's tool access. The docs pitch progressive disclosure as the token saver, with only brief metadata scanned until a task needs the full instructions. Skills for more Maps products are listed as coming soon.

Sources: Google for Developers: Maps Platform agent skills, googlemaps/agent-skills on GitHub
