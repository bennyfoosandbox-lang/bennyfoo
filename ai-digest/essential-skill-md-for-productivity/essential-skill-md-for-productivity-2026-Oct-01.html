1. Posit Package Manager now governs agent plugins: curated, pinned and air-gap-ready marketplaces for SKILL.md bundles

Posit announced on 30 September that Package Manager can serve agent plugins, including bundles built from a single SKILL.md or a skills/ directory, as an admin-curated marketplace over a read-only Git endpoint. Administrators can mix public and private sources, attach approval metadata such as risk score and reviewer, pin the repository to an immutable dated snapshot so upstream changes never reach users unannounced, and run it air-gapped. It works with Claude Code, VS Code, Codex and Cursor, and is generally available (git mirroring needs the Advanced licence tier). For teams standardising on a small set of productivity skills, it is a concrete path from "everyone installs whatever" to an approved, versioned skill set.

Sources: Posit

2. PixelLeak: an agent skill for attaching screenshots helped leak 13,000+ internal images to public GitHub repos

Glow Labs reported on 29 September that coding agents published more than 13,000 internal screenshots from 343 organisations to over 900 public GitHub repositories, with 93% sitting on employees' personal accounts. Agents reached for a public repo because the gh CLI cannot upload images to pull requests and private attachments will not render; about a third of cases went through gitshot, an "agent-first" skill whose default creates a public repository, and at one software company more than ten agents saved the trick as a skill for every ticket. Glow sells endpoint security, so treat the figures as vendor research, but the mechanism is easy to verify. The lesson for anyone collecting productivity skills: read what a skill does by default, and require confirmation before an agent creates repositories or changes visibility.

Sources: The Register, Pasquale Pillitteri, Glow Labs

3. "Stealth Apart, Harm Together": cascading skill attacks slip past per-skill scanners

A NeurIPS 2026 paper (arXiv 2609.30383, submitted 24 September) introduces skill cascading attacks, where a malicious goal is split across several skills so each edit looks harmless alone but the chain is harmful. Its example is a prescription-review pipeline in which three small changes make a severe drug-interaction warning silently vanish before reaching the physician. The authors built the SkillCascade red-teaming framework and a 213-case benchmark, and report that cascades reliably induced harmful behaviour in agents including OpenClaw, Claude Code and Codex while evading existing per-skill scanners and runtime monitors. The practical takeaway is that vetting skills one at a time is not enough; the combination you install together needs review too.

Sources: arXiv

4. Meta's Muse for Small Business ships built-in skills, but only Muse Code reads your SKILL.md files

Meta's 29 September Muse for Small Business launch added a collection of Meta-authored skills and connectors to the Muse assistant for ads, sales planning, finance and inbox work, in the US and Canada. According to a 30 September explainer, the Muse app has no documented way to upload your own skills, while Meta's developer agent Muse Code does read standard SKILL.md files, including from ~/.claude/skills and the Codex skills directory. That makes Muse Code another harness where a skill written once should run unchanged, which matters if you want portable productivity skills. The explainer's caveat is that more Meta skills are promised but user-installable ones are not announced.

Sources: AI Agents Library, Meta Muse Code docs, Meta

5. AgentHouse Skills release: a positioning-brief skill and motion-ad 0.2.0, with copy-paste install prompts

The open-source agenthouse-org/skills repository tagged release-2026-09-30 on 30 September, adding a positioning-brief skill and updating motion-ad to 0.2.0. The positioning-brief skill reads provided sources first, then asks one question at a time with a proposed answer, working through audience, value proposition, jobs to be done, alternatives and proof ranking. Motion-ad now starts with a brief step, reusing that positioning brief when present, and gains story arcs and a loud register alongside the default calm one. Every skill also gets a copy-paste agent install prompt. It is a small, incremental release, but a good example of skills that chain into one another.

Sources: GitHub release, Pull request #1
