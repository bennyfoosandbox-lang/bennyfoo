1. Theo Browne's three skill files: 27 of 32 "Full Send" PRs merged without a second look

T3 Code founder Theo Browne says three small markdown skills (Sole Loop, Full Send and Full Stop) now carry much of his coding work. Sole Loop runs a budgeted review cycle (three rounds, five only for security or data-loss risk) with a second model reviewing the first; Full Send gives the agent written permission to own a change through to a merged PR, with proof requirements and a merge checklist; Full Stop is the same minus the merge. In a recent window he invoked Full Send 32 times and 27 PRs merged without him reopening the thread. His practical lessons are that a skill's description is a trigger telling the model when to load it, not documentation, and that you should write down what you repeatedly trust an agent to do. He also stresses the caveat that the result depends on six-hourly nightlies and rollback most teams lack.

Sources: BigGo Finance, BigGo Finance (podcast page)

2. Google Cloud ships IAM Helper: agent skills that fix 403s without over-permissioning

Google Cloud introduced IAM Helper, a set of Agent Skills built on the open standard and backed by Google-managed IAM MCP tools. Four skills cover policy authoring (blocking public access and broad basic roles), 403 troubleshooting, policy simulation against 90 days of access logs, and just-in-time privileged access through PAM. Each skill separates read-only discovery from changes: diagnostics run automatically, while any access-policy change pauses for human confirmation by risk tier. They work across Gemini CLI, Gemini Cloud Assist, ADK, Claude Code and Cursor, and live in Google's skills catalog on GitHub. For productivity, the point is that a stuck deployment agent can self-unblock without a ticket or a standing admin grant.

Sources: Google Cloud Blog, Google Cloud Agent Skills Catalog (GitHub)

3. Box publishes four agent skills, and says installing one grants no account access

Box released four skills on October 22: Box CLI, Box MCP, Box SDK Development and Box Integration Best Practices. Each packages guidance for a different execution path, such as confirming the acting user and verifying changes in the CLI, or handling pagination, retries and rate limits in the SDK. Its bulk-operation guidance tells the agent to establish which file moves succeeded before retrying a failed batch. Installation is a one-liner (npx skills add box/skills), but Box is explicit that a skill only describes how to approach a task; the authenticated CLI, MCP connection or client still determines what the agent can do. Box recommends a first task with a stated completion condition, such as checking an upload landed in the right folder.

Sources: OpenTools, Box Blog

4. Researchers hijack Codex and Claude Code with an instruction file dropped in ~/Downloads

Forever Security found that a plain AGENTS.md or CLAUDE.md in the Downloads folder can steer a coding agent that is launched from there. The finding started with a real customer incident in which an agent was blocked from installing the malicious npm package function-color. In controlled tests Codex followed the file in over 90% of attempts and wrote a rogue MCP server into its global config, while Claude Code changed ANTHROPIC_BASE_URL in about half of tests, exposing its OAuth token. The attack is not automatic, since it needs the agent to run in that folder with enough access. The advice carries over to SKILL.md hygiene: never start an agent in Downloads, review unknown instruction files, keep sandboxes and approvals on, and check agent config for unfamiliar servers or proxies.

Sources: Cyber Security News, Forever Security

5. GitHub Copilot usage metrics now name your custom skills, agents and MCP servers

GitHub's October 22 changelog adds configured names for customer-defined skills, custom agents, MCP servers, slash commands and plugins to Copilot usage-metrics reports, which previously filed them under generic "other" or "custom" buckets. Each totals_by_* list also grows from five entries to as many as 25. For an admin rolling out an internal skill, this finally shows whether anyone uses it. Coverage depends on client versions (Copilot CLI 1.0.97 or later, Copilot SDK 1.0.21 or later), IDE built-in chat does not report names, and earlier days keep the old labels. GitHub also advises reviewing names before sharing reports outside the organization, since they can reveal internal project names.

Sources: GitHub Changelog, OpenTools
