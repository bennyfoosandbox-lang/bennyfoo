1. Anthropic ships Claude for Manufacturing: 17 skills that turn factory records into quotes and quality reports

Anthropic launched Claude for Manufacturing on 12 November, a plugin for Team and Enterprise plans with 17 workflow skills and four connectors (Autodesk Fusion, Infor, Microsoft 365 and Oracle NetSuite). The skills cover sales, quality, operations, supply chain, design and setup. They include quoting a new job, investigating a failed inspection, diagnosing a breakdown, finding a second supplier, comparing designs in Fusion and writing production reports. Each one ends with a person responsible for the work, such as an estimator who releases the quote, reviewing it. The plugin does not operate equipment, and plants on other systems can save regular exports to Microsoft 365 for Claude to read. A setup skill asks which systems a team uses, tests the connectors and reports which skills can't run fully yet. Infor announced a matching partnership the same day so approved recommendations can be carried out inside Infor. For productivity, this is the most complete packaged skill set for one industry so far: one install brings a whole department's routines, not just a single helper. Anthropic says it will add new skills periodically.

Sources: Manufacturing Dive, Yahoo Tech, Unite.AI, MLQ.ai, Cryptopolitan, FourWeekMBA, Infor

2. Claude Code 2.1.323 lets plugins declare which versions they support and pauses skills' git commands in unusual worktrees

Claude Code 2.1.323 (12 November) adds an engines["claude-code"] field to plugin.json. A plugin outside its stated version range is no longer installed, updated or loaded, and install and update now choose the newest version that fits. That gives skill and plugin authors a supported way to ship features that need a newer release without breaking older installs. claude plugin validate now type-checks a plugin's TypeScript hooks module, reporting findings as warnings that --strict turns into failures. A plugin's agent setting is now deprecated and warns. On safety, /security-review now asks before it runs. Skills' inline git commands stop in bare-repository worktrees and similar layouts until you allow them, unless you're in auto or bypass mode. claude.ai chats and Cowork tasks now check plugin files for secret keys before sending them. After safeguards stop a forked skill, Claude is told to retry with a narrower prompt or tell you, instead of doing the work itself. The release also adds Code Mode, an experimental opt-in in which Claude writes JavaScript to call its tools.

Sources: Claude Code v2.1.323 release (GitHub), Claude Code CHANGELOG

3. Copilot CLI 1.0.110 goes stable with consistent skill counts and a fix for skills hidden behind escape sequences

GitHub released Copilot CLI 1.0.110 as stable on 12 November, rolling up the 1.0.110-0 to -3 pre-releases. Two of the skill changes are new since our earlier coverage. /skills reload now reports the same skill count as /skills list. The / command picker no longer lists, preselects or runs a skill because of a word hidden in its description by a terminal escape sequence, which closes a small way for a booby-trapped skill to slip into a session. /mcp, /skills and /plugin now show when a refresh has finished in the Installed view. /context shows loaded custom instructions as their own token count, which makes it easier to see what an instruction or skill file costs. Plugin and marketplace settings also survive an invalid settings.json now. The release adds an experimental masked dialog for git, ssh and sudo password prompts.

Sources: Copilot CLI v1.0.110 release (GitHub), Copilot CLI releases

4. Qwen Code 0.27.3 lets managed agents import an exact revision of a skill

Qwen Code 0.27.3 (13 November) adds managed-agent interfaces that import an exact revision of a skill or extension from an external source, storing the compiled archives in private storage (PR #16882). Qwen Code Desktop 0.27.3 adds importing skills from a session's original runtime. The skill endpoint now makes clear that it updates workspace skill settings by name. For teams running Qwen Code as a hosted agent, this means a skill can be pinned to a known version rather than whatever is latest. It is the same reproducibility push seen in the skills CLI lock files covered earlier this week. The release also makes the repository's CLAUDE.md import AGENTS.md, so one instruction file serves several agents. Other changes include caps on managed MCP selection (32 live, 16 enabled) and human approval for git commit --amend in auto mode.

Sources: Qwen Code v0.27.3 release (GitHub), Qwen Code releases
