1. Hermes Agent v0.23.0 trims its built-in skills from 58 to 44 and adds a hard lock on hand-curated skills

Nous Research's Hermes Agent v0.23.0, released 5 November, shrinks the built-in skill set from 58 to 44: twelve niche skills became optional installs, and the Word, PowerPoint and Excel skills were merged into a single microsoft-office skill. The headline productivity feature is hermes curator lock <skill>, which stops the agent from rewriting a skill you tuned by hand through skill_manage, file edits or terminal writes, even under --yolo; the curator also won't archive it. That graduates the per-skill write locks from v0.22.6. Skills removed during context compaction now leave a reload marker, plugin skills load even when the model adds a plugin: prefix, and the skills index in the prompt is shorter. Upgrade note: old browser tools were removed, so skills that name them need browser_exec.

Sources: Hermes Agent v0.23.0 release notes

2. OpenClaw 2026.11.1 protects skills during failed restores, and the next beta improves learned-skill capture

OpenClaw's stable 2026.11.1 release, published 5 November, includes a fix so that failed skill-restore rollbacks preserve the original copy, meaning a botched restore no longer costs you the skill you were trying to recover. The 2026.11.5-beta.1 pre-release from 4 November lists a "Learning and skills" change that improves how learned skills are captured, reused and authored with guidance, backed by three pull requests (#181747, #181879, #186861). Together they show agent runtimes moving from simply loading SKILL.md files toward generating and safeguarding them. The beta notes are brief, so the exact behaviour of the new authoring flow is not yet documented.

Sources: OpenClaw v2026.11.1, OpenClaw v2026.11.5-beta.1

3. Codex 0.167.0 lets you search the skills toggle view and points the openai-docs skill at replacement models

OpenAI's Codex CLI shipped stable 0.167.0 early on 6 November. For skills users, the skills toggle view now accepts pasted search text, which helps when a long skill list makes finding one entry slow. The bundled openai-docs skill also now recommends the documented replacement when you are migrating away from a deprecated model, a small example of skills being used to keep guidance current. A run of 0.168.0 alpha builds followed the same day, but their notes list no skill changes.

Sources: Codex rust-v0.167.0 release notes

4. Copilot CLI 1.0.106-10 fixes a trap where a re-added skill started out disabled

GitHub Copilot CLI pre-release 1.0.106-10, published 5 November, changes copilot skill remove and /skills remove so they forget the removed skill's disabled state. Before, if you disabled a skill, deleted it, and later added a different skill under the same name, the new one silently started disabled and appeared not to work. The follow-up 1.0.106-11 the same day lists no skill changes. It continues the run of skill-handling fixes in the 1.0.106 line covered earlier this week.

Sources: Copilot CLI v1.0.106-10
