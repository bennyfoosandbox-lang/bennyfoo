1. MaliciousSkillBench consolidates 13 sources into a 9,740-skill ground truth for catching bad SKILL.md files

Researchers published MaliciousSkillBench on arXiv on August 20, the most comprehensive malicious-Agent-Skill benchmark to date, built by pulling from 13 public sources (11 of them contributing confirmed-malicious artifacts) and de-duplicating aggressively: 8,414 raw malicious records collapse to 7,539 normalized-unique identities across 4,588 distinct structural families before cross-label conflicts are excluded. The final dataset pairs 7,505 malicious skills against 2,235 benign ones, and the methodology explicitly separates "broad structural reuse" (a skill that merely resembles another) from "attack semantics" (a skill that actually does something malicious) — a distinction earlier benchmarks like MalSkillBench blurred and that made their reported detection rates less trustworthy. For teams building or buying skill scanners, this gives a much harder, less gameable ground truth than the smaller ad-hoc sets used in prior malicious-skill studies logged in this digest throughout August.

Sources: arXiv abstract, arXiv full text

2. ACES asks the question scanners can't: does this skill actually help, measured live across 145 real ones

A separate arXiv paper published the same week, "Evaluating Skills, Not Just Agents," introduces ACES (Agentic Continuous Evaluation of Skills), a repository-native framework that treats a skill as an executable artifact rather than a text file to lint. Instead of a static quality gate, ACES runs paired live trials — the same task, harness, workspace, and scorer, once with the target skill loaded and once without — normalizes both trajectories into a new Agent Trajectory Interchange Format, grades six runtime metrics, and reports a single "Skill Lift" number for the value the skill actually added. Run across 145 real skills pulled from internal enterprise repositories and public catalogs, the authors found that scan-only quality gates surface real authoring issues but measure a largely different, complementary facet from whether the skill helps a live agent finish the job. It's a direct research answer to the productivity question this digest keeps circling: passing a linter and improving a workday are not the same claim.

Sources: arXiv abstract, arXiv full text

3. NVIDIA open-sources SkillEvaluator after measuring a 41-point correctness lift across 300+ of its own skills

NVIDIA's developer blog detailed SkillEvaluator, an open-source, multi-tier tool that runs the same paired with/without-skill comparison as ACES but at production scale: more than 300 NVIDIA-verified skills spanning over 30 products, tested across two agent harnesses (Claude Code and Codex). The headline numbers are a 41-point average lift in Correctness and 39-point lift in Effectiveness when a skill is loaded versus not, but the more actionable finding is the spread — per-product Skill Lift ranged from +2 to +46 points, meaning the product domain and evaluation design matter more than which coding agent runs it. SkillEvaluator also tracks token and time cost separately from correctness, catching cases like the jetson-optimize-memory skill cutting token usage 76.9% while cuopt-install increased it 120.3% — the kind of efficiency regression a pure accuracy benchmark would miss entirely. NVIDIA is already piloting the tool with OpenClaw's ClawHub and Nous Research's Hermes Agent for pre-install scanning, giving it a plausible path to becoming a shared vetting layer beyond NVIDIA's own catalog.

Sources: NVIDIA Technical Blog, GitHub — NVIDIA/SkillEvaluator

4. Study of 17,022 marketplace skills finds credential leaks survive fixes because forks never get patched

Wake Forest University's research office spotlighted a large-scale academic study on credential leakage in third-party LLM agent skills, which sampled 17,022 skills out of 170,226 artifacts on SkillsMP, the largest open skill marketplace, using static secret extraction, dynamic sandbox execution, and cross-referencing. It found 520 skills (3.1%) carrying 1,708 distinct credential-leakage issues, 84% traceable to plain developer negligence rather than malice, with debug logging alone — a stray print or console.log that an agent framework then captures into the LLM's own context window — responsible for 73.5% of all issues. The more durable problem is remediation: 89.6% of leaked credentials were immediately exploitable without elevated privileges, and because skills spread by forking, secrets already removed from 107 upstream repositories were found still live and leaking across more than 50 independent forks. For anyone treating a skill's GitHub stars or install count as a trust signal, this is a concrete case for scanning the skill you actually installed, not just the one it was forked from.

Sources: Wake Forest News, Tech Xplore, arXiv paper

5. Anthropic-backed Ode buys Casper Studios, betting that "building your skills library" is now a services business

Ode with Anthropic — an enterprise AI transformation firm backed by Anthropic, Blackstone, and Hellman & Friedman — acquired consultancy Casper Studios in its second such acquisition in four months. Casper's specific trade is building the skills, connectors, and context inside Anthropic's products that make Claude useful for a specific company's systems, work the two firms had already converged on independently: reporting says they discovered they were both configuring clients' Claude Code setups the same way and could pick up each other's tooling instantly. The deal is a small but telling signal about where the SKILL.md ecosystem's value is concentrating: not just in the open-source skill files themselves, but in the professional-services layer of consultancies paid to author, audit, and maintain a company's private skill library — a market that didn't really exist as a distinct acquisition target a year ago.

Sources: AIwire / HPCwire, Forbes, TNW
