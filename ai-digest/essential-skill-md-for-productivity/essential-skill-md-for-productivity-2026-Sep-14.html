1. OpenClaw v2026.9.4 unifies skill discovery and lets a Claw mine its own past conversations for new skills

OpenClaw shipped v2026.9.4 on 11 September, and the headline change is a single Skills page that searches installed skills and the ClawHub catalog together, so a user sees what they already have and what's available to add without checking separate places — cards flag whether each skill is ready to use or still needs setup, and switching agents updates which skills show as available. More strikingly, the release adds a steerable feature that lets a user watch and guide their Claw as it looks for patterns in past conversations worth turning into new reusable skills — self-authoring SKILL.md-equivalent procedures from usage history rather than requiring a human to draft one first. The same release adds a read-only config mode (OPENCLAW_CONFIG_READONLY=1) that stops OpenClaw from rewriting deployment-managed configuration, rollback safety for failed schema-neutral updates, and automatic detection of a compatible local Node install. It landed across 1,558 pull requests from 293 contributors, a pace of iteration that underlines how central skill tooling has become to the project roughly six weeks after its 2.0 relaunch.

Sources: v2026.9.4 release, Release notes

2. GitHub Copilot's September 7 weekly release overhauls skill, plugin and MCP commands in the CLI

GitHub's Copilot weekly release covering the week of September 7, published September 10, replaced Copilot CLI's mixed copilot plugins enable/disable --plugin|--mcp|--skill syntax with dedicated copilot skill, copilot mcp, and copilot plugin commands, each now carrying its own enable/disable subcommands, marketplace browsing (copilot plugin marketplace list, marketplace browse), and a --json flag for scripting. It also replaced copilot plugins install --skill with a shorter copilot skill add [--project], cementing skills as a first-class CLI object distinct from generic plugins rather than a flag on a shared command. The same release shipped Project HydraFusion, adaptive model orchestration that routes CLI requests across local, cloud, and compound models, plus new agent automation in VS Code and expanded enterprise controls for Copilot in JetBrains. For teams standardizing SKILL.md installs across CI pipelines, the cleaner command surface is a small but concrete productivity win — scripting "install this skill, verify it's enabled" no longer requires parsing a shared, overloaded flag.

Sources: GitHub Changelog — weekly releases, Sept 7, Copilot Weekly, 3–11 Sept 2026

3. Microsoft lets declarative Copilot agents carry packaged SKILL.md capabilities in Agent Builder preview

Microsoft has moved "custom skills" for Microsoft 365 Copilot's Agent Builder into Frontier Preview: a declarative agent can now carry packaged skills — a zipped folder holding a required SKILL.md file (YAML front matter with name and description acting as the LLM's routing signal, plus a markdown body of task procedures) alongside optional reference files and scripts. Builders upload the complete .zip, never a bare SKILL.md, with a cap of eight skills per agent and 50MB per package; bundled scripts run in a sandbox, sensitivity labels are honored, and the feature sits under existing admin governance. It's a notable convergence signal: rather than inventing a Microsoft-proprietary skill schema, Agent Builder is adopting the same portable SKILL.md format Anthropic popularized — the same push toward portability that Copilot in SharePoint's own skills feature began earlier this month, now extended to the no-code agent-authoring surface most Microsoft 365 admins actually touch.

Sources: Add custom skills in Agent Builder, Custom skills in declarative agents (preview), Copilot Weekly, 3–11 Sept 2026

4. Finch merges two agent-economy platforms and opens a marketplace for buying and selling AI Skills

Finch — formed by merging FinChip's agent-economy infrastructure with AgentOn's task-dispatch network — closed a $50 million Pre-A funding round on 9 September, backed by Waterdrip Capital and Peer VC, and unveiled three linked marketplaces. The Skill Market lets developers package expertise into reusable, resellable Skills, with creators earning an ongoing revenue share on every sale and invocation; the Expertise Market lets industry specialists distil private know-how into deployable proprietary skills; and the Task Market escrows funded work and auto-settles once delivery is verified. The platform already reports 18,600+ skills, 13,000+ user agents, and 100+ experts distilling expertise through it. It's a bet that the SKILL.md ecosystem's next phase is economic as much as technical — treating a well-written skill as a sellable, ownable asset rather than a free community contribution, distinct from the open discovery-only directories (Skills.sh, SkillsMP) that dominate today.

Sources: GlobeNewswire announcement, Manila Times coverage
