1. Copilot CLI 1.0.97 goes stable: agent-scoped hooks, marketplace fetch retry and --plugin-dir skill fix

Yesterday's 1.0.97 prereleases are now a stable build (13 Oct). It keeps the headline changes: custom agents can declare hooks scoped to just that agent, skills and agents loaded from --plugin-dir plugins show up in autocomplete and work when invoked, and plugin hooks, including those from repo-local marketplaces, survive --resume. The stable release adds a resilience fix for teams on private marketplaces: when a remote plugin or marketplace fetch fails HTTPS auth, Copilot CLI retries once with your GitHub token. Custom agents are also discovered in repositories with more than 100 or deeply nested agent files. A 1.0.98 prerelease (14 Oct) follows, adding Gemini 4 Argon support and MCP status sync fixes, with no skill-specific changes.

Sources: Copilot CLI release list (1.0.97 stable, 1.0.98-0), Copilot CLI v1.0.98-1 release notes
