1. Notion ships a shared Skills library, betting portability beats lock-in

Notion 3.7, released September 15, adds a dedicated Skills tab to every workspace's Library: teams turn a page into a reusable SKILL.md-style instruction set, keep it versioned in a shared database, and let the Notion Agent invoke it automatically when a request matches. The distinguishing move is portability — a skill authored in Notion can be downloaded and run in Claude Code, Codex, Cursor, Gemini or Grok rather than staying locked to Notion's own agent, explicitly betting that teams want one canonical skill library rather than a duplicate per tool. It also ships a Skills API so developers can generate and sync skills programmatically, plus tighter MCP connections to GitHub and Amplitude for skills that need to pull live context. For productivity teams already standardizing on SKILL.md, this is the first major workspace tool to treat "export your skill anywhere" as the headline feature rather than an afterthought.

Sources: Notion Releases, Notion Developers, Notion (X/Twitter)

2. Salesforce puts named, GA'd agents onstage at Dreamforce, backed by a new "AIforce" interface layer

At Dreamforce 2026 (September 15–17), Salesforce moved seven job-titled Agentforce agents — Casey, Paige, Carter, Hunter, Marshall, Piper and Fin — out of demo territory: five (Casey, Paige, Carter, Marshall, Piper) are generally available now, with Hunter in pilot and GA slated for November. Alongside them, Salesforce introduced AIforce, a live interface layer launching with Claudeforce, Slackforce and Agentforce Coworker, plus Koa, its first CRM reasoning model built on NVIDIA Nemotron. Each named agent packages a fixed bundle of skills for one business function — e.g., Marshall runs deterministic back-office processes with a full audit trail, Casey resolves service tickets across voice, SMS, WhatsApp and web — signaling a shift from generic chat agents toward pre-composed, role-specific skill sets sold as products. For enterprise productivity buyers, this is the clearest evidence yet that "skills" are consolidating into packaged job roles rather than à la carte capabilities.

Sources: Salesforce Newsroom, Unite.AI, BusinessWorld

3. Anthropic folds Cowork into Claude chat and ships Docs and Slides as native skills-driven surfaces

On September 16, Anthropic announced it is discontinuing Claude Cowork as a separate interface and merging it into the main Claude chat window, alongside chat, Artifacts, and the new Claude Docs and Claude Slides beta products for creating, editing and exporting documents and presentations (including PowerPoint/PDF export) without leaving the conversation. The rollout starts with Pro and Max subscribers over the coming weeks, with Team and Free plans following later. The framing matters for the skills ecosystem: Anthropic describes Claude as now choosing "available context, skills, and connectors" automatically to decide which surface (chat, doc, slide deck) a request should produce, collapsing what used to be separate app choices into a single skill-routing decision. It's a concrete step toward skills becoming the dispatch layer for everyday productivity work rather than a niche power-user feature.

Sources: TechCrunch, VentureBeat, The Decoder

4. Claude Code's v2.1.273–274 push tightens session recovery and memory safety for unattended runs

Anthropic shipped two more Claude Code releases this week: v2.1.273 (September 15) added the ability to fork a `--remote-control` session into a background local session and fixed `/plugin` changes requiring a manual `/reload-plugins`; v2.1.274 (September 17) added a visible warning when memory usage gets critical, fixed sessions that got stuck endlessly retrying "unexpected tool_use_id" 400 errors, and fixed MCP prompts/resources not refreshing on list-changed notifications. Together they read as reliability hardening specifically for long-running, unattended agent sessions — the exact failure modes (silent memory exhaustion, stuck retry loops, stale MCP state) that would otherwise corrupt a scheduled skill-driven workflow overnight. For anyone running Claude Code as a background productivity engine rather than an interactive pair-programmer, this pair of releases is the most operationally relevant update of the week.

Sources: Claude Code Changelog, Claude Code Log (X/Twitter)

5. GitHub Copilot pairs enterprise-wide agent guardrails with tiered auto model selection

GitHub's September changelog shows Copilot converging governance and cost control into one settings surface: enterprise-managed permissions (rolled out generally available September 9) let Business/Enterprise admins centrally mark specific agent operations — shell commands, file reads/edits, network domain access — as blocked, requiring human approval, or auto-approved, with rules that can't be overridden by a user's own settings. Layered on top, the September 14 update to Copilot's auto model selection adds three named tiers (efficiency, balance, intelligence) so teams can tune how aggressively Copilot trades cost and latency against output quality per prompt, on top of code review that now auto-resolves its own addressed comments. The combination is notable for productivity teams standardizing agent skills at scale: it's an admission that "which skill/tool ran" and "which model it ran on" both need the same kind of policy control, not separate settings screens.

Sources: GitHub Changelog (permissions), GitHub Changelog (model selection)
