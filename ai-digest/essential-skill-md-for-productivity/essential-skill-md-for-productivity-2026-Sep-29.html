1. OpenAI tells developers to slim down skills and prompts for GPT-6 Astra

OpenAI Developers published guidance telling teams to revisit their skills, AGENTS.md files and task prompts before moving to GPT-6 Astra. The advice is to make skill triggers specific, load guidance only when it is relevant, and define what "done" looks like up front. The reasoning is that a more capable, better-aligned model is held back by the defensive rules written for its predecessors, so stripping instructions now pays off more than adding them. For anyone maintaining a personal skill library, that means pruning overly cautious language and tightening each skill's description. Codex's bundled OpenAI Docs skill was also updated with GPT-6 Astra migration and prompting guidance, including a note that Astra does not accept a reasoning effort of "none".

Sources: OpenAI Developers, AI Weekly, AlphaSignal, Digital Applied, openai/codex PR #42931

2. "Signal or Noise?": injecting a matched skill lowered pass rates in a web-dev benchmark

A new arXiv study built WebDev-Skills-Bench and tested 31 public web-development skills on 50 projects and 1,000 ordered tasks, placing only SKILL.md in the prompt. Across four models, injecting the target skill cut mean Pass@2 by 1.3% to 4.2% and raised token cost by 72% to 394%, with gains in only 17% to 36% of skill-project pairs. Some of the loss was pure length distraction, since an equally long irrelevant skill reproduced most of it. Anti-pattern rules beat example-heavy content within the skills that did help. The authors recast a skill as a hypothesis about one skill, project and model combination, so injection becomes a per-deployment routing decision. The paper is from late August, so it is a fallback item rather than a last-24h one.

Sources: arXiv 2608.23067, arXiv (HTML), Pith review

3. Skill Coverage: agents exercise fewer than half of a skill's instructions

Skill Coverage is a trajectory-based test-adequacy metric that pulls behavior constraints out of a SKILL.md and checks which ones an agent run actually exercises. On the SkillsBench leaderboard, agent trajectories covered only 38.66% to 45.51% of the extracted constraints on average. Where a constraint was hit and failed, emphasizing that instruction in the skill recovered an average 16.0% of the failed tasks. A companion paper asks whether production cloud skills are adequately tested at all. For productivity-minded skill authors the practical lesson is that a skill passing one task proves little, and that failed-constraint evidence shows which lines to sharpen. Both papers date from June and July, so they are fallback items.

Sources: arXiv 2606.20659, arXiv (HTML v2), arXiv 2607.22015, Awesome Papers summary

4. Microsoft 365 Copilot Cowork gets shareable skills

Microsoft's September Copilot update adds shareable skills to Copilot Cowork. A skill there is a reusable set of instructions capturing your structure, tone and process, which Cowork applies consistently and which you can now share with colleagues. The same release adds cost visibility, an Automations tab for scheduled prompts, and a reasoning-effort slider that trades speed and cost against a slower, context-heavy pass. A companion "Skills Vault" roundup collects 14 skills for PowerPoint, Excel and Cowork. It is one more sign that skills are becoming a standard sharing unit in mainstream office software, not only in coding agents.

Sources: M365 Copilot Connection, Copilot Skills Vault, Microsoft Community Hub, Releasebot

5. Curated skill packs keep winning: Matt Pocock's repo nears 270k stars, .NET team ships ~95 skills

Matt Pocock's mattpocock/skills, a public copy of his personal .agents directory, reportedly stands near 270,000 GitHub stars, with roughly 10,000 added in a week. Its v1.2.3 plugin ships 25 of about 35 skills, and only 11 of those can be invoked by the model itself, while the rest are held for a human to call. That explicit split between model-invoked and human-invoked skills is a useful design pattern for keeping context lean. Separately, Microsoft's .NET team maintains an MIT-licensed dotnet/skills repository of 14 plugins and around 95 skills, built on the agentskills.io standard and usable from Claude Code, Codex, Copilot and Cursor. Star counts come from third-party trackers and were not independently confirmed.

Sources: Mervin Praison, GitHub: mattpocock/skills, Productize, GitHub: dotnet/skills, Hysen Labs, .NET Blog
