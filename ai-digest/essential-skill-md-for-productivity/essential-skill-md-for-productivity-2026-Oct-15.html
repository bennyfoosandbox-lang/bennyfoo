1. Claude Code 2.1.299 and 2.1.300 give skill hooks full frontmatter and let agent.spawn rewrite workflow prompts

Two Claude Code releases landed on 14 Oct. 2.1.299 makes the skill.prompt hook receive a skill's frontmatter, source, plugin name and file path, so mods can react to which skill is running, and adds a --disallow-tools flag to claude plugin eval to keep tools like Agent out of eval runs. 2.1.300 lets the agent.spawn hook rewrite a workflow agent's prompt and model instead of only refusing it, adds a prompt.change hook, and fixes plugin WorktreeCreate/WorktreeRemove hooks not running with --worktree. The built-in plugin-authoring skill now scans a mod's files for keys before opening them and asks before scanning outside the project. Hook input from PreToolUse and PermissionRequest is now validated like Claude's own tool input, which tightens what skill-driven automation can slip through. Release notes on the page are truncated, so 2.1.297-2.1.298 changes may be missing.

Sources: Claude Code releases (v2.1.299, v2.1.300)

2. Copilot CLI 1.0.99-0 auto-installs trusted repo plugins and fixes allowed-tools parsing in skills

The 15 Oct 1.0.99-0 prerelease makes trusted repository plugins install and update automatically before a chat runs, and renames the built-in browser plugin to browser-use with existing preferences carried over. For skill authors, a skill's allowed-tools rule now keeps commas inside its arguments, and where a list's structure is ambiguous, unscoped rules prompt for approval rather than being granted automatically, a safer default for shared skills. Path-specific instruction files under .github/instructions now apply automatically when the agent reads or edits a matching file. Stable 1.0.98 (14 Oct, marked Latest) lists no skill, plugin or agent changes.

Sources: Copilot CLI release list (1.0.99-0, 1.0.98)

3. Codex 0.163.0 alphas continue to alpha.11 with no changelog; 0.162.1 remains the stable build

OpenAI's Codex kept cutting 0.163.0 prereleases, with alpha.9 on 13 Oct and alpha.10.1 and alpha.11 on 14 Oct, none of which carry release notes beyond the version title. The newest stable build is still 0.162.1 (9 Oct), whose notes cover only TUI and startup bug fixes. Nothing skill-specific is confirmed, so the practical takeaway is to stay on 0.162.x, which keeps skill and plugin snapshots scoped to each step, and wait for the 0.163.0 notes before upgrading skill-heavy workflows.

Sources: Codex releases (0.163.0-alpha.9 to alpha.11, 0.162.1)
