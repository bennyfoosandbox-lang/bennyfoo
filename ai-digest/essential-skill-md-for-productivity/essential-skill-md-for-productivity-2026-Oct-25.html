1. Google's Data Agent Kit reaches GA with 37 open-source skills, and a split between advice and enforcement

Google made Data Agent Kit generally available on or just before 24 October: a free, open-source bundle of MCP tools plus 37 Apache-2.0 skills that teach coding agents practices such as optimizing BigQuery SQL or designing Bigtable row keys. It installs into Claude Code, Codex, Cursor, Antigravity and VS Code-compatible editors, and the GA release adds BigQuery Graph, Bigtable and Managed Service for Apache Spark. The sharper lesson for anyone writing skills is InfoQ's framing of guardrails: a skill such as accidental-data-loss-prevention only asks the agent to stop before DROP TABLE or a bucket deletion, while an IAM deny policy on non-read-only MCP tools actually refuses the call. Treat SKILL.md instructions as guidance and keep hard limits in permissions. Versioned releases (1.0.0 on 29 September, 1.1.0 on 13 October) mean teams can pin the skills they depend on.

Sources: InfoQ, Data Agent Kit plugin repository

2. Cloudflare's security-audit skill gets a hands-on guide: six phases, three profiles, and a clear scope budget

A 24 October walkthrough explains how to run Cloudflare's MIT-licensed security-audit skill in Claude Code or Codex (the skill itself dates from June, so the news here is the practical guide). Installed with one npx skills command, it runs reconnaissance, parallel hunters, an independent verifier that tries to disprove each candidate, and a report, and it never edits your code. You pick a quick, standard or deep profile and can cap scope and agent-call budget in plain language, which makes it a good model of a skill that is configurable without extra files. Cloudflare's internal figures (20,799 raw candidates across 128 repositories, validation rejections falling from 40% to 11%) come from its own non-public harness and are unreplicated, and the guide notes one pass finds roughly half of what repeated runs find.

Sources: Pasquale Pillitteri guide, cloudflare/security-audit-skill, Cloudflare blog

3. EMNLP paper SkillMe evolves skills through repeated use and reports +25.7 points over no-skill baselines

SkillMe, published in the EMNLP 2026 proceedings, tackles the gap between a skill that is generally relevant and one that fits your own tools, files and failure modes. A Publisher induces and validates an initial skill from a successful run, then Executors reuse it and send back trace-grounded feedback so the skill improves with each recurrence. Skills are activated on demand as workspace files rather than permanently installed. On the 71-task skill-needed subset of PinchBench with OpenClaw, all eight Executors beat their no-skill baselines, with a mean gain of 25.7 points, and task-scoped evolved skills proved more stable than static ones. For productivity users the takeaway is to refine a skill after each real use instead of writing it once.

Sources: ACL Anthology

4. Awesome Agent Skills packages 49 maintenance and audit procedures with evidence-first reports

From 21 October (featured in HackerNoon's 24 October roundup), a Khasky collection of 49 SKILL.md procedures covers code review, debugging, testing, architecture, security, documentation, Git and writing. Each skill defines an expected deliverable, such as a ranked test-gap list or a cleanup report, requires findings to be tied to code or command output, and separates investigation from remediation. The author compares it with Superpowers, Matt Pocock's skills and Addy Osmani's agent skills, and is candid that no head-to-head result shows it fixes more bugs, so trial it on one familiar task. It installs for Claude Code, Codex and Gemini CLI via npx skills or a plugin marketplace.

Sources: HackerNoon, khasky/awesome-agent-skills

5. Laravel AI SDK 1.1 brings SKILL.md-style skills to PHP agents to stop prompt bloat

Laravel AI SDK 1.1, released on 5 October, lets PHP agents load skills from resources/skills, one folder per skill with a SKILL.md. The agent always sees each skill's name and description and reads the full text only when a request matches, so refund rules, shipping rules and tone guidance stop being sent on every call. A walkthrough published on 24 October says the description is required and should be written as a trigger starting with 'Use when', and that an agent opts in by implementing a HasSkills contract (requires PHP 8.3+ and symfony/yaml). It is another sign that the SKILL.md progressive-loading pattern is now a framework feature outside the coding-agent world. The full article is members-only, so details beyond setup are not verified here.

Sources: Dev Talk on Medium
