1. Anthropic opens the Claude Marketplace, turning committed API spend into a procurement channel

Anthropic launched the Claude Marketplace on September 23, converting what had been a partner directory into an actual purchasing route: enterprise customers with committed annual API spend can redirect a portion of that commitment toward Claude-powered third-party products, and Anthropic takes no commission on the transactions. Launch partners span security (CrowdStrike), coding (Cursor, Replit, Lovable), legal (Harvey, Legora), data (Snowflake, GitLab) and systems integrators (Accenture, BCG, Deloitte), with Anthropic citing CodeRabbit applying spend toward Vercel and Power Digital/ThoughtSpot toward Snowflake as early examples. For teams building SKILL.md-based workflows, this matters because it formalizes Claude as a procurement hub for the very productivity tools those skills plug into, not just a model API — a different growth lever than OpenAI's and Microsoft's app-store approaches. Anthropic hasn't yet said what share of a commitment is eligible, which several outlets flagged as the open question that will decide how much this actually moves enterprise budgets.

Sources: VentureBeat, PYMNTS, Techzine, Superpower Daily

2. Claude Code v2.1.281 tightens enterprise gateway control and trims skill/plugin naming clutter

Claude Code shipped v2.1.281 on September 23, continuing the near-daily release cadence this digest has tracked. The update adds Claude apps gateway support for newer Claude Desktop policy keys (including blockReadsOutsideWorkingDirectories and disableBypassPermissionsMode), lets a gateway assume an IAM role via STS to call Bedrock from another AWS account, and applies a named Bedrock guardrail to every gateway-routed request. On the skills side, the / menu, /skills, /context and the /plugin installed list now show skills synced from claude.ai by their short name instead of a long qualified path, and /code-review switched to leaner inline review prompts instead of spawning many review subagents — a change aimed squarely at the token cost of skill-heavy review workflows. Bedrock, Vertex, Foundry and telemetry-disabled installs also moved to the newer MCP 2026-07-28 negotiation by default.

Sources: Claude Code v2.1.281 release notes, Claude Code changelog, Anthropic release notes

3. GitHub Copilot for JetBrains 1.18 catches up with org-wide shared skills and assisted tool approvals

GitHub shipped Copilot for JetBrains 1.18.0 on September 22, and its headline feature puts it in direct competition with the skill-syncing pushes Claude Code and Notion have shipped this month: local and cloud Copilot agent sessions inside JetBrains IDEs can now pull organization- and enterprise-level shared skills and custom instructions, so a company can centralize its playbooks once instead of every developer maintaining a personal copy. The release pairs that with AI-assisted tool approvals in public preview — which auto-clears low-risk tool calls like reads and lint checks while still prompting for higher-risk actions — plus plan-mode review for the Codex agent and the ability to rewind both conversation and file changes when re-editing a previous prompt. It's a meaningful gap-closer versus VS Code and the Copilot CLI, which picked up organization skills and cloud-agent skill support earlier in 2026, and confirms that shared, org-scoped SKILL.md libraries are becoming table stakes across every major IDE surface, not just the terminal-first agents this digest usually leads with.

Sources: GitHub Changelog, Windows Forum, daily.dev

4. OpenClaw's v2026.9.6 release bricks macOS launches within hours, pulled from auto-update

OpenClaw's v2026.9.6 release on September 23 turned into a same-day incident: the macOS build crashes on every launch after the in-app update completes, leaving affected Macs unable to open the app at all. The bug (tracked as issue #156861) was root-caused to async sleep-frame handling during startup, and maintainers pulled the build from the Sparkle auto-update feed within hours while pushing a fix (PR #156881) toward a 2026.9.7 hotfix. Non-macOS parts of the same release — gateway reliability work that closes failed HTTP/Responses streams and repairs message-loss bugs across Discord, Matrix, Telegram, Slack and WhatsApp integrations — shipped without issue, and Windows and Linux installs were unaffected. It's the second consecutive OpenClaw release cycle this digest has flagged for update-mechanism fragility, after v2026.9.5's own update path was separately blocked by a retained-plugin-source conflict, underscoring that the platform hosting the largest public SKILL.md registry is still shipping its own updater faster than it can harden it.

Sources: OpenClaw issue #156861, OpenClaw fix PR #156881, OpenClaw releases

5. A new arXiv paper repurposes SKILL.md itself as the index layer for agent knowledge bases

A September 22 arXiv paper, "Knowledge-as-Skill," tackles a problem this digest has approached from the opposite direction for months: once an agent can decide for itself whether to retrieve, what to inspect and when to stop, it still doesn't know what a knowledge base actually contains. Author Jiangxu Wu's design layers a SKILL.md file at the top of a knowledge base as a discovery layer, adds one index.md per subdirectory for navigation, and gives individual documents YAML frontmatter for topic, type, provenance and lifecycle — repurposing the exact skill-authoring convention this digest tracks daily as a knowledge-base table of contents rather than a task instruction. It's a small, single-author paper without the benchmark scale of some of this week's other skill research, but it's a clean illustration of SKILL.md's format proving reusable well outside its original "teach the agent a task" use case, extending instead into structuring the data an agent works over.

Sources: arXiv abstract, arXiv full text
