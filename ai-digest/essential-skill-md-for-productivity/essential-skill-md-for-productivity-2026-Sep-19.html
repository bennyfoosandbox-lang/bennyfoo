1. GitHub starts tracking skill, agent and MCP usage inside its own metrics API

GitHub shipped an update to Copilot's usage metrics API that folds "agentic CLI customizations" — skills, custom agents, MCP servers, slash commands and plugins — into the same enterprise and organization reports that already track chat and completions. Admins can now pull per-user and aggregate 1-day and 28-day reports that show which of these customizations are actually being invoked, not just installed, closing a visibility gap that made it hard to tell which productivity skills were paying for themselves versus quietly rotting unused. It lands the same week Slack ships its own skill-bundling tool below, part of a broader shift from "does the skill exist" to "is the skill being used."

Sources: GitHub Changelog

2. OpenAI's Astra for Law ships with 47 ready-made legal skills, not just a smarter model

OpenAI introduced Astra for Law, a GPT-6 Astra configuration pairing a legal search index of more than 230 million URLs with access controls built for law firms, alongside 9 community skill packs from LegalQuants, LECG and Skills.law carrying 47 adaptable skills and 26 partner-built plugins connecting to tools like Relativity and Clio. The launch treats the model itself as only half the product: the other half is a curated skill library practitioners can drop straight into ChatGPT to skip rebuilding common legal-research and drafting workflows from scratch. It's a template other verticals are likely to copy — ship the model and the skill pack together, rather than leaving customers to author their own SKILL.md files.

Sources: OpenAI, LawNext, SiliconANGLE

3. ChatGPT for Word reaches every plan, completing OpenAI's Skills-enabled Office suite

ChatGPT for Word is now generally available on every ChatGPT plan including Free, joining the existing Excel and PowerPoint add-ins through the same Microsoft Office integration; it works as a sidebar for drafting from notes, summarizing a document, revising selected text and adjusting formatting, and will be turned on by default starting October 1, 2026. It shares the Skills mechanism already live in Excel and Google Sheets (reusable playbooks for financial modeling and formatting) and PowerPoint (repeatable workflows for deck structure and narrative), so the same skill library now spans all three core Office documents rather than being siloed by app. Conversations inside Word don't carry ChatGPT memory or plugin support, and usage is billed at token-based API rates against the user's plan limits — worth flagging for anyone assuming it behaves exactly like chat.

Sources: Mixed News, OpenAI Help Center

4. Slack lets admins bundle Slackbot skills into one-click "Skill Sets" for the whole org

Slack's September 2026 admin update ships Skill Sets, which let an IT admin package related Slackbot skills — say a helpdesk triage skill, a ticket-creation skill and an escalation skill — into one named bundle of up to 25 skills and roll the whole thing out to a person, a channel or the entire org in a single share, instead of distributing each skill one at a time. New hires get the full kit on day one, and when the admin updates the set with a new skill, everyone who has it gets the update automatically; owners, admins and Skill Managers get a dedicated admin-dashboard view of who has which set and when it was added. It's a direct answer to the sprawl problem that shows up once an org has dozens of individually-shared skills with no shared distribution or versioning story.

Sources: Vantage Point, Slack Help Center

5. Dreamforce reality check: buyers say last year's AI already covers most of what skills need to do

A day after Salesforce's AIforce and named-agent launches (covered in yesterday's digest), Dreamforce 2026 attendees pushed back on frontier-model hype: G2's chief innovation officer Tim Sanders told CNBC that "the majority of agentic outcomes aren't driven by frontier capabilities... they're driven by last year's AI," and several enterprise leaders said they're still struggling to absorb tools and skill libraries that already exist, let alone new ones. Salesforce itself doesn't depend on the newest Anthropic or OpenAI releases to drive its Agentforce outcomes, reinforcing that skill design and workflow fit — not raw model capability — are the binding constraint on productivity gains right now. Cost pressure compounds the point: executives flagged token-based pricing as a threat to margins, meaning a well-built skill that avoids redundant model calls is now also a cost-control lever, not just a productivity one.

Sources: CNBC, Quartz
