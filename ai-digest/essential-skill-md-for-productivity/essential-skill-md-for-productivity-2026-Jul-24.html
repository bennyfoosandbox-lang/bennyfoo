1. Claude Code v2.1.218 puts more of the skill workflow in the background by default

Anthropic shipped Claude Code v2.1.218 with 4 new features, 7 improvements, 2 security fixes, and 22 bug fixes. The headline behavioral change for skill authors: skills declared with context: fork now run as background subagents by default (opt out per-skill with background: false), and the bundled /code-review skill now runs the same way — so a review or a forked-context skill no longer blocks the main conversation while it works. The release also adds detailed HTTP status and error text to claude mcp list//mcp when a server fails to connect, fixes skill and plugin frontmatter booleans that used yes/no/1/0 instead of true/false, and patches two security issues. For anyone running a library of SKILL.md files day to day, it's a direct productivity change: heavier skills stop stalling the terminal.

Sources: Claude Code release notes (GitHub), DevelopersIO: Claude Code v2.1.218 major updates

2. Anthropic raises the per-session skill cap on its Managed Agent Platform from 20 to 500

Anthropic's Claude Managed Agent (CMA) platform shipped six updates this week, the biggest being a 25x jump in how many skills a single agent session can mount — from 20 to 500. In practice that means one long-running managed agent can now hold what amounts to an entire enterprise knowledge base as loadable skills instead of juggling a handful at a time. The update bundle also adds five adjustable levels of reasoning effort (to trade off token spend against depth), makes the agent "version" field optional for single-flow deployments, and adds thread-level streaming plus lifecycle webhooks so operators can watch and hook into what each sub-agent is doing in real time. For teams building on Anthropic's agent infrastructure rather than Claude Code directly, this removes the skill-count ceiling that previously forced hard prioritization choices.

Sources: BigGo Finance: Anthropic gives AI agents an operating system, 36Kr: Claude Agent unveils major update, AI Disruption: Claude Agent Update

3. The skill ecosystem discovers a new use case: SKILL.md as a marketing channel

A new guide published today argues that a well-written SKILL.md is no longer just an internal productivity tool — it's becoming a distribution channel in its own right. The pitch: an agent skill reaches a buyer while they're actually doing the task (deploying an app, instrumenting analytics, writing in a brand voice), which a landing page never does. The guide walks marketers through briefing an "official product skill," writing descriptions agents can actually route to (per Anthropic's own authoring guidance), requesting API keys safely from within a skill, and publishing through GitHub, ClawHub, and Skills.sh to earn Featured/Trending placement. It's a sign of how far the SKILL.md format has moved from a coding-agent convenience into a full go-to-market surface, with its own launch playbook and growth metrics (installs, first successful API call, returning accounts).

Sources: Skillscout: An AI Agent Skill Is a Product Marketing Asset Now, Anthropic: Agent Skills authoring best practices

4. ThreatDown's new cybercrime report catalogs malicious AI agent skills as an active threat, not a hypothetical one

Malwarebytes' ThreatDown unit published a report this week (its research window closed a few days before this run, so it's the one item here that isn't from the last 24 hours) documenting that "guardrail-free" AI has gone mainstream — including AI agent skills built specifically to steal credentials, exfiltrate data, install malware, or manipulate the agents and people running them. The report also flags 6,644 openly published models labeled "abliterated," "uncensored," or "unfiltered" with 22M+ combined downloads, and notes attackers are now using AI to compress patch-to-exploit timelines to minutes. Read alongside this KB's running coverage of AgentBaiting, FakeGit, and SkillCloak, it reinforces the same message for anyone installing third-party SKILL.md files for productivity: scanning a skill's static files at install time is no longer sufficient — runtime monitoring matters just as much.

Sources: Business Wire: ThreatDown Research — Guardrail-Free AI Has Gone Mainstream, Help Net Security: ThreatDown expands security visibility to AI tools, eSecurity Planet: AI cybercrime report warns of emerging threats
