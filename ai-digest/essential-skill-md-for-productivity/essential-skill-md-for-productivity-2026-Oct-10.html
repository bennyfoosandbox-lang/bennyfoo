1. Claude Code 2.1.296 lets subagents auto-compact early and hardens managed hooks

Anthropic shipped Claude Code 2.1.296 on 9 October, one day after 2.1.295. Subagent frontmatter and --agents definitions gain an autoCompactWindow field so a subagent can compact earlier than the main conversation, and a new CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL variable pins every workflow agent to one model. On the hooks side, managed PreToolUse hooks that deny a call with "continue": false now refuse the call without ending the turn, and managed PostToolUse hooks apply updatedMCPToolOutput reliably. For anyone running skills inside long subagent chains, this means less context bloat and fewer silently dropped guardrails.

Sources: Claude Code v2.1.296 release notes, Claude Code releases

2. Anthropic's claude-api skill adds dynamic workflows and four Managed Agents quickstarts

Two commits landed in anthropics/skills on 9 October, both updating the bundled claude-api skill. The larger one (+977/−143 across 27 files) teaches the skill to route work too big for a session's 25 child threads to Managed Agents dynamic workflows, enabled through a multiagent_20261001 config, and adds four workflow quickstarts (bug hunter, explainer-video maker, performance tuner, watchlist scanner). It also narrows "outcomes" to single deliverables and makes allowed_hosts gate web tools under limited networking. The companion commit makes Haiku 5.5 the current Haiku, defaults examples to limited networking with web tools off, and documents the auto permission policy with user.tool_confirmation replies. It is a useful model of a skill that stays current with a fast-moving API.

Sources: anthropics/skills commit dbd4588 (dynamic workflows), anthropics/skills commit 9d63080 (Haiku 5.5, Managed Agents), anthropics/skills commit history

3. Codex CLI 0.162 enforces required skills before inference and scopes plugin snapshots per step

OpenAI's Codex CLI 0.162.0 (8 October) changes how skills behave: skill identity and path matching now use PathUri, required environment skills are enforced before model inference, and plugin and skill snapshots are scoped to each step rather than the whole session. The release also adds managed Git worktree tools, pinned tasks in the Command Center, opt-in ranked tool search, and MCP fixes (truncated oversized tool results, Windows environment variables for remote servers). The 0.162.1 patch on 9 October fixes a TUI crash and a startup mismatch with background-server feature settings, while 0.163.0 alphas are already on the way. Required-skill enforcement is the notable shift for teams that rely on a skill always running.

Sources: Codex rust-v0.162.0 release notes, Codex releases (0.162.1, 0.163.0 alphas)

4. Copilot CLI 1.0.95 retries managed plugin setup hourly; 1.0.96 prereleases add sandbox controls

GitHub's Copilot CLI 1.0.95 became the latest stable build on 9 October. For plugin-heavy setups the useful change is that managed plugin setup now retries hourly or when policy changes, instead of only after a failed message. It also adds native Microsoft Entra broker sign-in on macOS and sandbox credential injectHosts keys in copilot config. The 1.0.96 prereleases (9 and 10 October) show which permission path approved each action, let /add-dir extend sandbox access for a session, and add interactive sandbox settings that suggest secrets to mask. None of these builds changes skills handling directly, so they are enterprise-hardening rather than skill features.

Sources: Copilot CLI releases (v1.0.95, v1.0.96-0, v1.0.96-1)

5. Gemini CLI 0.64.0 preview.1 backports a trusted-command fix as the 0.65 nightly tightens MCP shutdown

Google's Gemini CLI shipped 0.64.0-preview.1 on 9 October, a single-fix patch that backports the work reducing false positives in untrusted command flag checks. The 10 October 0.65.0 nightly continues that line, and also makes the VS Code IDE companion server shut down cleanly even while MCP sessions are open, hardens fetchJson against malformed responses, and speeds up ignore filtering. Neither build touches skills or extensions, so this is a maintenance note: the trusted-folder and command-safety groundwork matters because skills can run scripts. It is a thin item and is flagged as such, since it partly follows earlier coverage of the 0.64 preview.

Sources: Gemini CLI releases (v0.64.0-preview.1, v0.65.0 nightly)
