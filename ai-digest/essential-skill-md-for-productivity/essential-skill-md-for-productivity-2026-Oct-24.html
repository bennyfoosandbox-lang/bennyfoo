1. Claude Code 2.1.308 to 2.1.310 fixes how skills are found, synced and namespaced

Three Claude Code releases landed on 22 and 23 October, and the 2.1.309 notes carry most of the skill-related changes. A skill in an added directory that shares a name with another skill is no longer unreachable and is now offered as folder:name, and skills in a nested package are found again when their files are changed from the shell. Plugins and skills synced from claude.ai are no longer removed after a disk read error, which had sometimes happened mid-session. The bundled dataviz skill now accepts APCA as a text-contrast measure, and the bundled claude-api skill got several tracing and Managed Agents updates. If you keep skills in more than one folder or sync them from claude.ai, these are fixes to the exact failure modes that make a skill silently not load; 2.1.308 and 2.1.310 list no skill changes.

Sources: Claude Code changelog, Claude Code releases

2. Expo finds an entrypoint skill raised agent skill usage from 9% to 55%

From earlier this month (8 October), Expo and Georgian's AI Lab argue that testing a skill by invoking it directly does not show whether an agent will find it during ordinary work. They measured how often coding agents loaded a relevant Expo skill across 10 app-building tasks and report the share rose from 9% to 55% after Expo added an expo-overview entrypoint skill. The post also flags that when many skills share a catalog budget, descriptions can be shortened or dropped, and it describes an evaluation harness run in CI. The practical lesson for a personal library is to write descriptions that trigger on real tasks and to check discovery, not just correctness. Expo bundles its skills as one plugin for Claude Code and Codex. This item is about two weeks old and the details above come from the post's published summary rather than a full read.

Sources: Expo blog

3. Google gives a rollout timeline for Gemini skills: Gemini app by mid-November, Workspace slightly delayed

An update from Google Workspace Updates dated 13 October says skills in the Gemini app are starting to roll out, with completion expected by mid-November, and that the Workspace rollout is slightly delayed. This follows the earlier announcement, already covered here, that skills would replace Gems. It is a timing update rather than a new feature, so the useful part is planning: if your team's Gemini skills are not visible yet, that is expected. This is from earlier this month, and the summary rests on the post's search listing rather than a full read of the page.

Sources: Google Workspace Updates
