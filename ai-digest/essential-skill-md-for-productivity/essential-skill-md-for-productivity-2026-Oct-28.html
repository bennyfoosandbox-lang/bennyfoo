1. Google's Gemini agent chooses its own skills, but it is still early access

At Gemini at Work 2026 on October 8, Google unveiled the Gemini agent: you hand it an objective, and it plans the work, picks the skills and tools it needs, and returns a finished result. Coverage describes sub-agents, persistent coworker agents and four memory types (session, semantic, procedural, episodic). For anyone curating SKILL.md files, the point is that skill selection is moving from the user to the agent, which makes clear skill descriptions the thing that decides whether your skill gets chosen. Analysts say the officially confirmed stage is early access, with pricing and eligible editions not yet set, and claims such as Claude model access remain unconfirmed. This item is about 20 days old; it is included because the fresh window produced too few new items.

Sources: Google Cloud blog, Windows Report, SmartScope

2. Microsoft's October partner update ships a SQL modernization agent as plain skills

Microsoft's October 2026 Partner Center announcements list a SQL modernization agent that is delivered as skills rather than a standalone app, so it can plug into any interface that supports skills. It starts with GitHub Copilot CLI and Visual Studio Code and is listed as public preview. It follows the pattern of Microsoft's modernization agent, whose CLI already lets architects define reusable skills that apply modernization standards across repositories. The practical takeaway is that a database migration playbook can now be packaged once and run in whichever agent a team already uses. I could not open the announcement page itself, so the preview details come from the search snippet and the page should be checked before relying on them.

Sources: Microsoft Partner Center, Microsoft Learn

3. PromptArmor: a skill used to vet other skills caught about 11% of seeded malicious ones

PromptArmor seeded roughly 1.05 million marketplace skills with malicious content from Microsoft's BIPIA benchmark and ran the check through the Skill Management skill built into Microsoft Copilot Cowork. It flagged about 11%, and only 0.4% once a one-line obfuscation trick was added. PromptArmor's conclusion is that a skill should never be the sole tool assessing another skill for malicious behavior. It separately reports that backdoored skills pass Anthropic's skill scanner because the payload is fetched at runtime, which the scanner never sees. The publication dates of these write-ups were not confirmed in my search, so treat the timing as unverified; the figures are PromptArmor's own and not independently reproduced.

Sources: PromptArmor, PromptArmor (Anthropic scanner)
