1. Claude Code 2.1.302–2.1.304 caps skill hooks, adds a Managed Agents security check, and fixes a cross-skill hook bug

Three Claude Code releases landed between 16 and 19 October, and the 2.1.304 notes are the busiest for skill authors. Each skill source (repo, personal folder or plugin) may now register at most 1,024 hooks and 16,384 matcher characters per session, and a main-conversation skill whose hooks are blocked by a plugins-only hooks policy no longer receives its allowed-tools. A fix stops a skill's once hook from also deleting another skill's identical hook, and resumed or cloud sessions no longer resend the full skill list on every plugin reload. The bundled claude-api skill gained /claude-api managed-agents-secure, which compares a Managed Agents agent's settings with Anthropic's security guide without changing anything, and 2.1.302 made fork subagents the default in claude -p, the Agent SDK, the desktop app and VS Code.

Sources: Claude Code releases (GitHub)

2. Copilot CLI 1.0.100 goes stable: install skills from GitHub links, auto-update trusted plugins, scope instructions by path

GitHub marked Copilot CLI 1.0.100 as the latest release on 19 October. Skills and plugins can be installed from GitHub install links with copilot plugin install, and plugins from trusted repositories now install and update automatically before chat runs. The built-in browser plugin was renamed browser-use with existing preferences carried over, and managed plugins update their activation inside existing sessions when managed policy changes. Path-specific files in .github/instructions now apply automatically when the agent reads or edits matching files, and a skill's allowed-tools rule keeps commas inside its arguments while ambiguous unscoped rules now prompt instead of being granted. A 1.0.101-0 pre-release followed the same day with no skills notes.

Sources: Copilot CLI releases (GitHub)

3. Addy Osmani's agent-skills 0.6.13 fixes two simplify-ignore hook bugs and makes TDD trigger on pasted code

The popular agent-skills collection shipped 0.6.13 on 13 October, a few days older than the rest of today's items but not previously covered here. It fixes code samples in three skills that did not work as written and two bugs in the simplify-ignore hook, one of which could lose protected code and another that could restore a change the user had reverted with git. The test-driven-development skill now fires on pasted code even without the word tests, and /review and /test are documented as running in the main session rather than spawning the code-reviewer or test-engineer personas. Host guides now need a written bar, and the Oh My Pi and Dojo Workspace guides added in 0.6.12 were withdrawn. The 0.6.12 release on 3 October had already slimmed performance-optimization from 496 to 267 lines and made spec-driven-development wait for approval after saving the spec.

Sources: agent-skills releases (GitHub)

4. Anthropic's official security-guidance plugin gets a run of fixes: nested repos, notebook cells, silent review failures

The anthropics/claude-plugins-official marketplace repository merged a cluster of security-guidance plugin changes on 19 October, with one more on 17 October. The plugin now stays out of repositories nested inside the work tree, runs its pattern checks on NotebookEdit cells, finds Python releases newer than the launcher's built-in list, and says so explicitly when its LLM-based reviews cannot run instead of failing quietly. For anyone installing official plugins as a productivity or safety layer, the changes mean fewer false positives in monorepos and clearer signals when a review was skipped. The commit log shows these as the bulk of recent activity on the repository's main branch.

Sources: claude-plugins-official commits (GitHub)

5. OpenClaw ships 2026.10.5 stable and a 2026.10.10 beta that extends plugin tool guards to standalone agent runs

OpenClaw tagged 2026.10.5 on 18 October and a 2026.10.10-beta.2 on 19 October. The beta's notes say plugin before_tool_call hooks now run in standalone openclaw agent exec sessions, so plugin tool guards apply outside the chat gateway, and restore the SDK facade exports that external plugins import so those plugins load again. It also rejects a multi-file apply_patch before touching any file if a later target is missing, and stops session diff capture from opening live SQLite files, which had been causing crash loops. The stable page lists release metadata rather than prose notes, so the full feature list for 2026.10.5 sits in the project's changelog. Skill Workshop and learned-skills changes arrived in the earlier betas already logged in this digest.

Sources: OpenClaw 2026.10.10-beta.2, OpenClaw releases (GitHub)
