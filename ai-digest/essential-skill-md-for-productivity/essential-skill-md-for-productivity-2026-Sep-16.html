1. Claude Code v2.1.272 stops orphaned synced skills from lingering on disk after sign-out

Anthropic shipped Claude Code v2.1.272 on September 15, 2026, a maintenance release billed only as "bug fixes and reliability improvements" but carrying a fix directly relevant to skill hygiene: skills synced down from claude.ai were staying on disk indefinitely after a user signed out, and copies that hadn't refreshed within cleanupPeriodDays now move to the recoverable trash at the next launch instead of sitting there stale. The same release closes an interactive /hooks menu crash triggered when a hook matcher is named after an inherited object property such as __proto__ or constructor, fixes spinner tips that suggested commands unavailable for the current account or session, and corrects several smaller input-handling glitches (arrow-key navigation in /add-dir, a stray leading ! being reordered in non-prompt text fields, and Delete/Alt+arrow keys misbehaving in attached background sessions under st and rxvt-unicode). None of it is a new capability, but for teams that treat Claude Code's skill-sync path as part of their daily productivity setup, the disk-hygiene fix quietly removes a source of drift between what claude.ai thinks is installed and what's actually sitting locally.

Sources: Claude Code v2.1.272 release notes, Claude Code changelog

2. SkillLift cuts the cost of skill self-evolution by learning a rubric instead of grading every attempt

A new paper, "SkillLift: Learning Dense Rubrics from Sparse Oracles for Efficient Skill Evolution" (arXiv:2609.15396, submitted September 14, 2026, by Haoxiang Kang and Ming Wen), targets a bottleneck in how agents improve their own SKILL.md-style procedures: existing self-evolution methods revise skill text directly from execution feedback, but each oracle evaluation needs a full agent rollout, so search gets confined to patching obvious failures. SkillLift's insight is that ranking two candidate skills is a much cheaper supervision signal than scoring each one in absolute terms, so it learns a dense, oracle-aligned rubric as a cheap surrogate an inner loop can consult for free, while an outer loop spends a small number of real oracle rollouts re-aligning that rubric via rank correlation. Across complex agent task benchmarks the authors report the method matches or beats existing auto-skill approaches while using 40–70% fewer tokens than frontier skill-evolution methods — a meaningful efficiency gain for anyone running automated skill-improvement loops in production rather than as a one-off research exercise.

Sources: arXiv:2609.15396 abstract, arXiv:2609.15396 PDF

3. Salesforce open-sources a SKILL.md library for Agentforce Vibes, timed to Dreamforce 2026

Ahead of Dreamforce 2026 (September 15–18, San Francisco), Salesforce published forcedotcom/afv-library (also mirrored as sf-skills) on GitHub: a curated, community-open collection of agent skills — each a standard SKILL.md folder with YAML front matter — covering Agentforce agents, Lightning apps, Flow, Apex, SOQL, Lightning Web Components, UI bundles, objects/fields, and permission sets. The library is built for Agentforce Vibes, where skills auto-install and auto-update, but Salesforce explicitly frames it as compatible with any AI coding tool that supports the SKILL.md format, including a documented npx skills add forcedotcom/sf-skills path for Claude Code. Dreamforce sessions this week walk developers through pairing the library with Anthropic's Metadata Grounding MCP and building with Agentforce Vibes and Claude Code side by side — another sign that platform vendors now see a public, versioned skills repository as table stakes for developer productivity, not just an internal tool.

Sources: forcedotcom/afv-library on GitHub, Salesforce Developer's Guide to Dreamforce 2026

4. Anthropic's new Smart Reports turn a team's repeated Claude usage into ready-made skill suggestions

Anthropic launched smart reports in beta for Claude Enterprise on September 10, 2026: a feature that analyzes how a team actually uses Claude and reports back on the work getting done, what it costs, and where sessions run into friction. The part most relevant to this digest is a dedicated section that surfaces repeated patterns worth packaging as a shared skill — the examples Anthropic gives include turning call notes into follow-ups, building account briefs, and drafting quarterly review outlines — with each surfaced pattern carrying a ready-to-use prompt for setting that skill up. During the beta, each organization can generate up to 10 reports a month at no extra charge, and Anthropic is explicit that the feature is not designed for evaluating individual employee performance. It's a notable inversion of the usual skill-authoring workflow: instead of someone deciding up front which processes deserve a SKILL.md, the tool watches usage and proposes the candidates itself.

Sources: Claude Help Center: Get started with smart reports, Claude release notes

5. Anthropic's September threat report: attackers are now industrializing the same agentic-workflow pattern productivity skills rely on

Anthropic's "Detecting and countering misuse of AI: September 2026" report, published September 10, 2026, documents activity it disrupted between December 2025 and August 2026 across seven harm areas — cyber operations, influence operations, surveillance, scams and fraud, biological misuse, conventional weapons development, and model distillation. Its central finding is a shift from interactive chat-based misuse toward autonomous, multi-agent execution: threat actors increasingly delegate entire multi-stage operations to agent frameworks, with human involvement narrowing to picking a target and reviewing the final output — structurally the same "thin harness, fat skill" pattern that makes legitimate productivity skills valuable. One disclosed case involved an attempted prompt injection against an unnamed AI vendor's evaluation sandbox aimed at a pre-release Claude model; Anthropic says the attempt failed and its own systems were not compromised. For anyone building or approving SKILL.md files for internal use, the report is a reminder that the same reusable-procedure design that improves productivity is exactly what lets an attacker automate an attack chain end to end once they get a foothold.

Sources: Anthropic: Countering misuse of AI, September 2026, Coverage: AI misuse across cyber ops, surveillance and weapons
