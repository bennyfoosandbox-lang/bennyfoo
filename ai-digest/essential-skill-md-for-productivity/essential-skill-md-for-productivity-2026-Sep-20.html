1. Claude Code v2.1.277–278 add AGENTS.md fallback and put auto mode's classifier on the server for free

Two back-to-back Claude Code releases land productivity-relevant changes for anyone leaning on skills day to day. v2.1.277 (Sep 18) makes Claude Code read AGENTS.md as a fallback whenever a project has no CLAUDE.md, so teams that already standardized on the emerging cross-agent AGENTS.md convention no longer need a duplicate Claude-specific file — check /config → "Project instructions" to see which one a session is actually using; the fallback isn't yet available when running against Bedrock, Vertex or Foundry. v2.1.278 (Sep 19) then defaults Auto mode's model-routing classifier to run server-side for Claude API, Enterprise, Bedrock, Vertex, Foundry and gateway users at no extra billing cost, adds an "Auto mode server" row to /status, and removes the TaskOutput tool in favor of reading background task output through the standard Read tool — a small surface-area cut that simplifies how skills and scripts watching long-running jobs need to be written.

Sources: GitHub Releases, GitHub Releases, Claude Code Changelog

2. Anthropic renames BetaSkill to BetaContainerSkill and drops the skills beta header entirely

The Claude Developer Platform shipped an SDK update this week that aligns beta and non-beta shapes for files and skills, renaming the BetaSkill type to BetaContainerSkill and changing how skill deletion behaves in the API. More practically for anyone building on top of Skills: requests no longer need to send the skills-2025-10-02 beta header at all, including Messages API calls that load a Skill through the container parameter — one fewer thing to remember when wiring a skill-using integration, and a signal that Anthropic now treats the container-skills feature as stable rather than experimental. Existing integrations that still send the old header should keep working, but new code can drop it.

Sources: Claude Platform Release Notes, Releasebot

3. SkillAtlas turns thousands of private skill-attack reports into a searchable public library

A new research library called SkillAtlas converts private agent-skill security report bundles into reviewed, redacted, searchable public cases — 3,014 attack cases, 6,589 traces, 151,131 individual steps and 233 affected skills across 8 risk categories, now browsable at skillatlas.top. The authors found that 42.5% of successful attacks only became successful after an initial failed attempt, meaning single-shot red-team tests miss a large share of real risk, and that grounding pre-execution guardrails in these multi-step trajectories rather than static signatures lifts guard accuracy to 0.770. For anyone assembling a team skill library, it's a concrete, evidence-based catalog of the failure patterns to test for before trusting a third-party SKILL.md, not just a theoretical taxonomy.

Sources: arXiv, arXiv (HTML), The Cryptonomist

4. EconSkills shows a skill library only pays off if the agent can actually pick the right skill back out

EconSkills, released on arXiv this week, is a library of 50 parameterized standard operating procedures distilled from verified trajectories for pulling live economic figures from authoritative web portals — central banks, statistical agencies, market-data sites and government fee schedules. What makes it useful beyond its own domain is the question it isolates: it separates "does a known relevant skill transfer to a new but similar task" from "can the agent actually retrieve and select the right skill from a growing library when it needs it," and finds the second problem is where most of the practical failure happens. That's a direct, generalizable warning for any team building out a large productivity skill library — writing good skills is necessary but not sufficient if retrieval and selection aren't tested just as rigorously.

Sources: arXiv, arXiv (HTML), Hugging Face Datasets

5. GitHub will merge Copilot Chat and its cloud agent into one experience — with a policy and retention reset attached

No earlier than September 28, 2026, GitHub is relaunching Copilot Chat on github.com, Copilot Chat in GitHub Mobile and the GitHub Copilot cloud agent as a single unified Copilot experience, replacing the separate policies each currently has with one combined policy. The change quietly extends chat data retention from 28 days to the life of the account, matching what the cloud agent experience already does — worth flagging to any admin who assumed chat history aged out automatically. It lands alongside other September resets already flagged: Business and Enterprise seats move to prepaid billing on October 1, and "Balanced" becomes the default code review effort level, changes admins running Copilot-driven skill and agent workflows will need to re-check before the switch.

Sources: GitHub Changelog, Developers Digest
