1. A hallucinated domain in an official OpenAI skill siphoned real production tokens

AIR Security researchers found that an official skill in OpenAI's skills repository, written to teach agents how to deploy apps on Render, told production apps to send their tokens to render-internal.com, a domain nobody had registered. The team registered it behind a listen-only sinkhole and promptly began receiving tokens and API calls from live apps, and testing with Codex confirmed the domain landed in generated application code as the default. The flaw came in with a January commit and was fixed in mid-August, when Render stripped every reference and OpenAI pulled the Render plugin. The lesson for anyone installing skills for productivity is that vendor-published does not mean vetted: treat skills like any other dependency, with review, monitoring and a way to revoke them.

Sources: CSO Online, AIR Security write-up

2. Oracle's Martinez: keep ~100 skills out of context with a retrieval "skillbox"

Oracle developer advocate Nacho Martinez argued on the AI Engineer podcast that the real leverage in agents is the harness around a frozen model, because accuracy degrades as context fills. He runs roughly 100 skills at 3,000 to 5,000 tokens each, which would overflow the window if loaded together, so he embeds them in a vector store and retrieves only the top few per step, optionally reranking to a single best match. He also describes distilling past conversations into reusable skills, such as a personal front-end colour style, as a lightweight form of continual learning that never touches model weights. His advice is to start small, strip out most of what a full agent like Claude Code carries, and keep a human in the loop for consequential actions.

Sources: BigGo Finance

3. Six Claude skills data scientists can package to stop re-prompting

Analytics Insight lays out how a SKILL.md folder with scripts, validation checks and report templates turns repeated data chores into consistent workflows. It names six starter skills: exploratory data analysis, a data quality auditor, a statistical analysis reviewer, an ML evaluation skill that checks for leakage and baselines, a SQL analytics assistant, and an analysis-to-report skill. The piece recommends starting with one frequent task, testing against trusted results on clean and messy data, versioning the skill, and reviewing any bundled scripts and dependencies for security. It is a practitioner explainer rather than a launch, but it is a clear template for what a productivity-focused skill should contain.

Sources: Analytics Insight

4. Reverse Engineer Anything (REA) pairs an MCP server with a skill for Claude Code and Codex

The open-source REA project, reported at more than 200,000 GitHub stars, connects coding agents such as Claude Code and Codex to disassemblers including Ghidra, Hopper and IDA so they can inspect binaries, trace function calls and test hypotheses about how an application works. It also supports static analysis of JavaScript and Electron apps and .NET assemblies, runs locally and is MIT-licensed. Setup registers the MCP server and copies a skill into the agent's skills folder, a good example of the MCP-plus-skill bundle that is becoming a common distribution shape. Its own guidance notes it is not a sandbox, and star counts and dates vary between sources, so treat popularity figures as unverified.

Sources: TechGig, Pasquale Pillitteri, Kunal Ganglani

5. Anthropic's multi-agent Flows talk leans on the claude-api skill, including a prompt-tuning "hill climb"

In an AI Engineer session, Anthropic's CJ Avilla and Harrison Stall demoed Flows in Claude Managed Agents, where Claude designs and runs its own multi-agent topology; Avilla said a 1,000-agent flow building a Unix-compatible OS was still running after 85 hours. For skill users, the useful parts are a hill-climb subcommand of the Claude API skill in Claude Code that iteratively improves prompts to cut token spend, and a Bug Hunter template that is also reachable through that skill. Stall's declare, contain, detect framing lists skills among the things an agent definition should declare, alongside permissions and tools. It shows the claude-api skill acting as a front door to Anthropic's newest agent features.

Sources: BigGo Finance (AI Engineer podcast), YouTube
