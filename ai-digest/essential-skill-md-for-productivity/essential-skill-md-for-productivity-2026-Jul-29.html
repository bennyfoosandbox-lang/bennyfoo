1. MCP ships a stateless core, the biggest change yet to how skills reach agents through servers

The Model Context Protocol's 2026-07-28 release retires the old initialize/initialized handshake and the per-connection session ID, replacing them with self-describing requests that carry protocol version, client identity, and capabilities on every call. That matters directly for skills: a growing share of skill delivery now runs through MCP servers (see Microsoft's item below), and a stateless core means any request can land on any server instance behind a plain round-robin load balancer instead of pinning to one session — a reliability and scaling fix developers have been asking for since MCP launched. The release also graduates Tasks and MCP Apps into a formal versioned-extensions framework, adds cache hints so clients can stop re-fetching tool/skill catalogs on every reconnect, and hardens OAuth/OIDC (RFC 9207 issuer validation, a shift from Dynamic Client Registration to Client ID Metadata Documents) for enterprise identity providers like Entra and Okta. Anthropic, AWS, Google Cloud, Microsoft, and Cloudflare all published same-day statements backing the spec, and all four Tier 1 SDKs — TypeScript, Python, Go, and C# — already speak it.

Sources: Model Context Protocol Blog, Claude by Anthropic, Médéric Hurier on Medium

2. Microsoft lets coding agents pull skills straight from an MCP server, and takes its Dataverse skill plugin to two more marketplaces

Microsoft shipped two skill-infrastructure updates the same day. The .NET Agent Framework can now discover and load Agent Skills directly from an MCP server through a new skill://index.json discovery document, so a team can point an agent at a central skills server instead of copying skill folders into every deployment — mixing centrally hosted and on-disk skills through one AgentSkillsProviderBuilder. Separately, the open-source Dataverse Skills plugin — which teaches coding agents to drive the Dataverse MCP server, CLI, Python SDK, and PAC CLI in natural language — expanded from the Claude, Cursor, and GitHub Copilot marketplaces into OpenAI and Codex, a week after landing in the Cursor Marketplace. Both moves point the same direction: skills increasingly get served from one governed source with least-privilege security and RBAC enforced centrally, rather than bundled separately per agent.

Sources: Microsoft Agent Framework Devblog, Microsoft Power Platform Blog

3. A DevOps starter list: the SKILL.md files practitioners actually keep installed

A widely shared home-lab and DevOps write-up catalogs which downloadable SKILL.md files are earning a permanent spot in practitioners' toolkits, drawing on two community directories — Awesome GitHub Copilot and skills.sh — rather than an official vendor list. The recommended starter set skews infrastructure-heavy: a Docker Patterns skill for compose networking, credential, and container-security review; a separate Docker Compose Orchestration skill for multi-container dependency and health-check design; a Multi-Stage Dockerfile skill for cutting image size and attack surface; an Acquire Codebase Knowledge skill for fast onboarding into unfamiliar repos; a Kubernetes Specialist skill for manifest best practices beyond valid YAML; a Security Review skill that flags hardcoded secrets and command injection; and a Dependabot config skill for taming update-PR floods. The throughline matches what this digest keeps surfacing: a generic agent produces syntactically valid output, but a skill loaded with opinionated best practices is what catches the operational and security mistakes a human reviewer would.

Sources: Virtualization Howto, Awesome GitHub Copilot, skills.sh
