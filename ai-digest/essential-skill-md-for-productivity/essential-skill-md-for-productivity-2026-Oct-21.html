1. DevExpress Agent Skills 1.6.0 adds BI Dashboard, WPF and Reports skills that run the app and verify before reporting success

DevExpress's October update ships v1.6.0 of its vendor skill pack for Copilot, Claude Code, Cursor, Codex CLI and JetBrains assistants. A new dx-dashboard plugin adds Data Sources, Export and Parameters skills that read the project file, detect the platform and write code for it, and four dx-wpf skills (From Screenshot, Theme Customizer, Grid Data Source, Dependency Injection) start the app and check results before claiming success. The reworked ASP.NET Core Reports skill follows a fixed inspect, plan, run and verify workflow and reports NOT VERIFIED when it cannot confirm the page, and all 13 DevExtreme skills now cover ASP.NET Core Razor syntax. DevExpress says smaller models gained the most, and that a mid-size model used about half the input tokens on export and report tasks; these are the vendor's own test results, not independent benchmarks. Install with /plugin install dx-dashboard@DevExpress-agent-skills, or update existing plugins with /plugin marketplace update DevExpress-agent-skills.

Sources: DevExpress Blogs, DevExpress/agent-skills (GitHub)

2. EvoSkill v2 uses one stateful agent to rewrite skills, beating SkillOpt and SkillBoost by up to 7.7 points

A paper submitted on 19 October describes EvoSkill v2, a three-agent system that improves the skills an agent is given while leaving its model and harness untouched. A benchmark adaptor builds a task plugin from a description and grader, a solver attempts tasks, and an evolver reads the solver's rollouts and rewrites the skills each epoch. The evolver is a single stateful coding agent with a bash tool for the whole run, rather than a chain of single model calls (SkillOpt) or an agent that restarts each round (SkillBoost), and every epoch's skills are accepted instead of selected on noisy scores. Against the stronger of those two baselines it raised held-out pass rate by 7.7 points on SpreadsheetBench v2 and 5.4 on tau3-bench banking at a lower cost per point gained, and with Claude Haiku 5.5 as both solver and evolver a weaker model lifted its own skills by up to 21.5 points. Because the skills in question are SKILL.md-style instruction bundles, this is a concrete route to maintaining a productivity skill library automatically.

Sources: arXiv:2610.25931, arXiv full text (HTML)

3. Two frontend skills worth installing first: Impeccable redesigns a vibe-coded site, Diagram Design explains a codebase

A hands-on DEV Community post from 20 October tests two popular skills found on the Skill Leaderboard, which ranks skill repos by GitHub stars and can filter by compatible agent. Impeccable, built on top of Anthropic's frontend-design skill, installs with npx impeccable install, writes a PRODUCT.md during /impeccable init and offers several design directions; the author suggests building each on its own Git branch to compare them. Diagram Design (npx skills add cathrynlavery/diagram-design) produces a self-contained HTML and SVG diagram from 45 diagram types and inferred the visitor flow of a no-backend site unprompted, which the author finds useful for orienting in an undocumented codebase. The post also gives the practical safety advice that matters for any skill install: read the SKILL.md and any scripts it pulls in first, because a skill runs with your agent's permissions, and it briefly rates Ponytail, Caveman, Addy Osmani's agent-skills and Superpowers.

Sources: DEV Community (Erik Hanchett), pbakaus/impeccable (GitHub), cathrynlavery/diagram-design (GitHub)

4. A legal-research skill pack shows what a verification-first plugin looks like, down to a quotation-check hook

The legal-research-skills project publishes parallel plugins for Claude Code and Codex CLI with six research skills: multi-agent legal research, cite-check, proofread, find-cite, a Zotero library builder and Supreme Court case prep. Its technical reference lays out house rules that generalise to any serious skill: verify against primary sources instead of model memory, use deterministic Python scripts for structure and models only for judgment, add an independent pass over findings, and enforce limits in code. The Claude Code plugin also installs hooks that, in sessions where a research skill is active, flag WebFetch and WebSearch output as small-model summaries and block a final reply whose quotations of five or more words do not match raw tool output. Install is /plugin install legal-research --marketplace danepps/legal-research-skills, with a codex plugin add path for Codex, and the author is candid that these are working tools built for one workflow rather than a product.

Sources: Legal Research Skills: technical reference, danepps/legal-research-skills (GitHub)
