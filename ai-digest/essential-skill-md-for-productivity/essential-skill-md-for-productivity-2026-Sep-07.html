1. SpecterOps open-sources an AI skills marketplace for offensive-security tradecraft

On 2 September 2026, SpecterOps launched SpecterOps Skills, an open-source library of SKILL.md-formatted packages that teach coding agents red-team tradecraft directly: writing Aggressor scripts and Malleable C2 profiles for Cobalt Strike, driving BloodHound through its MCP server, and other workflows normally locked inside blog posts and internal playbooks rather than anything an agent can act on. Outflank co-announced the release the same day, contributing its own Outflank C2 plugin and framing the project as a way to make institutional red-team knowledge "digestible" to an AI agent instead of scattered across write-ups. The stated goal is to let red teamers automate the repetitive setup work so they can spend their time on the parts of an engagement that actually require judgment — finding gaps specific to a target, evading current security products, and reaching real objectives. It's a notable data point for this digest's "essential skills" thread: a specialized professional community choosing to formalize its own expertise as installable SKILL.md packages, which lands squarely inside the ongoing debate this digest has tracked all year about which skills are trustworthy enough to install given the marketplace's persistent malware problem.

Sources: SpecterOps: Demystifying Agent Tradecraft, Outflank: Red Team AI Skills

2. A new paper turns the fix for malicious skills into a skill itself

A 1 September 2026 arXiv paper, "Defense-as-Skill: Evolving Runtime Guard Skill for Skill-Augmented Agents," tackles a problem this digest has documented for months: once an agent loads a skill as persistent runtime context, a malicious one gains a durable channel to steer later actions — leaking secrets, bypassing approvals, or staging data for exfiltration only once a task and workspace state make the unsafe action look useful. Rather than bolting on an external scanner, the authors propose SkillSonar, a guard that itself ships as an installable, inspectable, editable skill: it runs alongside untrusted task skills, checks sensitive actions against the user's declared task boundary, and routes each one to allow, replan, or confirm — without modifying the underlying agent runtime. That framing matters for productivity teams specifically because it keeps the safety layer auditable in the same plain-language SKILL.md format as the skills it's guarding, rather than as an opaque scanner nobody on the team can read. It's a research contribution rather than a shipped product, but it is a direct, on-topic answer to the ClawHavoc- and ToxicSkills-style incidents that have dominated this digest's security coverage all year.

Sources: arXiv:2609.01487 (abstract), arXiv:2609.01487 (full text)

3. GitHub closes a gap where Copilot's agents could read files admins had explicitly excluded

On 2 September 2026, GitHub took content exclusions to general availability inside the Copilot app and Copilot CLI, meaning enterprise, organization, and repository-level file-path exclusion policies are now honored by those two agentic surfaces. The gap being closed was concrete: background Copilot agent processes previously did not inherit the same path-exclusion filters as standard Copilot completions, so a directory blocked for ordinary use could still be read by an agent operating inside its own isolated workflow. The fix is scoped to Copilot Business and Copilot Enterprise customers, and coverage on GitHub.com and GitHub Mobile remains in public preview rather than GA, so admins rolling this out are advised to validate with canary marker files across the app, CLI, editor modes, and code review before trusting it fully. For teams treating "which skills or agents can see which files" as a governance question — the same question the OWASP Agentic Skills Top 10 was written to answer — this closes one of the more obvious blind spots: an agent invoked through the CLI silently reading a file an admin thought was walled off.

Sources: GitHub Changelog, Blockchain.News coverage

4. Specter adds a "Skills" layer to its private-markets research agent

Specter, a startup-data and deal-sourcing platform, published "Meet Specter Agent" on 4 September 2026, introducing an agent embedded in its private-markets workspace that searches Specter's proprietary datasets and the open web, builds saved searches and lists, and — notably for this topic — runs repeatable "Skills" for sourcing and diligence work. The pitch is squarely productivity-focused: investors, founder-operators, and corporate-development teams can encode a recurring screening or diligence workflow once as a Skill and re-run it on demand, instead of re-deriving the same research steps by hand every time a new company needs vetting. Specter says scheduled background tasks and persistent memory across conversations are coming next, extending the same "codify a repeatable workflow once" logic that underpins SKILL.md elsewhere in this ecosystem. It's a narrower, single-vendor use of "Skills" than the open SKILL.md standard covered elsewhere in this digest — these skills are proprietary to Specter's own workspace, not portable files — but it's a useful data point for how far the vocabulary and pattern of reusable, named agent skills has spread into vertical SaaS products well beyond coding agents.

Sources: Specter Insights: Meet Specter Agent
