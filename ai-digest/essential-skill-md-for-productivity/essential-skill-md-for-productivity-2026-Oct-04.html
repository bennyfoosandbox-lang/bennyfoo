1. Google makes Gemini Skills official, rolling out in chat for free and paid accounts

Google has put a formal announcement behind Gemini Skills: you save a set of instructions once and call it from the chat box with a forward slash, instead of managing a separate Gems sub-menu. Coverage says Skills are rolling out globally to free and paid accounts, with Workspace business, enterprise, nonprofit and education customers following “in the coming weeks”. This is a material update to what we logged earlier (a Nov 17 Gems-to-Skills migration, with Skills reportedly gated to Pro/Ultra), so check the current scope against your own account. For productivity users it moves reusable, slash-invoked procedures from a developer feature into a default consumer chat surface.

Sources: Google blog: Let skills in Gemini tackle your most repetitive tasks, Android Headlines

2. Microsoft’s rebuilt Copilot puts role-specific Skills inside Word and Excel (from 25 Sep)

On 25 September Microsoft unveiled a redesigned Copilot built around three pieces: Home with Office in Copilot, a Code app builder and Autopilot, a persistent agent. Within it, a Skills feature brings role-specific expertise, such as financial skills in Excel and legal skills in Word, into the Microsoft 365 apps as reusable workflows. Code is slated to reach the Frontier programme at the end of September and broader availability in the following weeks, with Microsoft 365 Premium and Pro preview later in 2026. This item is about nine days old, included because it was not yet in our knowledge base and the thin 24-hour window left room; it is separate from the Copilot Studio skills GA we already covered.

Sources: The Official Microsoft Blog, Unite.AI, Technology.org

3. Unified.to publishes 100+ free SKILL.md files so coding agents can build integrations

API-integration vendor Unified.to said in its September product update that it now ships more than 100 free SKILL.md files designed to let a coding agent build an integration against its platform. It is another example of a vendor treating a skills pack as developer documentation for agents rather than for humans, the same pattern Zoom and Salesforce have followed. The practical upside is that an agent can load only the relevant integration skill instead of reading a full API reference. We could not open the vendor page from this environment, so details beyond the headline figure come from the news brief’s summary; verify scope before relying on it.

Sources: Unified.to: September 2026 product update, AI Agents News Brief, 2 Oct 2026

4. Codex CLI 0.160.0: faster plugin loading and projectless sessions

OpenAI’s Codex 0.160.0 (released 1 October) caches parsed plugin manifests and reuses HTTP connections for remote plugin requests, which trims repeated load work for the plugins that bundle skills, connectors and MCP config. It also lets sessions start outside a project with workspace defaults when policy permits, restoring saved permissions on resume, and adds an agent command center “Browse older tasks” history view. The release notes do not list skills changes as a headline, so treat this as plumbing that makes skill-carrying plugins cheaper to run rather than a new skills feature. Windows sandbox and SQLite-stall fixes round out the release.

Sources: openai/codex release 0.160.0, Releasebot: Codex updates, AI-TLDR: Codex CLI 0.160.0

5. Catalogue churn on 3 Oct: a new AgentHouse skills release and AgenticSkills directory v1.7.0

Two small catalogue updates landed on 3 October. The open-source AgentHouse skills repo cut a new release tag, release-2026-10-03, two days after its 1 October release (the page did not render a changelog for us, so the contents are unknown). Neither is a major launch; they are included because the window produced few other new items and they show curated, versioned skill catalogues being updated on a cadence of days rather than months.

Sources: AgentHouse Skills release-2026-10-03, AgenticSkills directory
