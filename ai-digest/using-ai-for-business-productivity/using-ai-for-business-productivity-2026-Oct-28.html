1. IBM's Orchestrate adds an AI Gateway to govern agents built on any platform

At TechXchange 2026, IBM introduced an AI Gateway for watsonx Orchestrate that discovers and governs third-party agents, models and MCP servers from platforms such as Amazon Bedrock, Microsoft and Google through one enforcement layer. The agent catalog becomes a governed library that shows performance, reliability and risk signals (aligned to OWASP, CoSAI and the EU AI Act) at the point of discovery, and a Premium Runtime adds hardware-virtualised isolation for agent code. New evaluation tools include custom LLM-as-a-judge scoring, user simulation, a Trace Inspector and an AgentOps Agent that diagnoses failures and tunes agents before promotion. The pitch to enterprises drowning in agent sprawl is to manage hundreds of agents without standardising on one vendor.

Sources: IBM, AI Agents Directory brief

2. IBM adds identity and access controls so agents are treated like accountable workers

Alongside Orchestrate, IBM announced identity and control tooling for AI agents covering discovery, verified identities, access controls and performance evaluation across enterprise systems. IBM Agent Identity supplies identity and authorisation context while HashiCorp Vault issues least-privilege credentials, and Orchestrate can connect to Microsoft Entra and IBM Verify to manage human and non-human identities together. For businesses putting agents into finance, HR and IT workflows, the point is accountability: every action traceable to a named agent with limited, auditable access rather than a shared service account.

Sources: IBM Newsroom, IBM

3. SAP TechEd: an Enterprise AI Gateway, a Joule Studio CLI and a business context layer

At TechEd in Berlin SAP followed last week's Joule Work news with the builder and governance pieces. Joule Studio lets business users describe agents in natural language while developers refine them through a new command-line tool, with a sandbox for testing and a governed path to production. A new SAP Enterprise AI Gateway centralises authentication, policy, routing and auditing for MCP, A2A and LLM traffic, and an AI Governance Assistant pre-fills EU AI Act assessments for review. On the data side, SAP is adding Iceberg lakehouse support, an ontology manager and two new prediction models for forecasting and order decisions, plus a free Joule Studio developer certification through 31 December.

Sources: SAP, CIO

4. OpenAI's GPT-6.1 Terra goes generally available with half-price computer-use agents

OpenAI released GPT-6.1 Terra, a mid-tier model pitched at faster, cheaper everyday work, and cut API pricing for agentic computer-use workloads by 50%, according to trade coverage. Microsoft made Terra generally available in Foundry the same week for agents that read charts and scanned documents and operate desktop applications. The price cut matters for back-office automation, where per-task cost has been the brake on running agents across legacy screens with no API. Note that naming and pricing details rest on secondary reports, and one independent search found model naming inconsistent, so check OpenAI's pricing page before budgeting.

Sources: PYMNTS, Microsoft Tech Community, Ground News

5. Dataiku Headless lets Claude Code and Codex build governed data and AI projects

Dataiku used its Succeed conference to launch Headless, a plugin that lets developers working in Claude Code, Codex, Cursor and similar coding agents hand building work to Dataiku Cobuild and get back an inspectable Dataiku project instead of a script only they can read. Early use cases are migrating Excel and Alteryx workflows into governed visual pipelines at scale and letting admins ask an agent to find and fix failing jobs across projects. It addresses a real productivity trap: coding agents make building fast, but the output is invisible to the wider business. Availability is via the Claude Code and Codex marketplaces.

Sources: Dataiku
