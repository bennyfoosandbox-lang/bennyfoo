1. Accenture caps central Claude funding at $29 per employee a month, pushing overages onto project budgets

Per an internal memo reported by 404 Media, Accenture centrally funds only $29 a month of Claude usage per employee from October 1, after some staff had been spending as much as $1,000 a month. The cap is a funding ceiling rather than a ban: people can go past it if a project or team code covers the cost, but licences are reviewed periodically and can be revoked, and at least one worker lost access altogether. Accenture's own agentic AI strategy lead said non-engineers drove many of the overages, mostly on routine jobs like converting PDFs to slides. It is a concrete example of the shift from flat seats to metered AI spend, where the productivity question becomes who pays for heavy use. The details rest on a leaked memo and secondary summaries; Accenture's public comment was limited to saying it provides the right tool for the right work.

Sources: 404 Media, AI Weekly, Superpower Daily, ExplainX

2. Microsoft previews Copilot Studio agents with their own accounts, shared memory and triggers

On October 15 Microsoft announced agent accounts, business-process memory and triggers for Copilot Studio, rolling out through its Frontier program. An account gives an agent its own Entra ID identity and mailbox, and triggers such as an incoming email or a set schedule can start work without a new prompt. Memory for an account-based agent is shared among its users, with no privacy boundary or opt-out in the preview. The limits are notable: these agents cannot answer people outside the tenant, cannot read documents carrying labels such as Confidential, and cannot make targeted edits to existing documents. Publishing also needs Microsoft 365 E5 with the Agent 365 add-on or E7, plus a Frontier licence per agent account, and usage may consume Copilot Credits. Ooredoo Qatar is named as an early customer using an agent to review business cases and prepare executive briefs.

Sources: NeoTeo, Microsoft Copilot blog, AI Agents Directory

3. Vendor rate limits, seat caps and per-call fees are breaking AI agents in production, Reworked warns

A Reworked analysis published October 16 argues that rules built for human click rates are now throttling AI agents. Salesforce said in September it will charge for each successful call a registered agent makes to its systems, including through MCP, with no price yet and 30 days' notice before billing starts. Figma caps agent requests by seat type, from six a month on View and Collab seats to 200 a day on Full and Dev seats. Experts quoted from Insight Enterprises, Redgate Software and G&A Partners warn that an agent hitting a limit may return a confident answer built on partial data without knowing it. Their advice is to map which vendor systems each agent touches, separate agent reads from writes, treat agents as managed non-human identities, negotiate at least 90 days' notice of API changes, and budget with hard caps and alerts. This is commentary built on expert opinion, not a measured study.

Sources: Reworked, Reworked on Slack API limits, Figma MCP rate limits

4. ServiceNow lets employees build their own role-specific agents in EmployeeWorks and adds ToolSmith for developers

On October 15 ServiceNow announced upgrades to its EmployeeWorks platform that let employees build AI agents customised to their job functions, aimed at automating routine tasks and persona-based workflows. It also introduced ToolSmith, a developer environment it says cuts tool creation from days to minutes while keeping enterprise security and operational controls. The announcement is separate from the AI Workflow Factory and Autonomous Engineer launch covered earlier, and shifts agent building toward line employees rather than only IT and developers. Public coverage so far is thin and partly auto-generated, so the specifics of pricing, availability and governance controls are not yet clear.

Sources: GuruFocus, AI Agents Directory

5. OpenAI's ChatGPT Chrome extension can now manage open browser tabs to complete tasks

OpenAI updated its ChatGPT Chrome extension on October 15 so it can control a user's open browser tabs, completing multi-step tasks and organising tabs directly in the browser. That extends ChatGPT's computer-use abilities into the place where much office work already happens, which is web apps and documents. It follows OpenAI's ChatGPT Work agent mode launched in July. The report is brief and secondhand: it does not detail permissions, admin controls or which plans get the feature, which matters for businesses weighing the security of an agent that can act across logged-in tabs.

Sources: Unite.AI, AI Agents Directory, SiliconANGLE on ChatGPT Work
