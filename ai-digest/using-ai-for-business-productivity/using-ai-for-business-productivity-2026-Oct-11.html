1. Oracle's Fusion Claw splits AI planning from deterministic execution for back-office work

Oracle introduced Fusion Claw on 29 September, a governed runtime for its Fusion Agentic Applications. A frontier model plans the job, then deterministic computation carries it out, so the same inputs produce the same result and every run leaves an audit record. Customers set an operating envelope per run and choose how much automation each process gets. It launched with 25 Claw-powered applications, taking Oracle's agentic portfolio to 75. This is a notable counter-design to free-roaming agents, aimed at finance and operations teams that need repeatability. (Not from the last 24 hours: reported about two weeks ago and not yet covered here.)

Sources: Oracle announcement, ERP Today, Techfinitive, Futurum

2. Nvidia's Open Agent Safety Platform puts a hardware watchdog around enterprise agents

Nvidia launched the Open Agent Safety Platform on 28 September as a reference design for keeping AI agents inside set limits. It pairs OpenShell, an open-source sandbox runtime that enforces operator-defined boundaries, with Sentry, a watchdog on BlueField-4 DPUs that sits outside the agent's machine and can quarantine an agent that tries to escape in milliseconds. Partners named include Cisco, Microsoft, Oracle, Dell and HPE, with an optional Claude Managed Agents layer built with Anthropic. Nvidia's pitch is that an agent cannot police itself, which speaks directly to the governance blockers holding back business rollouts. (From late September, not covered here before.)

Sources: The Next Web, SecurityWeek, PBS NewsHour, Let's Data Science

3. Cohere ships North 2 with cross-session memory and token-level admin controls

Cohere released North 2 on 5 October, an upgrade to its enterprise agent platform. The headline changes are a redesigned orchestration harness, persistent memory so agents keep context across sessions, and reusable agents and skills that teams can build from prompts and share. North Admin adds usage tracking, rate limits, user quotas and organization-wide caps with alert thresholds, plus role-based permissions, PII detection and prompt-injection guardrails. It is model-agnostic and can run in cloud, on-premises or air-gapped. Pricing is per deployment and unpublished, and Cohere has not released benchmarks.

Sources: Technology Magazine, Let's Data Science, AI Weekly, HPCwire

4. Salesforce Winter '27 goes GA on 12 October with Agentforce switched on by default

Salesforce's Winter '27 release reaches general availability on 12 October, and its main theme is agents completing whole workflows rather than single tasks. Agentforce is being enabled by default: new orgs get it at creation and existing orgs are being transitioned on a rolling basis. The release also covers commerce, voice, Slack and industry features, including new marketing agents for campaign creation and lead nurturing. One third-party analysis claims a 13% conversion lift for agentic commerce search, but its baseline is undisclosed, so treat that figure as unverified. Admins should check their org's upgrade window.

Sources: Stellagent, Salesforce Ben, Citrin Cooperman, Vantagepoint
